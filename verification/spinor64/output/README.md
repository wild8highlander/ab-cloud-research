# 📤 spinor64 — frozen run output

> **The certified result set of the 64/64 GUE-consistency run: report, table, JSON and the raw log.**

The output half of the spinor-64 verification: [`spinor64_report.md`](spinor64_report.md) is the human-readable verdict (64/64 structures GUE-consistent, orbit breakdown 28/21/7/7/1, E2 holonomy classes), [`spinor64_table.csv`](spinor64_table.csv) the per-structure table, [`spinor64_results.json`](spinor64_results.json) the machine-readable payload, and [`run_log.txt`](run_log.txt) the raw console stream of the certified run.

These files are the *record*: the verification test asserts its numbers against this frozen output, so any code change that shifts a value breaks CI here rather than quietly rescaling the claim. Regenerating is deliberate: rerun the verification from [`../`](../README.md) and diff before replacing.
