# Spinor64 — верификация 64 спинорных структур квартики Клейна

Эталонная реализация исправленного расчёта всех 64 спинорных структур
квартики Клейна (род g=3) с полным прогоном и отчётом. Исправляет
утверждение монографии v21 (разд. 3.1) о том, что «только idx=38 даёт
GUE-согласие (p=0.598)».

## Главный результат

**Все 64 спинорные структуры дают GUE-согласованные значения.** Ни одна
структура не является уникальной:

- **E1 (точная симметрия).** PSL(2,7) = Aut(K₄) разбивает 64 структуры на
  орбиты размеров **28 / 21 / 7 / 7 / 1**; орбита из 28 — нечётные структуры
  (Arf=1, 28 битангентов, транзитивность — классическая теорема Римана–Клейна,
  подтверждена численно). Операторы внутри орбиты перестановочно-сопряжены и
  имеют **точно одинаковые спектры** (max|Δλ| ≈ 8.9·10⁻¹⁵). Калибровочная
  инвариантность: 7.1·10⁻¹⁵. Нулевые моды дискретного оператора Дирака:
  2 (нечётная орбита) / 3 (чётные орбиты) / 7 (тривиальный класс).
- **E2 (статистика, AB-облако).** Хофштадтеровский тор L=44, α=1/2, Nv=54
  вихрей (плотностное масштабирование), калибровка :monumental, спиновая
  структура как граничные твисты: **64/64 структуры GUE-согласованы**
  (MC p-value против согласованного по размеру GUE-ансамбля, min p = 0.36),
  ⟨r⟩ = 0.5984 ± 0.0035 (GUE-референс 0.59965).

## Почему в v21 получилась «уникальность idx=38»

1. Вычислительная ошибка/артефакт: правильная конструкция операторов на
   PSL(2,7)-симметричной дискретизации делает структуры внутри орбит
   *изоспектральными по построению* — уникальность одной структуры
   невозможна (разд. 3.2.3 v21 называл это «решёточным артефактом Z₄»;
   численно подтверждено здесь для всех 64, а не только 28 нечётных).
2. Внутреннее противоречие v21: по собственной формуле монографии
   Arf(ε) = ε₁ε₂+ε₃ε₄+ε₅ε₆ вектор ε(38) = (0,1,1,0,0,1) даёт **Arf = 0**,
   а не 1, как утверждается в разд. 3.2.1 и 12.4.

## Состав

| Файл | Описание |
|---|---|
| `spinor64_core.py` | Библиотека: PSL(2,7) над F₇, граф Клейна {3,7} (регулярное отображение через стабилизаторы C₇/C₃/C₂), 64 спин-структуры как сигнатуры Кастелейна (нечётная граневая чётность, каноническая калибровка), GF(2)-линейная алгебра, хофштадтеровский порт :monumental, RMT-статистики (без scipy) |
| `run_spinor64.py` | Полный прогон E1+E2 → `output/` |
| `data/spinor_classes.csv` | Замороженные 64 сигнатур (class_idx, orbit, arf, 84 знака ±1) |
| `data/klein_graph_edges.csv` | Топология графа Клейна (84 рёбра, 56 вершин) |
| `data/reference_spectrum.csv` | Эталонный спектр представителя нечётной орбиты |
| `data/reference_stats.json` | Эталонные значения (r_mean, число нулевых мод) |
| `output/` | Результаты прогона: JSON, CSV-таблица 64 строк, Markdown-отчёт, лог |

## Воспроизведение

```bash
python3 verification/spinor64/run_spinor64.py   # ~10 минут, 2 ядра
```

Порты Test 38 на других языках: `verification/{cpp,java,rust,go,fortran,haskell,r,matlab,javascript}/spinor38/` — каждый читает замороженные данные
из `data/` и проверяет точную изоспектральность + ⟨r⟩ собственным
Якоби-алгоритмом (без LAPACK).
