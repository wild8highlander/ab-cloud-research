Русское издание переписанной монографии «AB-Cloud — фазовый резонатор для
нулей дзета-функции Римана», построенной с нуля на 37-тестовом верификационном
наборе (v18/v19). Каждый рисунок и каждое число в тексте привязаны к именному
тесту с полным журналом вычислений.

## What the text contains

- Механика AB-облака: хофштадтеровская решётка с потоком AB и топологическими
  вихрями; GUE-статистика спектра против нулей дзета-функции (⟨r⟩, Σ²(L),
  Δ₃(L), K(τ)).
- Полный разбор 37-тестового набора: сходимость b(N) (b(50000) = 1.2126),
  тест Монтгомери (KS = 0.047, p = 0.27), дефект Байерса–Янга 3.5·10⁻¹⁵,
  самодвойственность Конна, дираковский конус (v_F ≈ 0.125, R² = 0.9997).
- Приложение B (в сборке v22.1): протокол двухпроходного прогона
  `run_20260902_134759` — Julia 1.12.0, 50 000 нулей Одлыжко, проход 2 на
  96×96 (HARDCORE), 37/37 тестов отработали.
- Приложение D (в сборке v22.1): spinor64 — все 64 спинорные структуры
  GUE-согласованы; орбиты PSL(2,7) 28/21/7/7/1; изоспектральность ~1e-14;
  утверждение v21 об «уникальности idx=38» снято (Arf(ε(38)) = 0 по формуле
  самой монографии).

## How to read / rebuild

- Читать: `AB_Cloud_Monograph_v22_RU_v221.pdf` — самая свежая сборка.
- Править: `.md` (или `.tex`), затем пересобрать HTML/DOCX через pandoc
  (CSS — `original-v21/ru/text/mono.css`), PDF — через `xelatex` на `.tex`
  (два прохода).
