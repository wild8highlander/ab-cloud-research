# 📘 Monograph v22 — Russian text

> **The Russian edition of the v22 monograph in every shipping format: md/html/tex/pdf/docx/pptx.**

The complete Russian edition of monograph **v22**: the canonical Markdown (`AB_Cloud_Monograph_v22_RU.md`), the web edition (`.html`), the LaTeX source, the compiled PDF and DOCX, the 14-slide presentation (`.pptx`), and the v2.2.1 revision pair (`*_v221.*`). The figures embedded by the text live in [`../figures/`](../figures/); the verification artifacts the numbers come from live in [`../../../results/`](../../../results/README.md).

Which file to open first: the `.pdf` for reading, the `.md` for diffing and quoting, the `.pptx` for the talk. The `_v221` files are the revision lineage — kept alongside so citations to either state keep resolving.
