## 🔁 Regeneration workflow

1. Edit prompts here (centralized registry — keep IDs stable).
2. Re-generate (Midjourney / Flux / DALL·E / SDXL, or the bundled driver):
   `python3 scripts/readme/gen_images.py` (driver kept for reproducibility).
3. Post-process: `python3 scripts/readme/process_images.py` (crops + WebP).
4. Validate: `assets-validate` GitHub Action must pass (manifest ↔ files).
