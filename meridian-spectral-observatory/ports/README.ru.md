# AB-Cloud Multi-Language Ports

Полные вычислительные аналоги сюиты **meridian-spectral-observatory**
(`ab_cloud_full.jl`, `hp_audit_standalone.jl`, `AB_Cloud_Monumental_v6_3.jl`)
на четырёх языках: **Python, C++, Rust, Go** — с эталонной автосверкой
(golden selftest) против **неповреждённых Julia-оригиналов**.

---

## Быстрый старт

| Язык | Сборка / запуск | Самопроверка |
|------|-----------------|--------------|
| Python 3.8+ | `python3 -m abcloud …` (пакет `ports/python/abcloud/`) | `python3 -m abcloud selftest` |
| C++17 | `g++ -O2 -std=c++17 -o abcloud abcloud_port.cpp` | `./abcloud selftest` |
| Rust | `cargo build --release` | `./target/release/abcloud selftest` |
| Go | `go build -o abcloud .` | `./abcloud selftest` |

Каждый `selftest` пересчитывает контрольные числа из
`ports/golden/abcloud_golden.json` — файла эталонов, сгенерированного из
оригинального Julia-кода генератором `ports/golden/gen_golden.jl` — и
печатает PASS/FAIL по каждой контрольной точке: **199 проверок** в
C++/Rust/Go (133 базовых + 66 векторного яруса §8); Python-пакет
покрывает базовые 133.

Статус верификации (эталонная сверка `selftest`):

| Порт | Golden selftest | Suite (25 тестов) |
|------|-----------------|-------------------|
| Python | **133/133 PASS** (базовый ярус) | 19 PASS, 0 FAIL, 3 WARN, 3 INFO |
| C++ | **199/199 PASS** (вкл. §8) | 19 PASS, 0 FAIL, 3 WARN, 3 INFO |
| Rust | **199/199 PASS** (вкл. §8) | 19 PASS, 0 FAIL, 3 WARN, 3 INFO |
| Go | **199/199 PASS** (вкл. §8) | 20 PASS, 0 FAIL, 2 WARN, 3 INFO |

## CLI (одинаков на всех языках)

```
selftest                      — эталонная сверка с Julia-оригиналами (199 проверок)
zeros  [--data P] [--n N]     — полная батарея анализа нулей
                                (KS / CvM / A² / χ² / ⟨r⟩ / Σ² / Δ₃ / K(t) / H1-SNR)
suite  [--test N|all]         — переносимое подмножество 39-тестовой сюиты
ham                           — векторный ярус §8: энтропия/ТЭЭ/IPR/RH-метрики
                                трёх дегенеративно-безопасных сценариев
bN     --N n… [--offset k]    — статистика b(N)
gram   --n n…                 — точки Грама
test11 --mc N --seed S        — честный тест Андерсона–Дарлинга + MC-null
hp     [--data P] [--n N]     — H1-детектор (Брэгг-пики на ω = log p)
sweep  --N n…                  — лестница b(N)
```

## Эталонная система (golden)

* `ports/golden/gen_golden.jl` — включает **немодифицированные** оригиналы
  (`ab_cloud_full.jl`), прогоняет каждую секцию и пишет JSON с `%.17g`.
* ВсеWindow-выборки Σ²/Δ₃ используют **классический MT19937**
  (init_genrand), встроенный идентично во все пять программ (включая
  генератор) — оконная выборка бит-в-бит совпадает во всех языках.
* Сетки частот ω (726 точек) и t (30 точек) записаны в JSON — устранена
  зависимость от `colon`/`arange`-семантики языков.
* Допуски: 1e-9 rel на чисто скалярных секциях; 1e-7 rel на спец-функциях
  (кросс-либм exp/log: openlibm vs glibc ~2e-8); 1e-8 abs на
  собственных значениях (LAPACK zheevr vs Jacobi-солвер портов);
  1e-6 rel на Фурье-суммах H1/K(t).

## Что портировано (вычислительное ядро, 1:1 с оригиналом)

* **Скалярная математика**: Lanczos lgamma, регуляризованная неполная
  гамма (серия + дробь Лентца), точный χ²-CDF (любые df), асимптотическое
  KS-p-value (двойная тета-серия с корректным −2k²λ²), суррогаты Wigner
  GUE β=2 / GOE β=1, Lambert W₀ (Хэлли), точки Грама (исправленная
  асимптотика θ с 1/(48t)+7/(5760t³)), лестница b(N).
* **RMT-движок опорного закона**: интерполяционная таблица CDF
  (32768 точек, |ΔF|≤1e-9), обратная CDF-квантильная сетка (4096, 48
  бисекций) — точный закон-exact MC-сэмплер Теста 11.
* **GOF-статистики**: KS (поправка Стивенса), двухвыборочный KS с
  полной дисциплиной связок, Крамер–фон Мизес W², Андерсон–Дарлинг A²,
  χ²-гистограмма (переполняющая корзина, порог exp≥5), ⟨r⟩ (с защитой
  от 0/0 при вырождениях), гладкая функция счёта Н̄(T), развёртка,
  Σ²(L), Δ₃(L) (через linreg-остатки — как в оригинале), двухуровневый
  форм-фактор K(t) с локальным развёртыванием и сглаживанием.
* **Решётка AB-облака**: Vortex, ABCloudConfig, монументальная
  гладкая-калибровка вертикальных связей (atan2-разности ·0.5),
  модель :dirac (гладкая часть + явная струна Дирака: −2πq на
  восходящей связи, +2πq на нисходящей, тор-ветка), кулоновский
  потенциал вихрей + остаточный беспорядок ε (см. ниже),
  эрмитова симметризация (H+H†)/2, канонический plaquette_flux
  (CCW-сумма angle(−H)), flux_circdist (круговое расстояние —
  защита от фантома ветки ±π), центральная полоса спектра.
* **HP-аудит (H1)**: сырой позиционный периодограммный детектор
  P(ω)=|Σwₖe^{−iωTₖ}|²/Σwₖ² (окно Ханна), SNR-ярдык против медианы
  полосы 0.3:0.004:3.2, вердикты PASS/STRONG (≥4 из 6 простых гармоник
  выше SNR 10 / все выше 100), GUE-огибающая K_box(t)=t(1−sinc(2πt)),
  AICc, Wald-CI, Спирмен (средние ранги), флуктуационный high-pass.

## Векторный ярус §8 (numpy/LAPACK-ярус) — C++/Rust/Go

Ярус, требующий эйгенвекторов и МНК-фита; в Python опирался на
`numpy.linalg`, в C++/Rust/Go работает на собственном циклическом
Якоби-солвере с накоплением матрицы вращений U (PORT_SPEC §8):

* **mon_entropy** — энтропия фон Неймана ранг-1 редуцированной матрицы
  C_A = ψ_A ψ_A† (клампы [1e-12, 1−1e-12], натуральный логарифм,
  round(Int,·) = half-even) центральных трёх состояний при f=0.25/0.5/0.75
  + IPR = Σ|ψ|⁴;
* **topo_tee** — топологическая энтропия запутанности (V90): полный
  эйгенразложение H, 53 fraction из оригинала, фит
  `[boundaries ones] \ S_mean` через Householder QR → slope_alpha, gamma_top;
* **rh_metrics** — KS D/p на центральной полосе 0.6 (разворотка local-mean,
  протокол Теста 16) + ⟨r⟩.

Сценарии (W=0, open, проверены гард-ом вырождений gap > 1e-9):
`L8_open_a025_2vort`, `L10_open_a03_clean`, `L12_open_a03_clean`.
α=0.5-сценарии и торус L10 исключены: точные дуплеты делают базис
векторов несравнимым между LAPACK и Якоби.

## Документированные отклонения портов

1. **Беспорядок при W>0**: ε ~ U(−0.01,0.01) берётся из классического
   MT19937 (seed = disorder_seed). Оригинал использует встроенный dSFMT
   Julia, который не воспроизводим в других языках. **Все golden-якоря
   используют W=0**, где ε не разыгрывается вовсе.
2. **Собственные значения**: циклический Jacobi для эрмитовых матриц
   (C++/Rust/Go) вместо LAPACK zheevr — совпадение ~1e-12, внутри
   золотых допусков 1e-7/1e-8.
3. **Размеры решёток в suite-статистике**: из-за отсутствия LAPACK
   статистические тесты 12/16/34 в C++/Rust/Go используют решётки
   200²/24²/28² (Python — 400²/32²/40² через numpy). Это СТАТИСТИЧЕСКИЕ
   тесты — пороги калиброваны под конечный размер; golden-selftest
   использует полные размеры (64/100/144) и верифицирован на всех.
4. **Сюита**: портировано 25 из 39 тестов (вычислительное ядро);
   остальные 14 печатают честный `[SKIP]` с причиной (графика,
   специализированные протоколы, dSFMT-зависимый беспорядок).
5. **Векторный ярус §8**: наблюдаемые зависят только от модулей
   компонент эйгенвекторов, поэтому фаза/знак вектора не фиксируется;
   легально ТОЛЬКО на невырожденных спектрах — генератор эталона
   проверяет зазор и падает при нарушении (см. PORT_SPEC §8.3).

## Структура

```
ports/
├── golden/
│   ├── gen_golden.jl           — генератор эталонов из НЕмодифицированного Julia
│   └── abcloud_golden.json     — 199 эталонных чисел + сетки ω/t
├── python/abcloud/             — канонический пакет (mt19937, special,
│                                 rmt_table, gof, lattice, unfold, hp_audit,
│                                 golden, suite, cli)
├── cpp/abcloud_port.cpp        — однофайловый C++17 порт (тот же CLI)
├── rust/ (Cargo)               — однофайловый Rust-порт (std only)
├── go/main.go + go.mod         — однофайловый Go-порт (std only)
├── PORT_SPEC.md                — спецификация паритета (формат эталонов,
│                                 допуски, MT19937, правила портирования)
└── README.md / README.ru.md    — этот файл
```

## Regenerating the golden

```bash
julia ports/golden/gen_golden.jl <meridian_dir> <out.json>
# по умолчанию: julia ports/golden/gen_golden.jl . ports/golden/abcloud_golden.json
```

Требуется Julia 1.10+ с stdlib (LinearAlgebra, DelimitedFiles, Printf) и
файл `zeros50k.txt` в корне meridian-каталога.
