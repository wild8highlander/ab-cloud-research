# PORT_SPEC.md — Cross-Language Parity Specification

Спецификация паритета для многоязычных портов сюиты
meridian-spectral-observatory. Любой новый порт обязан удовлетворять
этому документу и проходить `selftest` со счётом 133/133.

---

## 1. Контракт паритета

1. **Эталон** — `ports/golden/abcloud_golden.json`, сгенерированный
   `gen_golden.jl` из НЕмодифицированных оригиналов. Эталон —
   единственный источник истины; никакие «известные правильные
   значения» из документации не являются контрактом.
2. **Проверка** — `selftest` порта пересчитывает все секции эталона
   (кроме `meta`/`grids`) и сравнивает с допусками §3. Счёт 133/133
   обязателен.
3. **Ключи** секций формируются строкой `name` в формате Julia
   `string(Float64)` — кратчайшее round-trip представление с точкой:
   `1.0 → "1.0"`, `0.05 → "0.05"`, `10.0 → "10.0"` (НЕ `"1"`, НЕ
   `"1e+01"`). Несовпадение формата ключа = FAIL.

## 2. RNG: классический MT19937 (обязателен)

Julia `Random.MersenneTwister` — это dSFMT и **не** совместим между
языками. Все порты и генератор эталонов обязаны использовать
**классический MT19937** со следующей спецификацией (совпадает с
референсной C-реализацией mt19937ar и с CPython `random.random()`):

- init: `mt[0] = seed; mt[i] = 1812433253·(mt[i−1] ⊕ (mt[i−1] >> 30)) + i (mod 2³²)`;
- блок: 624 чисел, twist `y = (mt[k]&0x80000000)|(mt[k+1 mod 624]&0x7fffffff)`,
  `mt[k] = mt[(k+397) mod 624] ⊕ (y>>1) ⊕ mag01[y&1]`, `mag01 = {0, 0x9908b0df}`;
- temper: `y ⊕= y>>11; y ⊕= (y<<7)&0x9d2c5680; y ⊕= (y<<15)&0xefc60000; y ⊕= y>>18`;
- double: `((a>>5)·2²⁶ + (b>>6)) / 2⁵³`, где a, b — последовательные uint32.
- **Критично**: блок выдает ВСЕ 624 числа (init-состояние «пустое»);
  ошибка «623 числа на блок» даёт расхождение потоков с 624-го вызова
  (реальный баг, найденный при отладке — см. worklog).

## 4. Сетки из эталона (НЕ строить локально)

Секции `grids.omega` (726 значений, H1-полоса) и `grids.tvals`
(30 значений, K(t)) читаются портом из JSON. Локальное построение
`0.3:0.004:3.2` зависит от семантики colon/arange языка и запрещено
в паритет-пути.

## 5. Обязательные алгоритмические детали (легко сломать)

1. `ks_asymptotic_pvalue`: ветка λ<0.6 — комплементарная форма
   `1 − √(2π)/λ·Σ exp(−((2k−1)²π²)/(8λ²))`, иначе тета-ряд `2Σ(−1)^{k−1}exp(−2k²λ²)`;
   брейки по term<1e-18, клампы [0,1].
2. `anderson_darling_stat`: клампы F в [1e-300, 1−1e-16]; формула через
   пары (i, n+1−i).
3. `chi2_gue_test`: s_max = min(max, 4.0); переполнение → последняя
   корзина; корзины с exp<5 пропускаются; df = max(count−1, 1).
4. `gue_cdf` — ВСЕГДА через таблицу (32768 точек, линейная интерполяция,
   точная формула при s≥5).
5. `compute_bN`: смещение `offset` — часть контракта (Test 10).
6. K(t): окно развёртки `max(3, round(0.05·n))`; сглаживание j∈[w, len−w−1],
   пропуск t<0.5; БЕЗ вычитания 1 (позиции абсолютные).
7. plaquette_flux: CCW-сумма `angle(−H[b,a])`; сравнение потоков — только
   через flux_circdist.
8. Jacobi-солвер: `s = t·c` (НОРМИРОВАННОЕ вращение; s=t даёт неверный
   спектр!), фаза φ=arg(a_pq), τ=(a_qq−a_pp)/(2|a_pq|),
   t = sign(τ)/(|τ|+√(1+τ²)).
9. eigend-ключи: `eigend3` = МАКСИМУМ спектра (Julia `ev[n−k]`), NOT
   `ev[n−3]`.
10. Σ²/Δ₃: один поток MT19937(777) общий для S2→D3 в порядке
    L=5,10,20,50,100 затем 5,10,20,50.

## 6. Порядок портирования нового языка

1. Скопировать Rust-порт как образец (std-only, без зависимостей).
2. Реализовать MT19937 по §2; проверить первые 5 doubles против
   Python: 0.15266373490132201, 0.30235660970752121, 0.062036414714562005,
   0.45986034160896883, 0.83525338443762831 (seed 777) И n=700:
   481389588 (uint32) — это ловит баг «623 числа».
3. Скалярные функции → GOF → решётка → selftest.
4. Гнать `selftest` до 133/133.
5. Прогнать `suite` — сравнить вердикты с Python (19 PASS / 0 FAIL).

## 7. Известные ловушки (найдены при отладке)

- Julia `string(1.0)` = "1.0", `%.17g` = "1" — ключи эталона в стиле Julia.
- `mod1(i+1, 624)` в twist при i=624 читает УЖЕ ОБНОВЛЁННЫЙ mt[1] —
  это соответствует референсу; но проверка `idx>=624` съедает последний
  элемент блока (см. §2).
- Дефект Коннеса на конечной open-решётке НЕ ноль (boundary-spoiled);
  золотое значение 0.35912715909696663 — детерминированный якорь.
- Byers–Yang/поток строки формулируются в модели `:dirac`; модель
  `:monumental` (гладкая калибровка) НЕ инвариантна к q→q+1.
- Монументальная фаза применяется ТОЛЬКО к вертикальным связям;
  горизонтальные несут чистую Ландау-фазу 2πα·iy.
- На торе фаза вихря/Ландау берётся с НЕразвёрнутой координатой
  (iy+1, а не 1) — магнитная трансляция.

## 8. Stack-слой: второй эталон и ярусы provenance (v1.1)

Помимо ядра (§1, 133/133) эталонизирован **stack-слой** — вычислительная
поверхность девяти программ стека (`AB_Cloud_Monumental_v6_3[_D].jl`,
`RH_Sweep_Pro[_D].jl`, `RH_Unified[_D/_v5].jl`, `hp_audit_standal_one/
hp_audit_standalone.jl`):

- **Эталон** — `ports/golden/abcloud_golden_stack.json` (27 секций),
  генераторы `gen_golden_stack.jl` + `gen_hp_battery.jl` (чекпоинт
  smoke-батареи). RNG — тот же классический MT19937 через глобальную
  подмену `MersenneTwister` (+ канонический `randperm`: Fisher–Yates,
  `j = 1 + floor(u·i)`, один res53-double на шаг).
- **Проверка**: `python3 -m`-уровень — `abcloud.stack_golden.
  run_stack_selftest()`; C++/Rust/Go — подкоманда `stack`.

### 8.3. Задокументированные ловушки stack-слоя

1. **Рационализатор α** (`AB_Cloud_Monumental_v6_3.jl::_rational_alpha(::Float64)`):
   точная бинарная дробь float почти всегда имеет знаменатель > 50, поэтому
   решает эвклидов цикл `qq = 1..50`: 1/3 → (1,2), 2/3 → (1,1), 1/π → (1,2).
   Число вихрей и размер Bloch-решётки следуют из этой пары.
2. **Монументальный билдер** — 0-базные координаты, тор-обёртка по ОБОИМ
   направлениям, x-major порядок сайтов (site = x·L + y), per-site расход
   `rand()` на disorder ε (даже при σ=0).
3. **mobius_function** не переворачивает знак самого простого (цикл от 2p) —
   bug-for-bug; µ(2) = +1 в эталоне.
4. **unfold_zeta_zeros** фитируется по ПЕРВЫМ 100 нулям
   (`unfold_zeta_zeros(zeta_zeros(100))`).
5. **Δ₃ (RH-стек)**: окна с `i_end − i_start < 3` пропускаются (guard
   Julia); v5-метрики используют polynomial-unfold (не local).
6. **mid-спектра**: `e[div(n,2)]` в 1-базной индексации Julia → 0-базной
   `e[n//2 − 1]`; аналогично `chirality_index` и `bott` E_fermi.
7. **chiral_winding** — целочисленное winding по 60 ИЗОЛИРОВАНным LAPACK-
   решениям: фазовый скачок между соседними сэмплами добавляет/убирает 2π
   оборот → якорь является provenance конкретной LAPACK-сборки.
8. **Julia-квирк monkey-patching**: повторное `function rep_begin!(...)`
   на том же имени ПЕРЕЗАПИСЫВАЕТ метод того же generic-объекта — трюк
   «сохранить оригинал в const и вызвать его» даёт бесконечную рекурсию.
   Захват вердиктов батареи — через `HPMeridian.ALL_STATES`.
