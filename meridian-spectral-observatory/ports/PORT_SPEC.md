# PORT_SPEC.md — Cross-Language Parity Specification

Спецификация паритета для многоязычных портов сюиты
meridian-spectral-observatory. Любой новый порт обязан удовлетворять
этому документу и проходить `selftest` со счётом 199/199
(133 базовых проверки + 66 векторного яруса §8).

---

## 1. Контракт паритета

1. **Эталон** — `ports/golden/abcloud_golden.json`, сгенерированный
   `gen_golden.jl` из НЕмодифицированных оригиналов. Эталон —
   единственный источник истины; никакие «известные правильные
   значения» из документации не являются контрактом.
2. **Проверка** — `selftest` порта пересчитывает все секции эталона
   (кроме `meta`/`grids`) и сравнивает с допусками §3. Счёт 199/199
   обязателен (базовый ярус 133 — исторический минимум).
3. **Ключи** секций формируются строкой `name` в формате Julia
   `string(Float64)` — кратчайшее round-trip представление с точкой:
   `1.0 → "1.0"`, `0.05 → "0.05"`, `10.0 → "10.0"` (НЕ `"1"`, НЕ
   `"1e+01"`). Несовпадение формата ключа = FAIL.

## 2. RNG: классический MT19937 (обязателен)

Julia `Random.MersenneTwister` — это dSFMT и **не** совместим между
языками. Все порты и генератор эталонов обязаны использовать
**классический MT19937** со следующей спецификацией (совпадает с
референсной C-реализацией mt19937ar и с CPython `random.random()`):

- init: `mt[0] = seed; mt[i] = 1812433253·(mt[i−1] ⊕ (mt[i−1] >> 30)) + i (mod 2³²)`;
- блок: 624 чисел, twist `y = (mt[k]&0x80000000)|(mt[k+1 mod 624]&0x7fffffff)`,
  `mt[k] = mt[(k+397) mod 624] ⊕ (y>>1) ⊕ mag01[y&1]`, `mag01 = {0, 0x9908b0df}`;
- temper: `y ⊕= y>>11; y ⊕= (y<<7)&0x9d2c5680; y ⊕= (y<<15)&0xefc60000; y ⊕= y>>18`;
- double: `((a>>5)·2²⁶ + (b>>6)) / 2⁵³`, где a, b — последовательные uint32.
- **Критично**: блок выдает ВСЕ 624 числа (init-состояние «пустое»);
  ошибка «623 числа на блок» даёт расхождение потоков с 624-го вызова
  (реальный баг, найденный при отладке — см. worklog).

## 4. Сетки из эталона (НЕ строить локально)

Секции `grids.omega` (726 значений, H1-полоса) и `grids.tvals`
(30 значений, K(t)) читаются портом из JSON. Локальное построение
`0.3:0.004:3.2` зависит от семантики colon/arange языка и запрещено
в паритет-пути.

## 5. Обязательные алгоритмические детали (легко сломать)

1. `ks_asymptotic_pvalue`: ветка λ<0.6 — комплементарная форма
   `1 − √(2π)/λ·Σ exp(−((2k−1)²π²)/(8λ²))`, иначе тета-ряд `2Σ(−1)^{k−1}exp(−2k²λ²)`;
   брейки по term<1e-18, клампы [0,1].
2. `anderson_darling_stat`: клампы F в [1e-300, 1−1e-16]; формула через
   пары (i, n+1−i).
3. `chi2_gue_test`: s_max = min(max, 4.0); переполнение → последняя
   корзина; корзины с exp<5 пропускаются; df = max(count−1, 1).
4. `gue_cdf` — ВСЕГДА через таблицу (32768 точек, линейная интерполяция,
   точная формула при s≥5).
5. `compute_bN`: смещение `offset` — часть контракта (Test 10).
6. K(t): окно развёртки `max(3, round(0.05·n))`; сглаживание j∈[w, len−w−1],
   пропуск t<0.5; БЕЗ вычитания 1 (позиции абсолютные).
7. plaquette_flux: CCW-сумма `angle(−H[b,a])`; сравнение потоков — только
   через flux_circdist.
8. Jacobi-солвер: `s = t·c` (НОРМИРОВАННОЕ вращение; s=t даёт неверный
   спектр!), фаза φ=arg(a_pq), τ=(a_qq−a_pp)/(2|a_pq|),
   t = sign(τ)/(|τ|+√(1+τ²)).
9. eigend-ключи: `eigend3` = МАКСИМУМ спектра (Julia `ev[n−k]`), NOT
   `ev[n−3]`.
10. Σ²/Δ₃: один поток MT19937(777) общий для S2→D3 в порядке
    L=5,10,20,50,100 затем 5,10,20,50.

## 6. Порядок портирования нового языка

1. Скопировать Rust-порт как образец (std-only, без зависимостей).
2. Реализовать MT19937 по §2; проверить первые 5 doubles против
   Python: 0.15266373490132201, 0.30235660970752121, 0.062036414714562005,
   0.45986034160896883, 0.83525338443762831 (seed 777) И n=700:
   481389588 (uint32) — это ловит баг «623 числа».
3. Скалярные функции → GOF → решётка → selftest.
4. Гнать `selftest` до 133/133.
5. Прогнать `suite` — сравнить вердикты с Python (19 PASS / 0 FAIL).

## 7. Известные ловушки (найдены при отладке)

- Julia `string(1.0)` = "1.0", `%.17g` = "1" — ключи эталона в стиле Julia.
- `mod1(i+1, 624)` в twist при i=624 читает УЖЕ ОБНОВЛЁННЫЙ mt[1] —
  это соответствует референсу; но проверка `idx>=624` съедает последний
  элемент блока (см. §2).
- Дефект Коннеса на конечной open-решётке НЕ ноль (boundary-spoiled);
  золотое значение 0.35912715909696663 — детерминированный якорь.
- Byers–Yang/поток строки формулируются в модели `:dirac`; модель
  `:monumental` (гладкая калибровка) НЕ инвариантна к q→q+1.
- Монументальная фаза применяется ТОЛЬКО к вертикальным связям;
  горизонтальные несут чистую Ландау-фазу 2πα·iy.
- На торе фаза вихря/Ландау берётся с НЕразвёрнутой координатой
  (iy+1, а не 1) — магнитная трансляция.
- **Ловушка раскладки §8 (vne/TEE)**: Julia индексирует узлы как
  `i = x·L + y` (y быстрый), а Python-порт строит строки как
  `i = y·L + x` (x быстрый) — раскладки взаимно транспонированы.
  Разрез подсистемы Julia `psi_mat[1:L_A, :]` — полоса **y < L_A** —
  в Python-раскладке (iy, ix) есть полоса **x < L_A** (первые L_A
  СТОЛБЦОВ reshape(L,L)). Ошибка оси незаметна на x↔y-симметричных
  состояниях и выдаёт себя только на несимметричных
  (L8_open_a025_2vort, состояние c2: расхождение до 12% по S).
  Все собственные значения (ham_*, eig*) транспонированию нечувствительны —
  ловушка проявляется ТОЛЬКО в векторном ярусе.

## 8. numpy/LAPACK-ярус: векторные наблюдаемые (rh_metrics, mon_entropy/topology)

Ярус, который в Python-порте опирается на `numpy.linalg` (eigh/eigvals,
lstsq), а в C++/Rust/Go обязан работать на собственном Якоби-солвере.
Секции эталона: `mon_entropy`, `topo_tee`, `rh_metrics`. Чек-лист
портирования — обязателен к исполнению в полном объёме:

1. **Солвер с векторами.** Расширение циклического Якоби §5.8:
   накапливать `U ← U·G` (та же последовательность вращений, что и для
   значений). Возвращает диагональ `H` и `U`; сортировка значений —
   восходящая, столбцы `U` переупорядочиваются ВМЕСТЕ со значениями.
2. **Фазовая инвариантность.** Все наблюдаемые яруса зависят только от
   модулей компонент вектора (‖ψ_A‖², Σᵢ|ψᵢ|⁴): фаза/знак собственного
   вектора НЕ фиксируется. Это легально ТОЛЬКО потому, что якорные
   спектры невырождены.
3. **Запрет вырождений.** Генератор эталона проверяет min gap > 1e-9
   среди восьми центральных собственных значений каждого сценария и
   падает с ошибкой при нарушении. В вырожденном подпространстве базис
   LAPACK и Якоби НЕ совпадает → энтропия/IPR несравнимы. Поэтому
   α=0.5-сценарии (точные хиральные AIII-дуплеты, проба gap ~4e-16) и
   торус L10 (магнитные вырождения q=2) в векторный ярус НЕ входят;
   якоря — три open-сценария W=0 (пробованные зазоры):
   `L8_open_a025_2vort` (2.9e-2), `L10_open_a03_clean` (6.0e-3),
   `L12_open_a03_clean` (9.6e-3).
4. **round(Int, ·) = half-even** (Julia `round(Int, x)`). Критично:
   L=10, f=0.25 → 2.5 → **2** (не 3!). Реализации: C++ `std::nearbyint`
   при FE_TONEAREST; Rust `f64::round_ties_even`; Go `math.RoundToEven`;
   Python `round()`. Запрещены `llround`/`floor(x+0.5)`.
5. **von_neumann_entropy 1:1** (оригинал V77): reshape ψ в L×L
   КОЛОНКО-МАЖОР (Julia-порядок: столбец c = ψ[(c−1)L+1 : cL]);
   подсистема A — первые L_A = max(1, min(L−1, round_half_even(L·f)))
   строк × ВСЕ L столбцов, n_A = L·L_A; C_A = ψ_A ψ_A† (ранг 1 —
   НЕ упрощать: полный Якоби-прогон C_A обязателен); eigs = кламп
   ВСЕХ собственных значений в [1e-12, 1−1e-12]; энтропия натуральная:
   S = −Σ λ·ln λ + (1−λ)·ln(1−λ). Вклад «нулевых» ветков
   1e-12·ln(1e-12)·(n_A−1) ≈ −3.8e-9 детерминирован клампом.
6. **topological_entanglement_entropy 1:1** (V90): eigen(H) с векторами;
   e_centered = eigs − mean(eigs); central_idx = sortperm(|e_centered|)
   [1:3] (значения различимы — стабильность сортировки не важна, но
   сортировать пары (значение, индекс)); 53 fraction из оригинала
   [0.25, 0.35, 0.5, 0.65, 0.75, 0.76…0.99, 1, 2…9, 10, 12, …, 64];
   S_mean/S_std по трём центральным состояниям (std — sample, n−1);
   boundaries = L·f (БЕЗ клампа — клампится только L_A); фит
   `[boundaries ones] \ S_mean` — **Householder QR 2 колонки** (не
   нормальные уравнения: cond ~5e4 → нормальные уравнения теряют
   ~5 знаков и ломают допуск 1e-6); slope_alpha = coeffs[1],
   gamma_top = −coeffs[2].
7. **IPR** центральных состояний: Σᵢ(|ψᵢ|²)² — тот же eigen-прогон,
   ключи `*_ipr_c{0,1,2}`.
8. **rh_metrics** (значения, вырождения безопасны): central band по
   §5-протоколу `central_band_eigs(ev, 0.6)`; спейсинги полосы →
   **локально-средняя развёртка `rh_band_ks`** (окно
   `max(5, round_half_even(0.05·n_c))`, спейсинг `central[i+1]−central[i]`
   делится на локальное среднее в окне ±win, фильтр `0<s<10`, при >10
   точках — `ks_test`) — **НЕ** `normalized_spacings`: тот кернел —
   ζ-специфичная форма фон Мангольдта и для решёточной полосы неприменим;
   `mean_adjacent_spacing_ratio` → r; ключи `D`, `p`, `r`, `n_cb`.
9. **Допуски** — §3 строки mon_entropy / topo_tee / rh_metrics.
   Источник разброса: |λ_Якоби − λ_LAPACK| ~ 1e-12 ⇒ ‖ψ_A‖² ~ 1e-12,
   дальше плавно через энтропию/фит.
10. **Тест-ловушка**: самопроверка half-even — round_half_even(2.5)=2,
    round_half_even(3.5)=4; L=10·f=0.35 → 3.4999999999999996 → 3
    (0.35 не представимо точно, произведение в Float64 одинаково во
    всех языках — полагаться на IEEE, не на десятичную интуицию).
