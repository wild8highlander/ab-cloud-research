# `FINAL_REPORT/reports/` — Raw Per-Test Report Copies (38 × 4 Formats)
> The untouched per-test report files (Markdown, HTML, PDF, DOCX for each of the 38 tests) as the run wrote them — the provenance layer behind the master report's inline embeddings.

_Location: [unpacked/](../../../../README.md) › [run_data/](../../../README.md) › [run_20260914_234626/](../../README.md) › [FINAL_REPORT/](../README.md) › [reports/](README.md)_

For every one of the 38 tests, the reference run wrote a four-format report set (`report.md`, `report.html`, `report.pdf`, `report.docx`). The **reading copies** live in each test's own folder (`../../test_XX_<slug>/`), and this directory preserves the **raw shipped copies** exactly as the run produced them, one subfolder per test, so that the FINAL_REPORT's inline embeddings can always be audited against untouched originals.

Everything in this tree is duplicated by design. For reading, navigate to the test's own folder (its README there includes the verification statement, the verdicts, the log excerpt and the console capture); for provenance checks — byte-comparing the FINAL_REPORT's embedded content against the run's raw output, or re-computing checksums against the original freeze's register — use the copies here. Each subfolder carries its own README with that test's report-file inventory and sizes; the published filenames carry the `AFR` location code (e.g. `report_AFR04.md` for Test 4's raw Markdown copy), and the complete mapping to the original names is in [`../../../FILE_INDEX.md`](../../../FILE_INDEX.md).
