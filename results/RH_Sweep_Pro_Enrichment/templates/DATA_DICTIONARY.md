# Словарь данных RH-Sweep PRO (Data Dictionary)

> Строка `metrics.csv` = одна конфигурация AB-облака. Метрики считаются на
> центральных 30 % спектра с блочным усреднением B = 250 (binning).
> Синхронизировано с RH_Sweep_Pro_D.jl v1.0 · редакция 1.0 (2026-10-16).

## 1. Идентификация конфигурации

| Колонка | Тип | Смысл |
|:--|:--|:--|
| `label` | String | человеко-читаемая метка точки: `α=…` (sweep) или `final_α=…` (финальный прогон) |
| `L` | Int | сторона решётки; гамильтониан имеет размер L²×L² |
| `alpha` | Float64 | магнитный поток Ааронова–Бома на чётную ось решётки |
| `W` | Float64 | амплитуда он-сайт беспорядка W·U(−1,1) |
| `sigma` | Float64 | радиус вихревого дефекта в потенциале σ·exp(−r/(0.5Lσ))/r |
| `n_eigs` | Int | суммарное число центральных собственных значений (все seed) |

## 2. Сигнальная метрика ⟨r⟩

| Колонка | Смысл | Эталон GUE |
|:--|:--|:--|
| `r_mean` | среднее отношение соседних интервалов min(δᵢ,δᵢ₊₁)/max(δᵢ,δᵢ₊₁) | 0.5996 |
| `r_std` | стандартное отклонение ⟨r⟩ между реализациями (значимость) | → 0 |
| `r_class` | ближайший класс RMT по ⟨r⟩: GUE / GOE / GSE / Poisson | GUE |
| `d_GUE` | |⟨r⟩ − 0.5996| · тест: < 0.05 | 0 |
| `d_GOE` | |⟨r⟩ − 0.5359| | — |
| `d_GSE` | |⟨r⟩ − 0.6762| | — |
| `d_Poisson` | |⟨r⟩ − 0.3863| | — |

## 3. Парная корреляция R₂(s) и форм-фактор K(t)

| Колонка | Смысл | Критерий |
|:--|:--|:--|
| `R2_rms_GUE` | RMS отклонения R₂(s) от теории GUE 1−(sin πs/πs)² | → 0 |
| `R2_rms_Poisson` | RMS отклонения R₂(s) от константы 1 | → ∞ |
| `R2_rms_zeta` | RMS отклонения R₂(s) от кривой ζ-нулей | → 0 |
| `R2_match_GUE` | R₂ ближе к GUE, чем к Пуассону | TRUE |
| `K_corr_GUE` | корреляция K(t) с GUE-ramp+plateau (τ→1) | → +1 |
| `K_corr_zeta` | корреляция K(t) с эмпирическим K(ζ) | > 0.8 |
| `K_match_GUE` | corr(ζ)>0.8 И corr(GUE)>−0.5 (см. отчёт, дефект D-6) | TRUE |
| `K_match_zeta` | corr(ζ)>0.7 | TRUE |

## 4. Статистики уровней

| Колонка | Смысл | Критерий GUE |
|:--|:--|:--|
| `Sigma2_rms_GUE` | RMS Σ²(L) против (ln L)/π² + 1/(8π²) | → 0 |
| `Sigma2_rms_Poisson` | RMS Σ²(L) против L | → ∞ |
| `Sigma2_match_GUE` | ближе к GUE, чем к Пуассону | TRUE |
| `Delta3_rms_GUE` | RMS Δ₃(L) против (ln L)/π² + 0.007 | < 0.5 |
| `p_rms_GUE` | RMS p(s) против Вигнера-GUE (32/π²)s²e^(−4s²/π) | < 0.2 |
| `p_mean` | среднее гистограммы p(s) (нормировочной контроль) | ~0.25 |

## 5. Новые метрики (внутренние сравнительные)

> ⚠️ Эти величины корректны для сравнения прогонов между собой; прямое
> сравнение с литературными числами требует пересчёта при тех же бинах.

| Колонка | Смысл | Цель GUE |
|:--|:--|:--|
| `chi2_wigner` | χ²-статистика гистограммы p(s) против Вигнера (30 бинов) | < 0.5 |
| `chi2_pvalue` | exp(−χ²/2) — монотонная мера согласия, НЕ настоящее p-value (дефект D-5) | → 1 |
| `brody_beta` | параметр Броуди по log-log регрессии первых 5 бинов | ≈ 2.0 |
| `spectral_compressibility` | mean Σ²(L)/L при L = 9–10 (прокси 1−lim Δ₃/L, дефект D-7) | < 0.3 |
| `gap_prob_E1` | доля интервалов s ≥ 1 (вероятность щели) | ≈ 0.171 |
| `r_tilde_mean` | ⟨r̃⟩ = ⟨sᵢ/(sᵢ+sᵢ₊₁)⟩ (модифицированное отношение) | ≈ 0.3602 |
| `level_number_dev` | ⟨δ²ₙ⟩ — отклонение номера уровня от линейной подгонки | → 0 |
| `symmetry_parameter` | S = ⟨r⟩/(1−⟨r⟩) — информационная, в тестах не считается | ≈ 1.496 |

## 6. Итоговые поля

| Колонка | Смысл |
|:--|:--|
| `composite_score` | агрегат 0–100 из 12 компонент: K corr(GUE) 15 · K corr(ζ) 10 · ⟨r⟩ 10 · R₂ 10 · Σ² 10 · Δ₃ 10 · p(s) 10 · χ² 5 · β 5 · χ 5 · E(s=1) 5 · ⟨r̃⟩ 5 |
| `tests_passed` | пройдено тестов из 11 (6 классических + 5 новых; S не считается) |
| `tests_total` | всегда 11 |
