**Конфигурация:** α = 1/π ≈ 0.31831 · W = 2.0 · σ = 0.5 · L = 64 (матрица 4096×4096) · 5 сидов · окно 0.3

\* пол GUE — RMS между двумя независимыми GUE-реализациями того же объёма (`data/gue_control.json`): значение прогона **ниже пола**, т.е. AB-облако статистически неотличимо от настоящей GUE-выборки.

**Единственный непройденный тест:** E(s=1) = 0.521 против 0.171 для GUE — плотность p(s) даёт меньше «щелей» размера ≥ 1, чем сюрмиз Вигнера (β Броуди = 1.72 < 2). Это не ошибка кода, а свойство данной конфигурации: отталкивание уровней чуть слабее эталонного на хвосте распределения. Кандидат на следующий sweep: тонкая сетка по W ∈ [1.8…2.4].

## Что добавлено в этой папке (после-прогонное обогащение)

1. **Кривые (curves/, 7 CSV)** — R₂(s), K(t), Σ²(L), Δ₃(L), p(s)+E(s), гистограмма r и кривая суперпозиции ⟨r⟩(m) — пересчитаны из сырых данных по методологии кода (poly-unfold deg5, блоки 250).
2. **GUE-контроль (data/gue_control.json)** — пол статистической погрешности методом Т34 (расщепление GUE-симуляции пополам).
3. **Фигуры (figures/, 7 новых PNG + баннер)** и **5 GIF-анимаций (animations/)**.
4. **Починенный код (scripts/RH_Sweep_Pro_D_FIXED.jl, v1.1)** — реализованы отсутствовавшие `sweep_parameter` / `save_sweep_results` / `sweep_all_parameters` (раньше — UndefVarError), настоящее χ²-выживание, единая цель ⟨r̃⟩, усилен K-критерий, МНК-оценка сжимаемости, per-seed файлы, GIF-генераторы. Полный список: `scripts/CHANGES_FIXED.md`.
5. **Научная находка:** `csv/ab_eigs.txt` сохранён **глобально отсортированным**, т.е. файл — объединение 5 сид-спектров. Суперпозиция m=5 смещает ⟨r⟩ от per-seed 0.5999 (прогон) к 0.3913 (файл) — проверено симуляцией (см. `figures/fig02_superposition.png` и `animations/anim01_superposition_m.gif`). Патч P10 в FIXED-коде сохраняет per-seed файлы и устраняет эффект.

## Быстрый старт

```bash
# 1) Пересчёт кривых/фигур не требуется — всё уже здесь.
# 2) Воспроизведение прогона (починенный код):
julia -e 'include("scripts/RH_Sweep_Pro_D_FIXED.jl"); cfg = preset_auto(5000); run(cfg)'
#    GIF-анимации заодно: ENV["RH_ANIM"]="1"
# 3) Sweep-движок (теперь работает):
julia -e 'include("scripts/RH_Sweep_Pro_D_FIXED.jl"); sweep_combined_quick()'
julia -e 'include("scripts/RH_Sweep_Pro_D_FIXED.jl"); sweep_top10_pro()'
julia -e 'include("scripts/RH_Sweep_Pro_D_FIXED.jl"); sweep_all_parameters()'
# 4) Обогащение любого прогона:
julia -e 'include("scripts/RH_Results_Enricher.jl"); enrich_run("путь/к/прогону")'
```
