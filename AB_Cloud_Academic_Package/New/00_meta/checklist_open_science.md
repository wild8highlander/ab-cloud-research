# Open-science checklist

- [x] **Open code** (MIT): six-language CLI, tests, web lab sources.
- [x] **Open data** (ODbL): curated datasets with checksums and datacard.
- [x] **Open text** (CC BY 4.0): monograph MD sources; PDF/DOCX builds.
- [x] **Open methodology**: config.yaml exposes every hypothesis parameter;
  pre-registered windows in the same file.
- [x] **Open peer-review posture**: reviewer notes and the response-to-
  reviewers discipline of the sources carry over (templates included).
- [x] **Reproducibility artefacts**: reproduce.sh, Dockerfile, binder/, colab/.
- [x] **arXiv-ready draft**: paper/ holds the short-paper LaTeX.
- [x] **No paywalled dependencies**: all fonts, tools and libraries are open.
- [x] **Multilingual access**: 8-language README surface; glossary in 3.
