# The numbered structure

| Section | Role |
|---|---|
| 00_meta | manifest, provenance, checklists, glossary, taxonomy, governance |
| 01_monographs | the unified monograph (RU/EN full + 5 abstracts) |
| 02_data | the funnel: raw copies, schemas, dictionaries, checksums |
| 03_figures | the consolidated figure set + bilingual captions |
| 04_reports | the report suite (all audiences) |
| 05_logs | run logs, provenance, metrics.json |
| 06_code | the six-language CLI + shared contract |
| 07_web_lab | the offline interactive laboratory |
| 08_assets | avatars, badges, logos, themes |
| 09_tests | the integrity suite (merge gate) |
| 10_notebooks | exploration/analysis/report/tutorial |

The package is **versionless by design** — editorial history in `CHANGELOG.md`.
