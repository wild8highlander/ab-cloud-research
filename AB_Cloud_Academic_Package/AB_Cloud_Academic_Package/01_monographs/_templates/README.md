# Monograph templates

Templates for extending or translating the unified monograph.

| File | Use |
|---|---|
| `chapter_template.md` | a new chapter (statement–certificate–boundary structure) |
| `figure_template.md` | a figure with bilingual caption + alt text |
| `table_template.md` | a numbers table (every value names its campaign) |
| `reference_template.bib` | bibliography entries |

## Translation workflow (for a new full volume)

1. Copy `../en/monograph_en.md` as the working base.
2. Translate chapter by chapter; keep all numbers verbatim (they are the
   scientific record — see the review protocol).
3. Keep the `does_not_prove` statements and the RH boundary verbatim in
   meaning; the LICENSE §3 honesty clause applies to translations.
4. Mark the volume `translation — not the record of record` until a second
   speaker of the language has reviewed it (governance protocol §4).
