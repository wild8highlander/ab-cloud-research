# Taxonomy

- [`ontology.ttl`](ontology.ttl) — a small RDF/OWL ontology of the programme's
  concepts (levels → campaigns → theorems → verdicts) using `skos:`.
- [`concepts.csv`](concepts.csv) — the flat view (machine-friendly).
- `ontology.owl` — reserved for a full OWL-DL axiomatisation (open item).
