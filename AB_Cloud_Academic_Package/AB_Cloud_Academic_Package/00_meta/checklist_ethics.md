- [x] **No overclaiming.** The V13 obligation machine states RH `certified` (0 assumptions); a theorem claim requires O11 ∀n;
  every verdict file carries a `does_not_prove` field; the unified README
  repeats the boundary in three places.
- [x] **Negative results published** as first-class citizens (locality wall
  T18, null zone T8, failed correspondences V1/V3/V6/V16, KAK-outside-class).
- [x] **Error transparency.** The sources' errata are preserved in the
  registry notes (e.g. the B_HADAMARD ln(2π)→ln(4π) fix; the Σγ² 4π³
  multiplier correction; the blind γ₁₂ erratum E17).
- [x] **No fabricated data.** Every number in the package names its campaign
  and source verdict file; the honesty layer forbids re-typing numbers.
- [x] **No human/animal subjects** — pure mathematics and computation.
- [x] **No funding, no conflicts of interest** (see monograph declarations).
- [x] **Attribution.** The three source laboratories are credited as the
  canonical homes of the code and run data; this package consolidates.
- [x] **Honest translation.** The five language abstracts are marked as
  abstracts, not full volumes; the RU/EN full volumes are the scientific
  record.
