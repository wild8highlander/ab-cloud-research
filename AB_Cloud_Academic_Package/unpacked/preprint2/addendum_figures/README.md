# `preprint2/addendum_figures/` — Addendum Figures (Academic Essence Edition)
> The same two English-labelled addendum figures as in preprint/, shipped with the Academic Essence preprint.

_Location: [unpacked/](../../README.md) › [preprint2/](../README.md) › [addendum_figures/](README.md)_

These are the two September 2026 addendum figures embedded in the Academic Essence preprint — byte-identical to the copies in `../../preprint/addendum_figures/` (documented there in full): **`fig_add1_w_sweep_en.png`**, the disorder sweep showing the confrontation distance flat across W, and **`fig_add2_mixture_en.png`**, the effective GUE+Poisson decomposition whose post-fit residual 0.0241 matches the GUE-matrix calibration floor 0.0242.

The package deliberately ships one copy per preprint so that each LaTeX project is self-contained and compiles without cross-folder references; on GitHub the duplicated basenames are disambiguated by location code (`_P1A` for the monograph preprint copy, `_P2A` for this one — see [`../../FILE_INDEX.md`](../../FILE_INDEX.md)). The original-resolution figures, together with the mixture-fit JSON summaries behind them, live in the run data at `../../run_data/run_20260917_080329_m2/analysis_addendum/`.
