# `preprint/addendum_figures/` — Figures of the September 2026 Addendum
> The two English-labelled addendum figures embedded in the monograph preprint: the disorder sweep and the mixture decomposition.

_Location: [unpacked/](../../README.md) › [preprint/](../README.md) › [addendum_figures/](README.md)_

The September 2026 addendum (chapters Add.1–Add.8 in the monograph, the Academic Essence and both preprints) documents the independent re-examination of the Test 34 confrontation. Two figures summarise its quantitative core, and this folder ships the exact PNG files the preprint's LaTeX source embeds.

**`fig_add1_w_sweep_en.png`** — the disorder sweep (Add.3). Across increasing disorder amplitude W the measured confrontation distance stays essentially flat, demonstrating that the residual D ≈ 0.10 of the reference protocol is not a disorder artifact. The panel plots the per-realization and pooled KS distances against the pre-registered D < 0.10 effect-size line.

**`fig_add2_mixture_en.png`** — the effective GUE+Poisson mixture decomposition (Add.5). The panel shows the measured spacing distribution resolved into a GUE component with a Poisson admixture of weight w* ≈ 0.25–0.28; after the decomposition the residual (0.0241 pooled) coincides with the independent GUE-matrix-versus-ζ calibration floor (0.0242), closing the addendum's argument that the confrontation's entire residual is accounted for.

Both figures were produced from the run `../run_data/run_20260917_080329_m2/` (its `analysis_addendum/` folder carries the mixture-fit JSON summaries and the same two figures in their original resolution). Identical copies ship with the Academic Essence preprint in `../../preprint2/addendum_figures/`; the published filenames differ by location code (`_P1A` here, `_P2A` there) precisely because the two preprints ship byte-identical images.
