# 🧭 Guides — the submission wizards, visible without unzipping

Each sealed zip on this shelf carries its own step-by-step guide inside.
This folder holds **render-friendly copies** of those guides so that a
reviewer, an editor — or the Author a month later — can read the exact
wizard instructions straight on GitHub, without downloading a single byte.

> [!IMPORTANT]
> **Provenance rule.** The copy **inside the zip is the source of truth**;
> these visible copies were re-extracted on **2026-10-18** from the
> 2026-10-18 re-seal and are stamped with a provenance note at the top. The
> zips themselves are pinned by [`../SHA256SUMS.txt`](../SHA256SUMS.txt) — if
> a zip is ever re-sealed again, the mirrored guide must be re-extracted in
> the same commit, and [`../CHANGELOG.md`](../CHANGELOG.md) must say so.

> [!TIP]
> The guides also live outside the zips' scope of authority: they describe
> *how to upload*, not *what the science says*. For the manuscript's

> (G1–G5, C17, algebraic_map — synced 2026-10-16), start from the
