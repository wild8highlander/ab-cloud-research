# 🎨 Journal Shelf Assets

The banner and emblem art of the **Journal submission shelf** README. The banner
is a hand-written SVG with SMIL animation (no build step, no external fonts,
view-source friendly); the emblem is an exported raster logo; the README embeds
both with plain `<img>` tags.

| File | What it is |
|---|---|
| `banner.svg` | animated SVG — three sealed submission packages travelling along dashed flight paths toward three journal houses (NSR JINR, SciPost Physics, arXiv) under a pulsing zeta node |
| `logo_journal_ai.png` | raster emblem — three sealed envelopes with golden wax seals flying toward three classical column buildings |

> [!NOTE]
> Art only — no data, no code, no results. The READMEs that consume these files
> live one level up: [`../README.md`](../README.md). The parent package keeps
> its own separate art family in
> [`../../AB_Cloud_Academic_Package/assets/`](../../AB_Cloud_Academic_Package/assets/).
