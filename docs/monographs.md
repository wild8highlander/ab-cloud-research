# Monographs — overview

The monograph layer is the narrative record of the AB-Cloud research programme:
a multi-edition book that develops the phase-resonator construction, the
spectral evidence and the formal layer, with every figure traceable to a run
artifact in [`results/`](https://github.com/wild8highlander/ab-cloud-research/tree/main/results).

## What ships with the monographs

- **Figures** — the full plate set rendered at 600 dpi, stored per language
  under the edition folders and referenced by the verification claims.
- **Documents** — the book ships in docx, pdf, html, pptx and tex formats.
- **Preprints** — tex + pdf preprint versions under
  [`projects/monographs/en/text/preprint/`](https://github.com/wild8highlander/ab-cloud-research/tree/main/projects/monographs/en/text/preprint).
