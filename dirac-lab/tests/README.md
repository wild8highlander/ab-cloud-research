## What is inside each folder

| File | Content |
|---|---|
| `README.md` | visual test page: badges, mermaid pipeline, key numbers, full ledger, figure gallery |
| `monograph.tex` | focused LaTeX monograph (theory → method → results → discussion → reproducibility) |
| `monograph.pdf` | the same, compiled with Tectonic (4–5 pages) |
| `results.json` | machine-readable ledger (the README table is generated from it) |
| `D*.csv` | the canonical data table written by the test itself |
| `figures/` | canonical figure + companion panels, all **600 dpi** |

## How a folder is produced

Two in-repo tools (see [`tools/`](../tools/README.md)) regenerate every
folder from the validated code — the same machinery that produced the
committed state:

```bash
python3 tools/run_into_folder.py core     # canonical artifacts → tests/D01…D08
python3 tools/make_extra_figures.py       # companion panels → tests/*/figures/
```

The LaTeX monographs compile standalone:

```bash
cd tests/D07_zeta_decoration && tectonic monograph.tex    # or: make monograph D=D7
```

## Reading order

- **Fast pass** — the ledger table above, then any folder's `README.md`.
- **Physics pass** — per-test monographs in test order; they are written to
  be read independently but share the canonical numbers.
- **Deep dive** — the full research monograph
  ([EN](../monographs/tex/Dirac_Lab_Monograph_EN.pdf) ·
  [RU](../monographs/tex/Dirac_Lab_Monograph_RU.pdf) ·
  DOCX editions in [monographs/](../monographs/)), which weaves all 14
  tests into one argument.
