# data/ — ζ-zero dataset

`zeta_zeros_2000.txt` — the first 2000 imaginary parts t_k of the non-trivial zeros
ρ_k = 1/2 + i·t_k of the Riemann zeta function, ascending, 9 decimal places.

**Provenance.** Andrew Odlyzko's official table [`zeros6`](https://www-users.cse.umn.edu/~odlyzko/zeta_tables/zeros6),
carried through the parent repository's verification data pipeline (`verification/data/zeta_zeros_50000.txt`,
13661 zeros) into this truncated copy used by tests D7–D8 for the deterministic ζ→vortex coding.

Format: one zero per line; lines starting with `#` are comments (attribution header).
See also parent data up to 2,001,052 zeros: `../verification/data/` of the root repository.

## Band files for tests D12–D14 (v1.3)

| File | Content | Used by |
|---|---|---|
| `zeta_zeros_2000.txt` | first 2000 zeros, t ∈ [14.13, 2515.3] | D7–D14 coding & main form-factor band |
| `zeta_zeros_low_600.txt` | first 600 zeros, t ∈ [14.13, 939.0] — the low-height control band | D14 low band |
| `zeta_zeros_high_2000.txt` | zeros № 137 300–139 299 of the Odlyzko 2M table, t ∈ [99500.3, 100798.6] — a genuinely large-height band (local mean spacing 0.6499 vs RvM 0.6498) | D14 Odlyzko band |

Provenance of the band files: subsets of the parent repository's
`verification/data/zeta_zeros_2M_odlyzko.txt` (Andrew Odlyzko's official `zeros6` table,
2,001,052 zeros). All three files carry attribution headers and are regenerated by
caching scripts; the tests read them read-only.
