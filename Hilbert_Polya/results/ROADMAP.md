# Roadmap — после 1.0.0

Направления упорядочены по ожидаемому эффекту на главный измеренный
разрыв (Г2: 9–10 порядков в ранговой метрике, ≈1 в тепловой).

## R1. Нелокальные следовые конструкции (приоритет 1)

Урок T6: след нулевого оператора несёт Λ(n)/√n точно. Кандидаты за
пределами решётки: операторы с ядром Q(a) как спектральной плотностью,
Berret–Keating H = xp с правильной константой, коннеровский полулокальный
множитель. Целевая метрика — та же тройка проекций (r_H7, ψ, r_EF) с
позитивным контролем PC0.

## R2. Сшивка статистической и кодировочной ветвей

C6 показывает: поток знает простые точно (1.35e-14), лестница знает нули
(0.972), спектр не знает ничего (универсальность). Нужен объект, несущий
И поток, И нули: кандидаты — фазовые кодировки с условием ко-локации
(T4) в качестве жёсткого ограничения на конфигурацию затвора.

## R3. Теоретико-числовое объяснение T9

Нулевые моды α = 1/3 на торах L ≡ 0 (mod 4) (18 при L=12, 42 при L=24) —
проверяемая лаборатория: дираковский индекс vs арифметика L ≡ 0 (mod 3).
Может дать первый мост «арифметика → спектр» внутри решётки.

## R4. Продление верифицированной полосы

Адаптивный шаг Тьюринга C2 масштабируется до T ≈ 5000 при тех же порогах;
мост арифметик гарантирует строгость. Ожидание: N = 649 → ~4200.

## R5. Инженерия пакета

- прогон portable-source двойников (Go/Rust/Julia) на машинах с тулчейнами;
- расширение IVP слепыми кампаниями C3-подобных семей;
- вынесение файла нулей в опциональный датапак с контрольными хэшами.
