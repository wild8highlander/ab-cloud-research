# Roadmap — после 2.0.0

Направления упорядочены по ожидаемому эффекту на главный измеренный
разрыв (Г2: 9–10 порядков в ранговой метрике, ≈0.5–1 в тепловой).

## Выполнено в v2.0 (было R1–R5)

- ✅ R1 → C9/T11: нелокальный примитив существует (r_H7 = 1, r_EF = PC0);
  разрыв — стена локальности, не следа.
- ✅ R2 → C10/T12: жёсткая ко-локация по построению (4.4e-16); спектр слеп
  (классификация T12: только β·ln p негэджева в оверлей-канале).
- ✅ R3 → C11/T13: арифметический мост найден: N₀ = 2L−6·[L≡0 mod 12],
  индекс −2 — первый «арифметика → спектр» внутри решётки.
- ✅ R4 → C12/T14: полоса продлена до T = 5000 (N = 4520 = N_strip).
- ✅ R5 → C13/T15 + IVP11–18: 5 слепых семейств, протокол расширен до 18.

## Новые направления (v3)

- **N1. Индексная формула T13 с доказательством**: объяснить
  N₀ = 2L − 6·[L ≡ 0 (mod 12)] через Кэлер–Дирака индекс и спектральную
  последовательность тора с флаксом (1/3) — кандидаты: Атия–Зингер
  на решётке, модулярность кривой x³ ≡ ... mod L.
- **N2. Полуцелые характеры**: перенести C15 на характеры mod 3, 11, 13
  и на модулярные формы (уровень 11): универсален ли T17 дальше?
- **N3. Сшивка через индекс**: T13 даёт арифметику в спектре решётки —
  попробовать Kähler–Dirac оператор как «затвор»: несёт ли он вес простых
  в тепловом следе (r_EF) при α = 1/3?
- **N4. Продление полосы до T = 50000**: та же машина (mp.siegelz,
  сегменты) — оценка ~40× времени C12.
- **N5. Квантовый отклик на индекс**: C16-протокол для α=1/3 решёток —
  видит ли MI фазовый переход N₀ > 0 ⇔ L ≡ 0 (mod 6)?
- **N6. Challenge**: живой приём подач (challenge/CHALLENGE.md).
