# Roadmap — после 2.0.0

Направления упорядочены по ожидаемому эффекту на главный измеренный
вердикт (Г2 = ДА на уровне самих нулей ζ: D_nn 0.0079; ранговая/тепловая ветви — консервативные пределы).

## Выполнено в v2.0 (было R1–R5)

- ✅ R1 → C9/T11: нелокальный примитив существует (r_H7 = 1, r_EF = PC0);
  разрыв — стена локальности, не следа.
- ✅ R2 → C10/T12: жёсткая ко-локация по построению (4.4e-16); спектр слеп
  (классификация T12: только β·ln p негэджева в оверлей-канале).
- ✅ R3 → C11/T13: арифметический мост найден: N₀ = 2L−6·[L≡0 mod 12],
  индекс −2 — первый «арифметика → спектр» внутри решётки.
- ✅ R4 → C12/T14: полоса продлена до T = 5000 (N = 4520 = N_strip).
- ✅ R5 → C13/T15 + IVP11–18: 5 слепых семейств, протокол расширен до 18.

## Новые направления (v3)

- **N1. Индексная формула T13 с доказательством**: объяснить
  N₀ = 2L − 6·[L ≡ 0 (mod 12)] через Кэлер–Дирака индекс и спектральную
  последовательность тора с флаксом (1/3) — кандидаты: Атия–Зингер
  на решётке, модулярность кривой x³ ≡ ... mod L.
- **N2. Полуцелые характеры**: перенести C15 на характеры mod 3, 11, 13
  и на модулярные формы (уровень 11): универсален ли T17 дальше?
- **N3. Сшивка через индекс**: T13 даёт арифметику в спектре решётки —
  попробовать Kähler–Dirac оператор как «затвор»: несёт ли он вес простых
  в тепловом следе (r_EF) при α = 1/3?
- **N4. Продление полосы до T = 50000**: та же машина (mp.siegelz,
  сегменты) — оценка ~40× времени C12.
- **N5. Квантовый отклик на индекс**: C16-протокол для α=1/3 решёток —
  видит ли MI фазовый переход N₀ > 0 ⇔ L ≡ 0 (mod 6)?
- **N6. Challenge**: живой приём подач (challenge/CHALLENGE.md).
- **N7. Независимость H от нулей** (аудит 13.10.2026; уточнено 13.10.2026,
  algebraic_map; **фаза B выполнена 13.10.2026 — кампания C17**,
  `campaigns/run_c17_blind_phaseB.py`): строить кандидатов только из
  арифметики и предсказывать нули вслепую. Источники: LCM-ядро,
  кэлер-дирак при α = 1/3, дискретизация следовой формулы (окно явной
  формулы как H), фазовый класс β·ln p. Протокол: фаза A — построение
  без zetazero; фаза B — слепой прогон (пиксельная фиксация); фаза C —
  сверка. **C17 (фаза B, замкнутая плотность явной формулы)**:
  ρ̃(t) = d̄(t) − (1/π)Σ_{k,p}(ln p)p^{−k/2}e^{−σ²k²(ln p)²/2}cos(k t ln p)
  только из простых и θ; моментная ветвь упирается в стенку Стилтьеса
  (h_n < 0 при n* = 7 при точности моментов 10⁻¹⁹ — замыкание фильма
  атомно-специфично), численная ветвь (дискретизация ρ̃ + Ланцош-24 +
  канва Q22 + sha256 до чтения нулей) даёт: предзарегистрированная
  метрика — NEGATIVE (окно N₀ режет горб γ₁, утечка съедает узлы);
  исследовательская ступень C17b (края окон — минимумы самой ρ̃, число
  узлов = round ∫ρ̃): счёт предсказан слепо с точностью ±0.1 (20.90→21,
  24.96→25), узлы воспроизводят квадратауру истинной гребёнки до
  RMS 0.044–0.055 при null 0.47–3.25 (z_GUE до 11.4, r ≥ 0.987),
  весь остаток до нулей (0.46–0.54) — инструментальный зазор самой
  24-точечной квадратауры. Критерии приёма при подтверждении без
  изменений (r_H7 ≥ 0.7 по challenge-протоколу; 3σ против GUE;
  воспроизведение вторым портом). Следующий шаг: подтверждающий прогон
  C17c с valley-правилом в предрегистрации и независимым портом.
  Отрицательные результаты опубликованы в отчёте C17.
