# 🕶️ C17 — blind phase B

> **The most recent pre-committed campaign: parameters frozen before the run, figures regenerated by script.**

Phase B of the blind series: the experimental parameters were committed to `data/` *before* the computations, and every figure in `figures/` is reproducible from the single script [`make_figures_c17.py`](make_figures_c17.py) — no manual plotting steps, so the figures cannot drift from the data. The `report/` directory holds the assembled campaign report and its HTML cover.

Read this folder together with the sibling blind campaigns C13–C16: the point of the series is that each phase's analysis rules were fixed in advance, which is what lets a WARN verdict here be read as an honest negative rather than a tuning artefact.
