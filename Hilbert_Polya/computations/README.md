# 🧮 `computations` — campaigns C1–C17

> **The campaign ledger of the Bridge: seventeen numbered experiments, each frozen with its data, figures and monograph.**

Every numbered subdirectory is one *campaign* of the Hilbert–Pólya programme — a pre-registered question, an experiment, and a frozen artifact set (`data/`, `figures/`, and for most campaigns a bilingual `monograph_ru.*` / `monograph_en.*` report pair — PDF + DOCX). The numbering is chronological and load-bearing: the main README, the theorems volume and the audit reports all refer to results by campaign number ("C14 found the anomaly…", "the C17 blind protocol…"), so this folder is the citation target for the whole package.

Campaigns C13–C17 form the *blind* series: parameters were committed to files before the runs, and the analysis scripts were not re-tuned afterwards — the protocol answers the classic post-hoc objection to numerical studies. Start with [`C1_identity_function/`](C1_identity_function/README.md) for the founding identity, or jump to [`C17_blind_phaseB/`](C17_blind_phaseB/) for the most recent blind phase.

Beyond the per-campaign sets: C7 ships the wave-packet animations `anim_wavepacket.gif` / `anim_wavepacket.mp4`, C10 the co-location animations `anim_coloc.gif` / `anim_coloc.mp4`, and C17 its single-source figure pipeline `make_figures_c17.py`.
