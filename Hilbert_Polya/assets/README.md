# 🎨 Hilbert_Polya Assets

The banner and avatar art of the **Hilbert-Polya monograph** README. Everything here is
hand-written SVG with SMIL animation (no build step, no external fonts,
view-source friendly) or exported raster logos; the READMEs embed it with
plain `<img>`/`<picture>` tags.

| File | What it is |
|---|---|
| `avatars/` | sub-folder: hp_agent_atlas.svg, hp_agent_lyra.svg, hp_agent_vera.svg, hp_cast_strip.svg, hp_hilbert.svg, hp_polya.svg, hp_riemann.svg |
| `illustrations/` | sub-folder: ill_closing_credits.png, ill_critical_line.png, ill_direct_input_error.png, ill_hero_shutters.png, ill_montage_bench.png, ill_pixel_encoding.png, ill_prime_flow.png, ill_shutter_wall.png, ill_spectrum_emerge.png, ill_stats_ladder.png, ill_trace_formula.png, ill_vortex_lattice.png |
