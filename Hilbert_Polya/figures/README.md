## What this folder is

This folder holds the **visual identity and the summary graphics** of the
series — the images that appear in READMEs and slides, as opposed to the
data figures (which live per-campaign in `computations/*/figures/` and at
600 dpi in `figures_hires/`). Every infographic here is a faithful
rendering of committed numbers: the scorecard of the H1–H5 verdicts, the
full bridge map, the trace formula, the handle space, the statistics
ladder — each in English and Russian, each in a light and a dark theme.

## Contents

```
logo/            hpb_logo_{light,dark}.{png,svg}
en/{light,dark}/ info_{scorecard,map,trace,handles,ladder}_en.png
ru/{light,dark}/ info_..._ru.png
```

Concretely:

- `logo/` — the Bridge logo in four files: `hpb_logo_light.png`,
  `hpb_logo_light.svg`, `hpb_logo_dark.png`, `hpb_logo_dark.svg` (the
  main README embeds the light PNG at the top of the repository page).
- `en/light/` and `en/dark/` — five English infographics each:
  `info_scorecard_en.png`, `info_map_en.png`, `info_trace_en.png`,
  `info_handles_en.png`, `info_ladder_en.png`.
- `ru/light/` and `ru/dark/` — the same five in Russian:
  `info_scorecard_ru.png`, `info_map_ru.png`, `info_trace_ru.png`,
  `info_handles_ru.png`, `info_ladder_ru.png`.
- `animations/` — the v2 motion graphics: `anim_coloc.gif`,
  `anim_coloc.mp4`, `anim_wavepacket.gif`, `anim_wavepacket.mp4` (the
  wave-packet transport of C7 and the co-location of C6, animated).

The five infographics, by subject: the **scorecard** renders the verdict
table H1–H5 (self-adjointness YES, spectral identity NO, GUE class YES,
Dirac dynamics YES, primes inside the operator NO); the **map** draws the
five-stage bridge with the three projections of the H2 gap; the **trace**
sheet summarizes the Guinand–Weil trace formula and Theorem T6; the
**handles** sheet is the guide to the reachable handle space (C3 protocol
plus the six C5 dimensions); the **ladder** shows the Poisson/GOE/GUE
statistics ladder of C8.

Infographics are rendered by Playwright+CSS at scale 3 (≈600 dpi).
Screen copies of the data figures of the campaigns are in
computations/*/figures/. The 600 dpi originals are in figures_hires/.

## How to use it

```bash
# regenerate the logo and the infographics from their sources
make logo
make infographics
# (the underlying scripts: python3 scripts/make_logo.py, scripts/make_infographics.py)
```

- For a talk or a slide deck: pick the language and theme you need —
  e.g. `en/dark/info_map_en.png` for a dark deck, `ru/light/info_scorecard_ru.png`
  for a printed Russian handout.
- For the repository page: the main README embeds the logo and the
  scorecard/map infographics directly from this folder.
- For publication-quality versions of the *data* figures (not these
  summaries), go to `figures_hires/` — the present folder is about
  identity and summary, not about the per-campaign plots.

## Conventions

- Two languages (`en/`, `ru/`) × two themes (`light/`, `dark/`), with
  identical naming inside: `info_<subject>_<lang>.png`.
- The SVG logo is the editable master; the PNGs are the drop-in rasters.
- Light theme is the print default; dark theme matches dark-mode READMEs
  and screens.
- Nothing here is hand-drawn: all images are generated by the scripts in
  `scripts/` and committed.
