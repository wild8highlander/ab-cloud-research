# figures/ — логотип и инфографики

```
logo/            hpb_logo_{light,dark}.{png,svg}
en/{light,dark}/ info_{scorecard,map,trace,handles,ladder}_en.png
ru/{light,dark}/ info_..._ru.png
```

Инфографики рендерятся Playwright+CSS в масштабе 3 (≈600 dpi).
Экранные копии рисунков данных кампаний — в computations/*/figures/.
600 dpi оригиналы — figures_hires/.
