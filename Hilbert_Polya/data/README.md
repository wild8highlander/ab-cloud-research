## Правила

1. Вердикты коммитятся; свежие пересчёты — опциональны.
2. Файл нулей ζ (2 001 052 высоты, Одлыжко) НЕ коммитится; путь — ZFILE.
3. Повторный прогон IVP обязан воспроизвести все вердикты бит-в-бит
   (детерминизм сидов: engine/hamiltonian.py).
4. JSON читаются кампаниями campaigns/run_c*.py — экскурсия без пересчёта.
