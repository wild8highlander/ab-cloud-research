# independent_verification/ — протокол IVP01–IVP10

Десять слепых проверок с порогами, известными до запуска.
- `PROTOCOL.md` — правила и реестр;
- `RUN_ALL.sh` — полный прогон (пересобирает C-двойник при наличии cc);
- `RESULTS.md` — закоммиченный вердикт последнего прогона.
Запуск: `make ivp`. Отличие от RESULTS.md — релиз-стоппер.
