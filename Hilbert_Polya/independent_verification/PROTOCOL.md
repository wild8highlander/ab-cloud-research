# Independent Verification Protocol (IVP) — Hilbert Polya Bridge 1.0.0

> Протокол независимой верификации: десять проверок, каждая из которых
> перечитывает **закоммиченные** вердикты, пересчитывает дешёвые инварианты
> и/или использует независимую реализацию (мультиязычные двойники).
> Ни одна проверка не требует файла нулей и не пересчитывает тяжёлые
> кампании — их вердикты закоммичены и защищены хэшами воспроизведения
> (см. data/README.md).

## Правила протокола

1. **Слепота к намерению.** Каждая проверка формулируется как утверждение
   с числовым порогом, известным ДО запуска; вердикт — бинарный.
2. **Позитивный контроль обязателен.** Проверка метода считается валидной,
   только если в серии есть проверка, где метод видит тождество
   (IVP06-PC0, IVP08-ко-локация и контроли кампаний C3/C4).
3. **Независимость.** IVP02/03 пересчитывают Γ-замыкания и Z_id своей
   реализацией (hpbridge.identity), а не читают кэш; IVP10 сверяет
   C-двойник с Python-реализацией.
4. **Коммит вердиктов.** RESULTS.md — закоммиченный протокол последнего
   прогона; повторный прогон обязан воспроизвести его бит-в-бит.

## Реестр проверок

| ID | Проверка | Порог | Метод |
|----|----------|-------|-------|
| IVP01 | целостность релиза (файлы) | все присутствуют | манифест |
| IVP02 | Γ-замыкания T1 (dps = 40) | ≤ 1e-35 | hpbridge.identity |
| IVP03 | вещественность Z_id (T2) | \|Im\| ≤ 1e-25 | hpbridge.identity |
| IVP04 | якоря аргументного принципа (T3) | 0/3/10/29/79/649 | data/c2 |
| IVP05 | счёт против N̄ Римана–Мангольдта | S(T) ≤ 1.8 | data/c2 |
| IVP06 | следовая формула T6 | \|ΔQ\| ≤ 1e-10, \|ΔK\| ≤ 5e-5 | data/c4 |
| IVP07 | GUE-класс расширенной семьи | ⟨r⟩ ∈ 0.5±0.03 | data/c5 |
| IVP08 | ко-локация потока (T4) | ≤ 1e-13 | data/c6 |
| IVP09 | ψ-лестница | corr ≥ 0.95 | data/c6 |
| IVP10 | мультиязычный двойник (C) | γ ≤ 1e-12; Λ совпадение | multilang/c |

## Запуск

```bash
bash independent_verification/RUN_ALL.sh
# или программно:
python3 -c "from hpbridge.validate import run_all; [print(r) for r in run_all()]"
```

## Коммит

По завершении прогона обновите `RESULTS.md` (таблица вердиктов + версия +
дата). Отличие результата от закоммиченного — релиз-стоппер.
