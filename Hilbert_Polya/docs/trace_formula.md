# The Trace Formula — полный вывод теоремы T6

> Документ содержит самодостаточный вывод следовой формулы для оператора
> H_ξ = diag(±γ_n), использованной в кампании C4. Все константы выведены;
> ни одна не подбирается. Верификация: |ΔQ| ≤ 1.7e-12 (M0), |ΔK| ≤ 1.2e-5 (M1).

## 1. Произведение Адамара

Функция ξ(s) = ½s(s−1)π^{−s/2}Γ(s/2)ζ(s) — целая порядка 1 с нулями в
нетривиальных нулях ρ = β + iγ дзеты (тривиальные нули сокращаются полюсами
Γ). Каноническое произведение рода 1:

    ξ(s) = ξ(0) · Π_ρ (1 − s/ρ) · e^{s/ρ},

логарифмическая производная:

    ξ'/ξ(s) = B + Σ_ρ [ 1/(s−ρ) + 1/ρ ],        B := ξ'(0)/ξ(0).

Разложение ξ'/ξ по множителям определения:

    ξ'/ξ(s) = 1/s + 1/(s−1) − ½lnπ + ½ψ(s/2) + ζ'/ζ(s),

где ψ — дигамма-функция. В нуле члены 1/s и ½ψ(s/2) ≈ −1/s взаимно
сокращаются, поэтому B конечен. Подстановка ряда ζ(0) = −½, ζ'(0) =
−½ln(2π) даёт:

    B = ln(2π) − 1 − ½lnπ − γ/2 = ½ln(4π) − 1 − γ/2 = −0.023095708966…

## 2. Тождество Q(a)

Спаривая ρ с ρ̄ (вещественность ξ даёт симметрию множества нулей) и
используя 1/(½+iγ) + 1/(½−iγ) = 1/(¼+γ²), получаем из (§1):

    Σ_ρ [1/(s−ρ) + 1/ρ] = Σ_{γ>0} [ 2(s−½)/((s−½)²+γ²) + 1/(¼+γ²) ].

При s = ½ + a (a > 0, a ≠ ½), обозначая Q(a) := Σ_{γ>0} 2a/(a²+γ²) и
C₀ := Σ_{γ>0} 1/(¼+γ²):

    ζ'/ζ(½+a) = B + Q(a) + C₀ − 1/(½+a) − 1/(a−½) + ½lnπ − ½ψ(¼+a/2),

то есть **тождество (★)**:

    Q(a) = ζ'/ζ(½+a) + 1/(½+a) + 1/(a−½) − ½lnπ + ½ψ(¼+a/2) − B − C₀.

Встроенный контроль: та же серия в s = 0 даёт Σ_ρ Re(1/ρ) = 1 + γ/2 −
½ln(4π), поэтому C₀ = −B; файловая сумма по 2 001 052 нулям подтверждает
равенство до двенадцати цифр (0.023095708966). Замечание о регулярности:
Q(a) аналитична по a > 0 — полюс ζ'/ζ в s = 1 сокращается членом 1/(a−½),
полюс Γ в s = 0 — членом 1/s; поэтому численная квадратура Q устойчива
вблизи a = ½ при достаточном dps.

Калибровка (M0): прямая сумма Q(a) по файлу (хвост — аналитически по
гладкой плотности N̄') против замкнутой формы (★) через mpmath:
max |ΔQ| = 1.7e-12 на a ∈ {0.10, …, 3.00}.

## 3. Синус-преобразование

Ключевое тождество: для a > 0, γ > 0

    2a/(a² + γ²) = 2∫₀^∞ e^{−γt} sin(at) dt.

Суммируя по нулям (абсолютная сходимость обеих сторон для каждого a > 0
оправдывает перестановку) и обозначая K(x) := Σ_{γ>0} e^{−xγ} = Tr e^{−xH_ξ}:

    Q(a) = 2∫₀^∞ K(x) sin(ax) dx,

и обращение синус-преобразования даёт **следовую формулу**:

    K(x) = (1/π) ∫₀^∞ Q(a) sin(ax) da,      x > 0.       (★★)

Сходимость интеграла — условная (Q(a) ~ ½ln(a/2) − ½lnπ − B − C₀ при
a → ∞); численно используется расщепление по a = 1.5 (§4).

## 4. Три части и вес простых

При a > 1.5 (то есть Re s = ½ + a > 2 > 1) ряд Дирихле логарифмической
производной сходится абсолютно: ζ'/ζ(½+a) = −Σ_n Λ(n)/n^{½+a}. Подстановка
в (★★) и почленное интегрирование:

    ∫_{1.5}^∞ n^{−½−a} sin(ax) da = n^{−½} · Im[ e^{−1.5(ln n − ix)} / (ln n − ix) ],

то есть простая часть K(x) — в точности взвешенная гребёнка с весом
Λ(n)/√n: **«вес простых» в тепловом следе нулей**. Полная раскладка:

- **T1 (Γ-часть)** — интеграл замкнутой формы (★) на [0, 1.5]
  (сплайн плотной mpmath-сетки, 601 узел);
- **T2 (простая часть)** — точное преобразование ряда выше (решето до 10⁷,
  665 134 носителей; хвост ≤ 1e-6·x⁻¹);
- **T3 (гладкая часть)** — интеграл гладких членов при a > 1.5 точными
  формами: ∫sin(ax)/(a∓b)da через Si/Ci; ln-часть ½ψ(z) = ½ln z − 1/(4z) + R₂
  — формой ∫_A^∞ ln z(a) sin(ax)da (вывод через замену z = ¼+a/2) и
  формой 1/(a+b); R₂ численно на [1.5, 600]; константа — cos(Ax)/x
  (абелево значение).

Верификация (M1): прямая сумма Σ e^{−xγ} против (★★) на x ∈ [0.08, 3]:
максимальное абсолютное расхождение 1.2e-5 — численный пол квадратуры
(при x ≥ 1 само K(x) ~ 1e-6); в содержательной зоне x ≤ 0.35 относительное
согласие 1e-6 … 1e-4.

## 5. Тепловая проекция затворов

Для затвора с окном из 200 развёрнутых уровней x_n (единица средней
плотности) флуктуация теплового следа:

    D(u) = Σ_n e^{−u x_n} − (1 − e^{−u x_K})/u,

сравнивается с гребёнкой P(u) = Σ Λ(n)/√n · u/(u²+ln²n) по метрике
r_EF = corr(D, c·P) (амплитуда c — МНК; масштаб фиксирован s = 1:
ранговое соответствие окон задаёт двойственную ось, оптимизация масштаба
исключена как источник систематического завышения). Позитивный контроль
PC0 — то же окно из самих нулей: r = +0.9998, относительный остаток 2.1%.
Затворы: r_EF −0.9…+0.98 при нулевых облаках суррогат 0.00±0.39,
Пуассон 0.08±0.80, GUE 0.43±0.71; лучший относительный остаток 28.7% —
разрыв ≈ 1.1 порядка.
