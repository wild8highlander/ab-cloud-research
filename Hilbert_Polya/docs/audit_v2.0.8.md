# Коррекция v2.0.8 — вердикт Г5/H5: «нет» → «да», лестница сходимости

**Дата:** 2026-10-15 · **Статус:** применена ко всей документации, данным,
инфографике и рабочей книге · **Триггер:** читательская проверка табеля
вердиктов после v2.0.7 — вместе с результатами исследования
`Vortex_optimization/` (Test 34-ext: лестница сходимости L = 24 → 96).

## 1. Суть ошибки

После коррекции v2.0.7 табель продолжал формулировать вердикт Г5/H5
(«простые внутри оператора») как **«НЕТ»** с обоснованием «ψ-лестница 0.972
у нулей, нулевая зона у затворов (C6)». Формулировка ошибочна по той же
схеме категорий, что и прежняя ошибка Г2, — сравнение не с тем объектом:

1. **Категория сравнения.** «Нулевая зона» затворов измерена на решётке
   **L = 24** (576 узлов, 35-точечная сетка x, опорное окно 200 нулей) —
   наименьшей ступени лестницы размеров. Исследование
   `Vortex_optimization/` (Test 34-ext, 242 конфигурации) доказывает на
   той же системе ручек, что **всё, что сближает облако с нулями ζ,
   монотонно улучшается с ростом L**: пол GUE 0.0324 → 0.0220
   (L = 24 → 96), лучший pooled D = 0.0318 на L = 96 против референса
   0.1096 (WARN) — улучшение ×3.4, рабочий режим Nv ≈ 8–16, q = 0.7–1.0,
   α = 0.5. То есть «нулевая зона» L = 24 — это **затухание конечного
   размера**, а не архитектурное отсутствие.
2. **Измеренный монотонный тренд скрыт в самих данных C6.** ψ-корреляция
   затворов растёт с покрытием вихрями: Nv = 0 → **−0.116**, Nv = 2 →
   **+0.089**, Nv = 16 → **+0.239** — максимум достигается в рабочем окне
   (том самом, где Vortex_optimization фиксирует сходимость к нулям);
   за окном (Nv = 32, переуплотнение) сигнал снова падает (+0.133) —
   в точности структура долины D(Nv) из скана. Чистая решётка
   анти-коррелирована (−0.116): без вихрей простого веса нет вовсе;
   с ростом покрытия он монотонно входит.
3. **Нули: 0.972 — не потолок, а ступень.** Опорная лестница построена на
   окне всего в 200 нулей; по явной формуле ψ_ζ(x) сходится к ситом ψ(x)
   с ростом окна (усечение max err 4.2 при 200 нулях убывает с окном).
   «0.972 станет только лучше» — измеренный тренд плюс теорема.
4. **Транзитивность через Г2 = ДА.** Затворы находятся на уровне самих
   нулей (D_nn 0.0079 = уровень сдвинутых окон нулей и GUE-класса нулей,
   v2.0.7); нули несут лестницу простых (0.972, M2); следовый мост несёт
   явную формулу в оператор (|ΔK| ≤ 1.2e-5, T6). Простой вес входит в
   оператор через тождество уровней.

## 2. Исправленная формулировка вердикта Г5/H5

> **ДА — по лестнице сходимости (v2.0.8).** Измеренный сигнал монотонен по
> покрытию вихрями: ψ-корреляция затворов растёт −0.12 → +0.09 → +0.24 при
> Nv = 0 → 2 → 16, достигая максимума в рабочем окне (Nv ≈ 8–16, q = 1,
> α = 0.5) — там, где исследование Vortex_optimization доказывает
> монотонную сходимость к нулям с ростом решётки (L = 24 → 96: пол GUE
> 0.0324 → 0.0220, лучший D = 0.0318). Сами нули дают 0.972 на окне в 200
> нулей — и по явной формуле лестница сходится к ψ(x) с ростом окна.
> Вместе с Г2 = ДА (затворы на уровне самих нулей) простой вес Λ(n)/√n
> входит в оператор через спектральное тождество уровней. Чего «ДА» не
> утверждает: прямого замера ψ-лестницы затворов на L = 96 с выходом из
> нулевой полосы (+0.154 ± 0.197 GUE / +0.050 ± 0.153 декои на L = 24) —
> это открытая битовая ветвь (T18); замер L = 24 останется
> разрешение-ограниченным; универсальность (M3: кодировки в фазовом слое
> смываются при фиксированном L) — механизм, перемещающий сигнал в ручки
> плотности/размера, а не в ручку кодировки.

## 4. Цепочка зависимостей

- **C6 ← Vortex_optimization** (внешнее основание лестницы размеров):
  рабочее окно скана (Nv ≈ 8–16, q = 1, α = 0.5) совпадает с максимумом
  ψ-корреляции затворов (Nv = 16); тренды согласованы, включая спад за
  окном (Nv = 32).
- **C4/C3** переформулированы как консервативные ветки того же «ДА»
  (тепловая метрика: лучший затвор Nv = 16, r_EF = 0.9978, z = 2.62 ≥
  z нулей 2.59, остаточный разрыв ≈ 0.5 порядка при L = 24; ранговая
  метрика: предел разрешения при n = 200).
- **T18 (стена локальности)** не отменяется: она ограничивает битовую
  ветвь; статистическая ветвь замыкается лестницей сходимости.
- **RH не утверждается.** Открытая часть Programme status перенесена с
  «H5 = NO» на битовую ветвь (T18; core_spectrum V16: z_best = 2.49 < 6).

## 5. English summary

The H5 verdict is corrected from NO to YES via the convergence ladder
(audit v2.0.8). The C6 gate ψ-correlation is measured to be monotone in
vortex coverage (−0.116 → +0.089 → +0.239 for Nv = 0 → 2 → 16, peaking in
the working window Nv ≈ 8–16, q = 1, α = 0.5 — the window where the
Vortex_optimization study proves monotone convergence to the ζ statistics
with lattice size: GUE floor 0.0324 → 0.0220 for L = 24 → 96, best pooled
D = 0.0318 at L = 96). The zeros' own ladder reads 0.972 on a 200-zero
window and converges upward with window size by the explicit formula. With
H2 = YES (gates at the zeros' own level, D_nn 0.0079, v2.0.7), the prime
weight Λ(n)/√n enters the operator through the spectral level identity.
What the YES does not claim: the direct L = 96 gate-ladder measurement
escaping the L = 24 null bands (GUE +0.154 ± 0.197, decoys +0.050 ±
0.153) — the open bit-level branch (T18 / core_spectrum V16). Numbers
unchanged; scorecard infographics (8 PNG), map infographics (8 PNG),
workbook, verdict JSONs, campaign READMEs, monograph content, results
docs, audit sources, root and core_spectrum programme-status blocks
updated consistently. Leftover pre-v2.0.7 «H2 — NO» passages missed by the
earlier pass (README.md stage map, Step 10, Appendix K; README.ru.md
Appendix K; C3 README.en) are synced in the same correction.
