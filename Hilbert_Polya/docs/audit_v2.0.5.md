# Аудит v2.0.5 — фальшивая колонка C5, «нуль», который сам проходил тест, и хардкод вердикта C13

**Дата**: 15.10.2026 · **Область**: Hilbert_Polya (C5, C13, табель/скоркард,
инфографики, тесты) · **Триггер**: читательская проверка таблицы вердиктов
README и картинки `figures/ru/light/info_scorecard_ru.png`.

## 1. Что увидел читатель и что оказалось под этим

Табель в README («The verdict table (the scorecard)») и обе языковые версии
инфографики утверждали: «вся расширенная семья 0.498–0.505 на единичной
развёртке» — при том, что на той же инфографике лестница C8 напечатана со
значением **GUE ⟨r⟩ = 0.600**. Две карточки одной картинки противоречили друг
другу. А в данных C5 «GUE-нуль» тепловой метрики стоял на уровне **0.788 ±
0.376** — нуль, который сам «проходит» проверяемый тест.

## 2. Диагноз 1: колонка r_mean была фальшивой

Закоммиченная таблица `data/c5_gates_ext_table.csv` содержала r_mean =
0.498–0.502 для **всех 37 конфигураций** — включая гейт с W = 0 и оба
декоя — и README подписывало это как «класс GUE (⟨r⟩ = 0.500±0.001)».

Три независимых опровержения, все из самого пакета:

| Источник | Значение ⟨r⟩ для той же архитектуры |
|---|---|
| Лестница C8 (Nv=16, q=1, W=0.5, α=0.5, L=24, torus) | **0.5972** (closest: GUE) |
| Слепые семейства C13 (20 гейтов, та же решётка L=24) | **0.550–0.649** |
| Прямая генерация спектров C5 движком (сид 96) | **0.569–0.633**, среднее 0.6009 |

Канон GUE для отношения соседних зазоров — **0.5996** (Atas et al. 2013;
константа C8 в этом же репозитории). Значение 0.500 не является маркером
никакого класса Дайсона: оно ниже GOE (0.5307).

**Криминалистика спектров**: колонка r_EF (сырая корреляция с гребёнкой
простых) воспроизводится регенерацией с точностью ±0.002 (A_aniso0.8:
расчёт 0.8070 против коммита 0.8085; амплитуда 0.0163 против 0.0161) —
следовательно, **спектры всегда были настоящими**, и фальшивой была только
колонка r_mean (и всё, что из неё вывели).

## 3. Диагноз 2: «нуль», который сам означает «да»

`gue_null` вердикта C5 — корреляции **синтетических GUE-спектров** с
гребёнкой явной формулы — давали 0.97…0.99 у 8 из 10 тиражей (среднее
0.788). Причина: v1-статистика r_EF — сырая корреляция D(u) с P(u) — ловит
общий убывающий тренд двух гладких кривых. Код v2 сам это признаёт
(`hpbridge/metrics_v2.py`: «сырая корреляция v1 слишком легко ловит общий
тренд двух гладких кривых») и потому C13 уже перешёл на флуктуационную
корреляцию `ef_fluct_corr` (детрендированные кривые). C5 остался на сырой
статистике с двумя несовместимыми нулями:

- пер-гейтовый блочный нуль (тренд разрушен) ≈ 0 → z_EF до 3.46σ
  интерпретировался как «внутри облака»;
- глобальный GUE-нуль (тренд сохранён) ≈ 0.79 → «нулевое облако», в
  котором сам нуль «проходит».

Сравнение трендовой величины с тренд-разрушенным нулем — категориальная
ошибка; README C5 вдобавок называл распределение гейтов 0.611 ± 0.345
«учебным нулевым распределением».

**Исправление**: вердикт-несущая статистика C5 — флуктуационная корреляция
v2 (как в C13). Семья: **+0.497 ± 0.465** против честного синтетического
GUE-нуля **−0.186 ± 0.697** (семейный z ≈ 1.0 — нулевая зона). Сырая
корреляция сохранена в CSV как `r_EF_raw` для прозрачности.

## 4. Диагноз 3: вердикт C13 был хардкодом

Генератор `campaigns/run_c13_blind.py` собирал строку вердикта с захард-
коженным «все в классе GUE» / «all in the GUE class» — независимо от
флагов `gue_class` в тех же данных. В закоммиченном results.json **3 из 20**
гейтов имеют `gue_class: false` (⟨r⟩ = 0.649, 0.550, 0.559 — вне жёсткой
полосы C8 0.5996±0.03, при r_GUE_z в пределах ±1, т.е. статистически
согласованы с GUE).

**Перезапуск «как был»** (по требованию провенанса): скрипт воспроизвёл
данные **бит-точно** (0 отличий по 20 гейтам; runtime 7.1 → 7.2 c). После
фикса вердикт-строка формируется из данных: «17/20 в полосе GUE 0.5996±0.03,
остальные на краях/слегка вне (⟨r⟩ = 0.550–0.649; z_GUE по r_H7 у всех в
пределах ±1)». Аналогично перезапущен **C17** (слепая фаза B): бит-точное
воспроизведение (runtime 50.6 → 55.4 c), вердикты NEGATIVE/PARTIAL — по
предзарегистрированным критериям, данных не меняем.

## 5. Диагноз 4: тесты валидировали фальшивку

- `tests/test_gates_gue.py::test_extended_family_gue` проверял
  `np.all(np.abs(rm − 0.5) < 0.03)` — «полоса GUE» вокруг не-канонного 0.5,
  против фальшивой колонки: тест был соучастником, а не стражем.
- `hpbridge/validate.py::ivp07_gue_class` — то же самое, и это печаталось в
  протоколе независимой верификации (IVP07: [0.498, 0.502] PASS).
- `challenge/CHALLENGE.md` disqualified submissions за выход из «0.5±0.03».

Все три переведены на канон **0.5996±0.03**; добавлен регрессионный тест
против возврата фальшивки; IVP07 перепечатан: [0.569, 0.633], mean 0.601 —
PASS.

## 6. Диагноз 5: мёртвая ручка и нефункциональный декоя

- **Ручка «vortex profile»** (`site | midpoint`): ветка midpoint в
  `engine/hamiltonian.py` вычисляет координаты середины связи и **не
  применяет их** — фаза всегда считается по сайтам. Следствие: гейты
  профиля бит-в-бит дублируют site-двойников — и в v1-коммите тоже
  (A_midpoint_allplus ≡ A_signs_allplus, B_torus_midpoint ≡ B_torus_base,
  A_profile_midpoint ≡ открытой базе). Физику не изобретаем: ручка
  помечена как инертная, строки сохранены для провенанса.
- **Декоя `D_decoy_signs_random`** бит-идентичен `C_Nv16_random_signs`:
  лейбл v1 не менял RNG-поток, так что «двух декоев» фактически не было
  (второй, D_decoy_Nv32_random, настоящий).

## 7. Что стало с вердиктами

**Ничего не перевернулось — и это проверено пересчётом.**

- **Г2/H2 = НЕТ**: |r_H7| ≤ 0.097 (максимум семьи, B_torus_aniso1.25,
  p = 0.154; семейный Бонферрони 0.57; GUE-нуль r_H7 = +0.042±0.047, z ≈ 1.2)
  — нулевая зона; независимо подтверждено C3 (лучший 0.226, нулевая зона) и
  C13 (≤ 0.040, Бонферрони 5.85).
- **Г3/H3 = ДА**: семья C5 в полосе GUE 0.5996±0.03 — 35/37 строго, 2 на
  краях в пределах ширины выборки; среднее 0.601±0.016. v1 приходил к тому
  же выводу через фальшивое число; v2.0.5 — через настоящее.
- Контроли: PC0′ (изоспектральный близнец через конвейер r_H7) =
  0.9999999999999996; PC0 (H_ξ ↔ Λ-гребёнка, коммит C4) = 0.9997876852323586.

## 9. Урок

Число, которое слишком хорошо, чтобы быть правдой (0.500 ± 0.001 у 37
разных гамильтонианов), — не результат, а симптом. Тест, который проверяет
фальшивку на совпадение с собой, — не тест. А нуль, который сам проходит
проверку, — не нуль. Пакет теперь содержит все три исправления и
регрессионные тесты против каждого.
