# T12. Классификация фазовых систем с ко-локацией (C10)

**Теорема T12.** Пусть Φ: {primes} → ℝ/2πℤ удовлетворяет
Φ_pq ≡ Φ_p + Φ_q (mod 2π) для всех пар. Тогда Φ продолжается до
гомоморфизма свободной абелевой группы ⟨p⟩ → ℝ/2πℤ и на образующих
произвольно; нормальная форма — Φ_p = 2π{β ln p}, β ∈ ℝ/ℤ.

**Следствие (калибровочная тривиальность).** Если Φ_p ∈ {0, π} (как для
Φ_p = π·χ₄(p)), то оверлей exp(iΦ) ∈ {±1} на y-связях снимается
преобразованием ψ → (−1)^y ψ: спектр не меняется. Измерение: спектры
β = 0 и χ4-кодировки совпадают до 8.4e-15. Негэджев класс один — β·ln p.

**Измерение (C10).** Оверлей привязан к сайту (простое ↔ номер сайта):
по-строчный оверлей — чистая калибровка (спектр не меняет, измерено).
Жёсткая ко-локация — 4.4e-16 при любом β. Спектр слеп: r_H7 ≤ 0.092,
GUE-класс неизменен — универсальность стирает даже тождество.
