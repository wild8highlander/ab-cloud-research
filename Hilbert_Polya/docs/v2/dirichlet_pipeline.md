# T17. Скрученная следовая формула для L-функций (C15)

**Вывод.** Λ_χ(s) = (q/π)^{(s+a)/2} Γ((s+a)/2) L(s,χ) — целая функция
первого порядка без полюсов (для непринципиального характера) с нулями
ρ = ½ ± iγ_χ. Произведение Адамара:

Λ'/Λ(s) = B_χ + Σ_{γ>0} [1/(s−ρ) + 1/(s−ρ̄) + 1/ρ + 1/ρ̄]

Спаривание пары даёт 2(s−½)/((s−½)²+γ²) + 1/(¼+γ²); на линии s = ½+a:

Q_χ(a) := Σ_{γ>0} 2a/(a²+γ²) = Λ'/Λ(½+a,χ) − B_χ − C₀^χ,
C₀^χ = Σ 1/(¼+γ²) = Λ'/Λ(½) − B_χ   (точное тождество; аналог B = −C₀)

Ядро 2a/(a²+γ²) = 2∫e^{−γx}sin(ax)dx даёт следовую формулу
K_χ(x) = Σ e^{−xγ_χ} = (1/π)∫₀^∞ Q_χ(a)sin(ax)da. При a > ½ ряд
L'/L(½+a,χ) = −Σχ(n)Λ(n)/n^{½+a} — СКРУТЕННЫЙ вес простых.

**Хвост.** Асимптотика ½ψ(z) = ½ln z − 1/(4z) − 1/(24z²), z = (a+b)/2,
b = a_char + ½: лог-часть — замкнутой формой (J_ln, валидирована
mp.quadosc), 1/(a+b) — через Si/Ci, R2 — численно, простая часть —
точным преобразованием ряда T2χ. Верификация: |ΔK| ≤ 9.6e-6 (χ₅),
6.1e-6 (χ₇) — точность v1 со скрученным весом.
