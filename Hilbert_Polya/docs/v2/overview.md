# v2.0 — «The Operator That Almost Exists»: обзор

Восемь кампаний (C9–C16) отвечают на дорожную карту v1 (R1–R5) и на семь
новых вопросов. Каждая кампания — папка в `computations/` с закоммиченным
вердиктом, рисунками 600 dpi (ru/en), README (EN) и вкладом в том T11–T18.

## Конвенции v2 (изменения против v1 — документировано)

1. **Нулевой эталон** — внутренний mpmath-кэш `data/zeros/` (800 нулей,
   воспроизводим побитово); внешних файлов данных нет вообще.
2. **Окна**: развёрнутое-с-развёрнутым (PC0' = изоспектральный близнец
   обязан давать r = 1.000; в v1 контролем была пара «файл против файла»).
3. **r_EF** — на детрендированных флуктуациях (сырая корреляция v1 ловит
   общий тренд двух гладких кривых; нулевой GUE широкий ±0.8 — фиксируется).
4. **Константа B** — исправлена (ln 2π → ln 4π); вердикты v1 не зависели
   от шиппед-литерала.
