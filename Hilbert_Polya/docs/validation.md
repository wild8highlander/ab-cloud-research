## 2. Машинные полы (где метрика «слепнет»)

- **Σ e^{−xγ} при x ≥ 1** — сам K(x) ~ 1e-6: относительная метрика теряет
  смысл, используется абсолютная (пол квадратуры 1.2e-5).
- **D_nn изоспектральных близнецов** — 1e-14: ниже лежит только шум
  диагонализации; разрывы меньше 1e-14 неразличимы.
- **Тепловая метрика 200-уровневого окна** — нулевое облако шириной
  ±0.39–0.80: r_EF различает только эффекты, дающие r за пределами облака
  (PC0: 0.9998); для затворов метрика консервативна.
- **Полиномиальная развёртка** — ломается при точных кратностях
  (W = 0 + midpoint); угол исключён из семейства C5 с пометкой.

## 3. Реестр контролей

Позитивные: PC1 близнецы (r = 1.000000000, D_nn = 2.7e-14), PC2 график↔файл
(r = 1.000000000000), PC0 окно нулей против Λ-гребёнки (r = +0.9998,
остаток 2.1%), встроенный контроль B = −C₀ (12 цифр), бит-в-бит
воспроизведение протокола C3 (1.45e-16), C-двойник (γ 5.9e-15, Λ 4.6e-11).

Негативные (нулевые): декуи 0.026±0.140 (r_H7) и +0.050±0.153 (ψ),
GUE 0.43±0.71 (r_EF), суррогат 0.00±0.39, Пуассон 0.08±0.80.

Правило допуска: отрицательный вердикт валиден только после положительного
контроля тем же методом (independent_verification/PROTOCOL.md, правило 2).

## 4. Воспроизводимость

Сиды: серия 96; вихри default_rng(96+3500); беспорядок default_rng(96+3501);
GUE default_rng(9000+k); Пуассон default_rng(7000+k); суррогаты
default_rng(1234+k). Все вердикты закоммичены (data/); кампании перечитывают
их за секунды; свежий пересчёт опционален и требует только файла нулей
(путь — ZFILE). Ровность версии: повторный прогон IVP обязан воспроизвести
RESULTS.md бит-в-бит.
