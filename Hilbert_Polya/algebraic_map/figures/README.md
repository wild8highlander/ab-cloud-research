# 🖼️ algebraic map — figures

> **Bilingual figure set of the algebraic-map study, generated from the frozen JSON.**

Two mirror directories — [`en/`](en/) and [`ru/`](ru/) — hold the same figures in English and Russian labelling. They are rendered from [`../data/amap_results.json`](../data/amap_results.json) and embedded by the documents in [`../report/`](../report/); if you regenerate the JSON, regenerate these from the campaign's figure script rather than editing the PNGs.
