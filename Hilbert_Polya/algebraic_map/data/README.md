# 🗂️ algebraic map — data

> **The machine-readable results of the algebraic-map study, one JSON snapshot.**

[`amap_results.json`](amap_results.json) is the frozen numeric payload of the algebraic-map campaign: every quantity the report and the figures render is serialized here, keyed and versioned, so the documents in [`../report/`](../report/) can be re-typeset or re-translated without touching a single number by hand.
