# hpbridge/ — python-пакет серии

| Модуль | Содержание |
|--------|------------|
| `constants.py` | протокольные константы (сид 96, окно 200, B Хадамара) |
| `identity.py` | Z_id, Γ-лестница, бисекция нулей, точки Грама (кампания C1) |
| `traceformula.py` | тождество Q(a), следовая формула, метрика r_EF, нули (C4, T6) |
| `primes.py` | Λ-сито, гребёнка P(u), ψ-лестница, поток Φ_p (C6) |
| `gates.py` | декларации семейств C3/C5 |
| `validate.py` | проверки IVP01–IVP10 |

Зависимости: numpy, scipy, mpmath. Файл нулей не нужен (используется
только свежими кампаниями по желанию).
