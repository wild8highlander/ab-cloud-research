# Contributing — Hilbert Polya Bridge

Пакет — авторское исследование с дисциплиной честности; внешние правки
принимаются как предложения (issues), а не прямые коммиты.

## Правила

1. **Статусы не завышаются.** Любое новое утверждение получает метку
   «доказано / измерено / конъектура» и порог ДО кода.
2. **Позитивный контроль обязателен.** Новый метод допускается к
   отрицательному вердикту только после демонстрации тождества там, где
   оно заведомо есть (см. independent_verification/PROTOCOL.md).
3. **Детерминизм.** Все сиды фиксированы (engine/hamiltonian.py);
   недетерминированные тесты не принимаются.
4. **Два языка.** Пользовательские тексты (README, монографии) — RU+EN.
5. **Зависимости.** Тяжёлые данные (файл нулей) не коммитятся; вердикты —
   коммитятся.

## Локальный цикл

```bash
make tests && make ivp && make tour
```
