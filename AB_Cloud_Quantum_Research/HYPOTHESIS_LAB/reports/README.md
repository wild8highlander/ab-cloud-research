# 📝 HYPOTHESIS_LAB — reports (output dir)

> **Where the lab writes assembled run reports — empty until you run it.**

This folder is the designated output directory of [`../ab_lab.py`](../ab_lab.py): each executed hypothesis produces a timestamped report here. It is intentionally empty in the repository — reports are *generated artifacts*, and only examples are versioned (see [`../examples/`](../examples/)). Run a hypothesis from the lab root and your first report will land in this folder.
