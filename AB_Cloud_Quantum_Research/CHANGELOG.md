# CHANGELOG — AB Cloud Quantum Research

Формат: Keep a Changelog 1.1.0 · версионирование: SemVer 2.0.0.

## [1.0.0] — 2026-10-11

Первый публичный релиз целостного исследования **AB Cloud Quantum
Research**: одна программа, одна архитектура, одна дисциплина честности —
от теории спектров до процессора, который *читает* математику и ничего
не хранит.

### Added — ядро исследования (`modules/core_spectrum`)
- Кампании **V01–V19**: слепой спектр, нуль-модели, скан критической
  прямой, паспорт оператора, решёточные пределы, арифметический след,
  самосопряжённость, спектральное тождество, блочная редукция, обратная
  задача, универсальность, машина обязательств **V13** (RH = `blocked`),
  сертификаты интервалов, критерий Ли, полный гамильтониан, критическая
  линия электрона, AB-процессор V18, сшивка ветвей **V19**
  (`ALGEBRAIC_CERTIFICATE`, θ-лестница 0.832, когерентность 0.9995).
- Теоремы **Th1–Th6** с сертификатами и монументальным томом теорем;
  формальные постановки Lean 4 / Coq / Agda / Isabelle, редукции A1–A6,
  `sorry`/`admit` не используются.
- Веб-лаборатория на **10 вкладок** (Z(t) Римана–Зигеля, конструктор
  затворов, след↔простые, критерий Ли, ψ-лестница, V16–V19, Теоремы).

### Added — процессор (`modules/processor_ab`)
- **V20 (P0)**: ISA AB-облаков, точный компилятор Givens-QR —
  1−F ≤ 4.4e−16 (4×4) и 6.7e−16 (8×8), глубина ≤ 7/29 затворов.
- Принцип «**читает, а не несёт**»: нули ζ воспроизводятся из 6 констант
  следовой формулы (12/12 точно; хранение = 0); нелокальность без
  сигналинга (CHSH S = 2.829112 ± 0.0014, защита 1000/1000).
- Веб-лаборатория на **8 вкладок** (ISA, компилятор V20, считывание
  нулей V23·E11/E17, нелокальность, дорожная карта, данные, Теоремы).

### Added — верификационная платформа (`modules/verifier_multilang`)
- Кампании **E01–E18** на Julia 1.10 (только стандартная библиотека):
  18/18 предрегистрированных вердиктов PASS.
- **E16**: независимый Риман–Зигель (Ариас де Рейна) — согласие с ЭМ
  ≤ 3.8e−15; **E17**: слепое чтение всех **649/649 + 639/639** нулей ζ
  до T=1000 двумя движками, кросс-движок 0.0 побитово, N(1000) = 649.0;
  **E18 (класс B)**: компилятор против 5 сильных baseline при равных
  ограничениях ISA — **×59 000** по времени при машинной точности.
- Кросс-языковая репликация Python ↔ Julia (BigFloat ↔ mpmath), все
  пины SHA256, отрицательные результаты публикуются.

### Added — слой теорем и формальности (верхний уровень)
- `theorems_lemmas/` — 6 папок теорем: 24 документа (RU/EN × PDF/DOCX)
  с внедрённой плиточной фигурой «4 измерения» + README каждой теоремы.
- `figures_tiled/` — 12 плиточных фигур 2×2 @600 dpi.
- `formal/` — мост к формальному слою, реестр редукций A1–A6.
- Мультиязычные реализации ядра: C / C++ / Rust / Go / JavaScript / Julia.

### Added — вспомогательные исследования и витрина
- `research/realtime_spinor_memory/` — вспомогательное исследование
  «машина без долговременной памяти»: три спинорные фазовые модели
  (θ = π/2, π/3, π/7), кампании ES1–ES5 с предрегистрированными
  порогами, теоремы TS1–TS3 (12 документов RU/EN × PDF/DOCX).
- `datasets/` — курируемые наборы данных (флагманские числа, хронология
  кампаний, первые нули ζ).
- `whitepaper/` — белый отчёт исследования (RU/EN, PDF).
- `timeline/` — хронологическая карта кампаний V01–V20 · E01–E18 (600 dpi).
- `atlas/` — атлас флагманских результатов (плитка 2×2, 600 dpi).
- `glossary/` — глоссарий терминов программы (RU/EN).
- `web_lab/` — портал исследования; веб-лаборатории всех модулей.

### Integrity
