# 🎬 VISUAL_ANIMATIONS — scripts

> **Visual-explainer layer of the Quantum package: generation scripts.**

The three Python generators that rebuild everything in gif/, html/ and svg/ from the package's data — edit here, regenerate there. Everything here is regenerated by [`../scripts/`](../scripts/) from the package's own data, and the folder-level entry point is [`../index.html`](../html/index.html) — the same tour set is reachable without cloning anything.
