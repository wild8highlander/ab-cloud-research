# 🎬 VISUAL_ANIMATIONS — svg

> **Visual-explainer layer of the Quantum package: SVG graphics.**

Vector graphics: the architecture flow, the critical line, the folder map, spinor rings (π/2 and π/3) and the pulsing logo. Everything here is regenerated by [`../scripts/`](../scripts/) from the package's own data, and the folder-level entry point is [`../index.html`](../html/index.html) — the same tour set is reachable without cloning anything.
