PIPELINE FLOW

Verdict → dataset → artifact → monograph: the reproducibility loop as an animation.
The data pipeline in one loop: verdict → dataset → artifact → monograph. The pulse is a number travelling with its provenance. Nothing moves backwards — that is what kills circularity.
Try it in the terminal
python3 scripts/make_datasets.py
python3 scripts/make_tiled_figures.py
python3 scripts/make_timeline.py
python3 scripts/validate_package.py
Why it matters
Every figure in every README is rebuildable from committed verdicts. Every number in the monographs traces to a dataset row. The chain is short and executable.
