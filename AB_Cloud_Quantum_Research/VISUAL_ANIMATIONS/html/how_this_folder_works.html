HOW THIS FOLDER WORKS

From campaigns to verdicts to artifacts to monographs — the evidence machine, animated.
The folder is a machine of evidence: campaigns produce verdicts, verdicts feed artifacts, artifacts feed monographs — and the license travels with everything.
1 · Research layers
modules/ (core · processor · verification) and research/realtime_spinor_memory/ run pre-registered campaigns; every threshold is fixed before the run; every verdict carries does_not_prove.
2 · Evidence layer
Verdict JSONs feed figures_tiled/, atlas/, timeline/, datasets/ — no figure is ever drawn by hand. scripts/validate_package.py re-checks 95+ consistencies.
3 · Publication layer
MONOGRAPH_ARCHIVE/ collects everything into RU/EN monographs (DOCX/PDF + LaTeX). HYPOTHESIS_LAB/ lets you test your own hypotheses under the same discipline.
4 · This folder
VISUAL_ANIMATIONS/ shows how it all works: GIFs for the READMEs, animated SVGs visible on GitHub, and these interactive HTML pages. The proprietary license is duplicated in every new folder.
