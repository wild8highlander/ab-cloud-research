# 🎬 VISUAL_ANIMATIONS — html

> **Visual-explainer layer of the Quantum package: interactive HTML pages.**

Self-contained interactive tours (open in any browser, no server): the architecture tour, the live-zeros page, the spinor lab, and `how_this_folder_works.html` — the folder's own doc. Everything here is regenerated by [`../scripts/`](../scripts/) from the package's own data, and the folder-level entry point is [`../index.html`](../html/index.html) — the same tour set is reachable without cloning anything.
