# formal/ — формальный слой пакета

Спецификации четырёх систем (портативные исходники, без внешних
зависимостей) + машина обязательств (`rpbridge/formaloblig.py`,
DAG — `obligations.json`).

## Базовый скелет

| Система | Файл | Содержание | Статус |
|---------|------|------------|--------|
| Lean 4 | lean/RPBasic.lean | эрмитовость-скелет: сумма |ν|² ≥ 0, вещественность λ, Tr(AB)=Tr(BA) | компиляция — O-lean |
| Coq | coq/RPBasic.v | те же факты в Gallina | компиляция — O-coq |

| Isabelle/HOL | isabelle/RPBasic.thy | те же факты в HOL | компиляция — O-isa |

## Формальные постановки теорем Th1–Th6 (v1.2.2)

| Система | Файл | Содержание | Статус |
|---------|------|------------|--------|
| Lean 4 | lean/RPTheorems.lean | постановки Th1–Th6; элементарные ядра доказаны (пропозициональная форма); редукции к именованным аксиомам A1–A6 | компиляция — O-lean; аксиомы A1–A6 → Mathlib — O-lean-mathlib |
| Coq | coq/RPTheorems.v | те же постановки в Gallina; доказательства — intros/exact; admit не используется | компиляция — O-coq |

Реестр редукций (одинаков в обоих файлах):

| Аксиома | Классический результат | Теорема |
|---------|------------------------|---------|
| A1 | спектральная теорема, эрмитовый случай | Th1 |
| A2 | одновременная диагонализация (конечная абелева группа) | Th5 |
| A2b | распадение ‖(H∓iI)ψ‖² = ‖Hψ‖² + ‖ψ‖² | Th2 |
| A3 | произведение Адамара для ξ, ζ′/ζ | Th6 |
| A4 | оценка Като–Темпл | Th3 |
| A5 | теорема Гершгорина | Th3 |
| A6 | абсолютная сходимость ряда Ли | Th4 |

Дисциплина: `sorry`/`admit` не используются нигде — глубокие шаги
оформлены как именованные аксиомы, так что формализация ЧЕСТНО показывает,
какая классика принимается на вход каждой теоремы. Ни одна аксиома не
является гипотезой RH; вывод RH остаётся заблокированным машиной
обязательств (V13): O08/O09/O11/O12 — assumed.

Ключевая функция слоя — не «доказать RH», а ГАРАНТИРОВАТЬ: вывод RH
заблокирован (7 блокеров), пока O08/O09/O11/O12 — assumed. Статус
компиляции каждого тулчейна — открытое обязательство (см.
results/ROADMAP.md, R5).
