# verification/claim_audit/ — аудит утверждений (кампания V14)

`claims/claim_vNN.json` — по файлу на каждую кампанию V1–V19. Схема
(Решение 14 плана): **statement** (точное утверждение), **premises**
(предпосылки), **code** (воспроизводимый код), **controls** (контроли
с passed-флагами), **does_not_prove** (что НЕ доказывает), **status**
(proven/measured/conjecture/refuted).

Проверки аудитора (`rpbridge/audit.py`): A1 — все пять частей непусты;
A2 — статус-гигиена (proven требует passed-контроля и не-следствий,
p-значения запрещены); A3 — покрытие всех вердиктов data/v*.json.

Статусы серии: **proven** — V4, V7, V8, V9, V12, V15; **measured** —
остальные тринадцать (V16–V19 включены с v1.1.0/v1.2.0). Регрессия
аудита — релиз-стоппер.
