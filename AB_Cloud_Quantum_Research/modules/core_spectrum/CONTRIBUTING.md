# CONTRIBUTING — AB Research Program

1. **Дисциплина статусов.** Каждое новое утверждение получает статус
   proven/measured/conjecture/refuted и claim-файл по схеме V14.
2. **Позитивный контроль обязателен.** Отрицательный вердикт без
   контроля, показывающего тождество там, где оно заведомо есть, не
   принимается.
3. **Вердикты коммитятся.** Свежий пересчёт обязан воспроизвести
   закоммиченные числа (test_repro); расхождение — релиз-стоппер.
4. **Предрегистрация метрик.** Статистики фиксируются до запусков;
   выбор постфактум запрещён.
5. **Новые кампании** — через `python3 scripts/new_experiment.py N
   "Название" slug` с последующим заполнением по шаблону V1–V15.

Сборка: `make all` (tour + tests + ivp). Релиз: `make zip`.
