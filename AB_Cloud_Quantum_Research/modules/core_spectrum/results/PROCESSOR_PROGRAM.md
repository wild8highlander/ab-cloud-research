# results/PROCESSOR_PROGRAM.md — программа «AB-процессор» (V20–V26)

**Назначение.** Перевести стратегическую заявку «AB-cloud — универсальный
процессор, считывающий любые алгебраические функции и числа» в измеримую,
фальсифицируемую спецификацию. Мы не декларируем статус процессора — мы
**исполняем процессорную спецификацию** на затворах AB-облака: ISA →
компилятор → память → ALU → интерфейс считывания → бенчмарки →
универсальность. Каждая кампания следует дисциплине честности пакета:
предрегистрированные пороги, позитивные контроли, вердикт и список
не-следствий (`does_not_prove`).

**База (уже доказано в пакете):**
- V18 — ISA {X, Y, Z, H, S, T} исполняется точно (fidelity 1−2e-16),
  зацепление C = 0.984, детерминированная AB-Pong с бит-в-бит реплеем;
- V16 — полная алгебраическая функция критической прямой живёт в облаке
  (позитивный контроль Z_id ↔ log|ζ|, r = 1.0);
- V19 — сшивка ветвей: гладкая Γ-фаза несёт одновременно статистику
  (θ-лестница 0.832) и кодировку нулей (когерентность 0.9995, z = 43.4);
  вердикт ALGEBRAIC_CERTIFICATE по контракту verhodge.

## V20 — Компилятор: произвольная унитарная логика на ISA

**Утверждение.** Любая унитарная матрица умеренного размера компилируется
в последовательность затворов ISA + фазовый затвор AB(φ) и исполняется
бит-в-бит воспроизводимо.

**Механизм.** KAK/Cartan-декомпозиция для 4×4; QR + двухкубитные блоки
для 8×8; фазы AB(φ) несут произвольные углы (это главное отличие от
фиксированных наборов — фазовое пространство континуально, но
дискретизируется алгебраическими числами, см. V23).

**Метрики и пороги (предрегистрированы):**
- M = 200 детерминированных унитарных 4×4 (сид 96): fidelity компиляции
  ≥ 1−1e-12, средняя глубина фиксируется в вердикте;
- M2 = 100 унитарных 8×8: fidelity ≥ 1−1e-10;
- контроли: тождество, перестановочные матрицы, DFT 4×4, CL(2).

**does_not_prove:** масштабируемую глубину при n → 10² кубитов;
физическую реализуемость.

## V21 — Память: запись, чтение, удержание, RAM

**Утверждение.** Узлы решётки образуют адресуемые регистры: запись —
приготовление состояния, чтение — измерение в вычислительном базисе,
удержание — сохранение под собственной эволюцией H_L.

**Механизм.** Регистр q = 6 узлов; все 2⁶ = 64 битовых паттерна
записываются, эволюционируют T = 10³ тактов под H_L и считываются.
RAM-слой: адресуемое чтение удалённой ячейки маршрутизацией SWAP —
измеряется латентность как функция расстояния d на решётке.

**Метрики и пороги:**
- RAM-тест: 64/64 паттерна считываются бит-в-бит (полный перебор, без
  выборки);
- персистентность: выживание вихревых (топологических) базисных
  состояний ≥ выживания тривиальных (контроль) при том же T;
- латентность: L(d) = a + b·d, порог b ≤ 6 затворов на узел.

**does_not_prove:** время когерентности физического носителя;
ошибко-коррекцию (отдельная кампания, если потребуется).

## V22 — ALU: арифметика на затворах AB

**Утверждение.** На ISA компилируется полная арифметика: сумматор,
умножение по модулю, сравнение, инкремент — и исполняется точно на всех
входах.

**Механизм.** Toffoli/CNOT-разложения (ripple-carry) поверх ISA V18.
Полный перебор входов делает демонстрацию детерминированной: это не
«тесты на примерах», а исчерпывающее доказательство таблицы истинности.

**Метрики и пороги:**
- 4-битный сумматор: 2⁸ = 256/256 сложений бит-в-бит;
- умножение mod 16: 256/256; компаратор: 256/256;
- глубина и число затворов на операцию фиксируются в вердикте.

**does_not_prove:** преимущество над классикой (не заявляется);
масштаб на 64 бита.

## V23 — Интерфейс считывания алгебраических функций (главный)

**Утверждение (формулировка пользователя, переведённая в протокол).**
Нули не «хранятся» в облаке — они **считываются** из полной алгебраической
функции критической прямой: функция загружается как фазовый код, и
спектральный отклик воспроизводит нули. Слой: функция → фазовая
кодировка → облако → интерферометрическое считывание.

**Механизм.**
1. *Библиотека алгебраических чисел* (16 значений, детерминированно):
   √2, √3, ∛2, φ = (1+√5)/2, 2cos(2π/7), корни x⁴−x²−1, … Каждое число
   загружается фазовым затвором AB(φ), считывается фазовой оценкой;
   невязка против точного алгебраического значения (mpmath, 40 dps):
   порог ≤ 1e-12 (double-слой), ≤ 1e-30 (mpmath-слой).
2. *Замкнутость интерфейса:* кодирование — гомоморфизм по композиции:
   считывание f∘g и f+g равно композиции/сумме считываний (порог 1e-12).
   Это и есть «читает любые формулы»: интерфейс замкнут относительно
   алгебраических операций.
3. *Слепое считывание нулей критической прямой:* полная алгебраическая
   функция Z_id загружается **без доступа к таблице нулей**; положение
   первых K нулей восстанавливается аргументной интерферометрией
   (как V19, слой B); сравнение с независимым вычислением ζ проводится
   после фиксации результата (blind-протокол V1). Порог: позиционная
   невязка ≤ 1e-8 при T = 300 (K = 138, как в V19).

**Контроль честности.** Именно слепой протокол отделяет «читает» от
«несёт»: если нули восстанавливаются из функции без обращения к таблице,
кодировка несёт функцию, а нули — её спектральный отклик. Позитивный
контроль V16 (r = 1.0) уже согласован с этой архитектурой.

**does_not_prove:** гипотезу Римана (все нули на прямой);
асимптотику на всех высотах (T → ∞).

## V24 — Нелокальность: AB-голономия как механизм «знания»

**Утверждение.** «Одна частица знает другую» в AB-облаке — это
топологическая (голономная) корреляция: фаза каждой частицы есть
функционал **общей глобальной** калибровочной конфигурации (вихревой
решётки), а не результат обмена сигналом. Обе частицы читают одно и то
же глобальное поле — поэтому корреляция мгновенна, топологически защищена
и не передаёт информацию.

**Механизм и тесты:**
1. *AB-интерферометр:* два пути вокруг вихря; сдвиг интерференции =
   фаза голономии. Порог: невязка против закона ≤ 1e-14.
2. *Топологическая защита:* 1000 случайных локальных возмущений
   потенциала в области без полей не меняют фазу (max dev ≤ 1e-12).
   Это ответ на «почему знает»: информация живёт в глобальной топологии,
   локальные помехи её не разрушают.
3. *Парная корреляция:* AB-связанная пара в унитарном состоянии типа
   |Φ⁺⟩; CHSH S ≥ 2.8 (симуляционный слой); одновременно
   демонстрируется [A_i, B_j] = 0 для разделённых наблюдаемых —
   **нет сверхсветового сигналинга** (алгебраическая проверка в коде).
4. *Контроль:* разрыв AB-линка (снятие вихря) уничтожает корреляцию —
   связь топологическая, не силовая.

**does_not_prove:** передачу информации быстрее света (напротив,
коммутативность показывает её отсутствие); квантовую гравитацию;
интерпретационные вопросы.

## V25 — Бенчмарки процессора

**Содержание.** Стандартная процессорная метрология, всё детерминировано
(фиксированные сиды): randomized benchmarking (средняя затворная fidelity
≥ 0.999), передача состояния вдоль строки из 8 узлов (fidelity ≥ 0.99),
латентность затвора в тактах, связность графа (диаметр, степень),
«квантовый объём» симуляционного слоя. Вердикт включает сравнительную
таблицу с литературными числами канонических архитектур (сверхпроводящие
кубиты, ионные ловушки) с явной пометкой «внешние, не пересчитываются
внутри пакета».

**does_not_prove:** физическую реализуемость чипа; конкуренцию с
инженерными платформами по энергопотреблению/времени такта.

## V26 — Вычислительная универсальность

**Утверждение.** Набор {H, T, AB(π/4)} универсален: порождает плотное
подмножество SU(2), а с Toffoli — SU(2ⁿ).

**Механизм.** Численное покрытие SU(2): для сетки целевых унитарных
подбирается схема ≤ 12 затворов с точностью 1e-8 (детерминированный
перебор сетки фаз); индуктивный шаг на n кубитов через двухкубитные
блоки V20. Формальное обязательство O-uni: формулировка плотности
переносится в Lean-слой (статус obligation, как остальные O-*).

**does_not_prove:** полиномиальную глубину для произвольных унитарных
n кубитов (это Solovay–Kitaev: глубина O(log^c(1/ε)) — заявляется как
обязательство с численной иллюстрацией, не более).

## Честные границы программы (общие)

1. Всё исполняется как точная линейная алгебра внутри пакета:
   демонстрируется **математическая спецификация процессора**,
   а не физический чип; вопрос носителя — вне области пакета.
2. Нули Римана: пакет демонстрирует **считывание из алгебраической
   функции** (слепой протокол V23), но не доказывает RH и не
   предсказывает нули «из ничего».
3. Нелокальность: демонстрируется голономная топологическая корреляция
   с алгебраически проверяемой коммутацией разделённых наблюдаемых —
   без сверхсветовой передачи информации.
4. Все числа детерминированы (фиксированные сиды); каждая кампания
   публикует claim-файл по схеме V14 (statement / premises / code /
   controls / does_not_prove / status) и проходит аудит.

## Порядок исполнения

Рекомендуемая последовательность: V20 → V21 → V22 (компилятор, память,
арифметика — фундамент «настоящего процессора»), затем V23 (главный
интерфейс считывания), затем V24 (нелокальность) и V25/V26 (метрология и
универсальность). Каждая кампания добавляет вкладку в веб-лабораторию:
V20 «Компилятор: формула → фазовый код → спектр», V21 «RAM-тест»,
V24 «Интерферометр».
