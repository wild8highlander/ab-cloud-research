# results/ROADMAP.md — направления после 1.0.0

Упорядочены по ожидаемому эффекту на главный измеренный разрыв серии —
спектральное тождество Г2 (затворы ↔ нули).

## R1. Нелокальные следовые конструкции

Урок Th6: вес простых Λ(n)/√n живёт в тепловом следе H_ξ и невидим в
следах локальных решёточных затворов (разрыв 0.63 порядка по невязке;
ранговое соответствие в эталоне — в нулевой зоне, r = 0.036). Кандидаты за пределами решётки:
оператор xp (Берри–Китинг), полулокальный множитель Коннеса,
следовые конструкции на нелокальных графах. Метрика отбора — та же
тройка V1/V7: r-ранги, r_EF против PC0, слепой контроль.

## R2. Сшивка статистической и кодировочной ветвей

Ко-локация потока простых (V7: PC0 +0.9996) знает простые точно;
статистика затворов знает GUE-класс (V2). Нужен один объект, несущий
оба признака. Формальный аналог — обязательство O08 (spec H_L →
spec H_ξ): гипотеза, которую следует либо доказать для специального
семейства, либо опровергнуть конструктивно.

Статус после v1.2.0 (V19): частично закрыто — ALGEBRAIC_CERTIFICATE.
Механизм сшивки ветвей алгебраической функции воспроизведён из
hodge-laboratory (Ферма-накрытие, монодромная склейка листов, точный
фазовый закон ζ^{ra+sb}: невязки 1e-40) и перенесён на полную
алгебраическую функцию критической прямой: Z₂-монодромия даёт строгое
чередование знаков на 2000 нулях, аргументное замыкание T = 300 точное
(138 = 138). Сшитый объект найден: гладкая Γ-фаза несёт оба признака
(θ-лестница 0.832; знаковая когерентность 0.9995, z = 43.4).
Остаточное обязательство O20: спектральная часть сшивки (замыкание
тождества на ручках затвора, r_align z ≤ 1.83) и полная группа
монодромии ζ в комплексной плоскости.

## R3. Континуальное вложение для предела L → ∞

Открытое обязательство O-C2 (V5): перекрытие проекторов между разными
L требует отображения пространств. Построить вложение (масштабная
предел решётки → оператор на L²([0,1]²)) и доказать норм-резольвентную
сходимость хотя бы для вихревого свободного случая.

## R4. Продление сертифицированной зоны критерия Ли

V15 даёт λ_n > 0 для n ≤ 3000 с хвостами ≤ 0.115. Направления:
(а) расширить файл нулей (2M высот родительского репозитория) и
снизить хвосты до 1e-3; (б) связать λ_n со старшими следами затворов
(обязательство O09) через формулу Ньютона; (в) аналитическая оценка
знака g_n для малых n.

## R5. Компиляция формального слоя

formal/ содержит спецификации Lean 4 / Coq / Agda / Isabelle. Задача:
поднять тулчейны, компилировать скелет (эрмитовость, вещественность,
Tr(AB) = Tr(BA)) и подключить исполняемую ре-деривацию к IVP как
дополнительную проверку (обязательство O-lean).

Λ-сита; расширить порты на Li-путь Th4. Веб-лаборатория (web_lab/) —
добавить слепой протокол и критическую линию как интерактивные
