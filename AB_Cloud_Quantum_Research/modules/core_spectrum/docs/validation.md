## 2. Машинные полы

- K(x) при x ≥ 1 — пол ~1e-9 (прямая сумма вымирает);
- D_KS ансамблевого эталона — 0.05–0.07 (размер окна 200);
- r_EF на окнах 200 уровней — собственный разброс σ ≈ 0.3–0.8 (это
  нулевая зона метрики, не сигнал);
- развёртка ломается на кратных уровнях (проверено на торах);
- λ_n-хвост растёт линейно по n (0.115 при n = 3000 — фактор файла
  нулей, не алгоритма).

## 4. Честные найденные-и-исправленные эпизоды

1. **Эрратум константы B** (родительский репозиторий): ½ln(2π) вместо
   ½ln(4π) — на тождество Q не влияло (сокращение −B−C₀), на значение B
   влияло. Выведено заново, подтверждено C₀(файл).
2. **Фаза простой части T2**: exp(−A·(ln n − ix)), а не exp(−A·(n − ix))
   — иначе T2 занижен на порядок.
3. **Рецепт PC0**: множитель u и U-сетка от 0.05 — иначе краевой
   транзиент имитирует корреляцию.
4. **Вес гребёнки**: prime_comb сам делит на √n — двойное деление в
   вызовах исправлено.
