# data/ — закоммиченные вердикты серии V1–V15

Каждая кампания публикует вердикт `vNN_verdict.json` (плюс `meta` с датой,
временем и версией пакета). Кампании-экскурсии (`campaigns/run_v*.py`)
читают эти файлы; свежий пересчёт — `scripts/compute_all.py`.

## Единственный внешний файл данных

- `zeta_zeros_50000_embedded.txt` — 50 000 действительных нулей ζ
  (таблица Одлыжко, извлечена из родительского репозитория
  ab-cloud-research). SHA-256:
  `2cf6a84e9da69ee27cf165f03bbc3b8bb2e33fa9afdaeba4ecb529aea9509db6`.

## Правила

1. Вердикты коммитятся; отличие свежего прогона от коммита —
   релиз-стоппер (test_repro).
2. Файл нулей входит в пакет — пакет самодостаточен и работает офлайн.
3. Никакой сторонний исследовательский код не импортируется.
4. JSON читаются campaigns/run_v*.py и rpbridge/ivp.py.
