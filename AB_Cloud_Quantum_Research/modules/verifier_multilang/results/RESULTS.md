## O-J2 (v0.4.0): класс B — компилятор против сильных baseline

**Постановка.** Равные ограничения ISA: все методы выдают программы из
AB2-блоков и PHASE-фаз; численные baseline (BL3/BL5) получают ровно те же
слоты, что ABQP. Независимый набор: 9 структурированных матриц + 40 Haar 4×4
+ 20 Haar 8×8 (seeds 41800+, не пересекаются с V20/E02) + испорченный
контроль DFT4+1e−3.

**Baseline.** BL1 — наивный Givens без пропусков; BL2 — учебная Эйлер-
декомпозиция W = D1·G(θ)·D2 (1 AB2 + 4 PHASE на блок, без слияния фаз);
BL4 — Хаусхолдер-QR с разложением отражений H = S†·P·S; BL3 — покоординатный
спуск золотым сечением (3 рестарта × 200 свипов @4×4, 1 × 100 @8×8); BL5 —
случайный поиск (3000/300 проб).

**Результаты (все 5 порогов PASS).** ABQP: max 1−F = 4.44e−16 на 100%
целей (порог 1e−12); бюджет примитивов ≤ каждой точной baseline на каждой
цели; медиана времени ABQP@haar4 = 0.0039 мс против BL3 232.2 мс (×59 000,
порог ×50); identity → 0 блоков AB2; испорченная цель компилируется
(1−F ≈ 5e−7 ≤ 0.01). Честная фиксация: BL3 — близкий промах 3e−12 после
520 803 оценок (успех ≤ 1e−12 лишь на 2 из 69); BL5 ≈ 0.5; 2q-эквивалент —
KAK-оптимум 3 для 4×4 вне ISA-класса (ABQP max 10 — превосходство НЕ
заявляется).

## O-J1 (v0.3.0): высота T = 1000 и Риман–Зигель

* **E16.** Движок Римана–Зигеля (Ариас де Рейна I/II, сборка сверена с
  mpmath/rszeta): главная сумма до N = ⌊√(t/2π)⌋ включительно, коэффициенты
  F — из целочисленной рекурренты чисел Эйлера на 400 бит (без рукописных
  таблиц), обрезка асимптотики — U-turn с шагом 2 (члены затухают парами
  нечёт/чёт). Самотесты: F-ряд 3.9e−42; вещественность Z(t) 5.7e−42; согласие
  с Эйлером–Маклореном при равной точности ≤ 3.8e−15 (порог O-J1: 1e−9).
  Стоимость (медиана, 7 прогонов): t=100 — 0.31/1.52 мс (ЭМ/РС); t=1000 —
  3.36/1.04 мс; t=10⁴ — 25.2/1.00 мс.
* **E17.** Два слепых детектора: A — Эйлер–Маклорен (N = 64·2^k ≥ 0.512·t,
  K=14), окно [0.3, 1000], h=0.01 (99 971 точка); B — Риман–Зигель, окно
  [50, 1000]. Оба выхода пинованы SHA256 до валидации; валидатор проверяет
  пины, уточняет Гауссом–Ньютоном с третьим расписанием (320, 12) и сверяет с
  эталоном mpmath.zetazero (660 строк, свой SHA256).
  Результат: **649/649** и **639/639**, precision = recall = 1; кросс-движок
  **0.0** (побитово); N(1000) = **649.000000** = числу найденных; max |Δγ| =
  3.0e−10 ≤ 1e−9 (RMS 2.3e−11); детектор до уточнения: 2.3e−13 по всем 649;
  устойчивость к сетке на [900,1000] (h = 0.02, 0.005): сдвиг 0.
* Кросс-язык: Python-слепая намотка [900, 960] чистым mpmath — 48/48 нулей,
  max |Δ| = 2.3e−13; все 649 позиций Julia против zetazero — 2.3e−13.

## Флагман E11 — слепой протокол

* Детектор: ζ(½+it) методом Эйлера–Маклорена (BigFloat(140), N=64, K=14);
  намотка аргумента, h = 0.01, [0.3, 60]; уточнение золотым сечением.
  Самотесты без нулей: ≤ 1.9e−17.
* Дисциплина: выход детектора зафиксирован и хеширован SHA256 **до** запуска
  валидатора (порядок контролирует `run_all.jl`).
* Валидатор: независимая локализация (Гаусс–Ньютон по |ζ|²), независимое
  расписание ζ (N=48, K=10), эталон mpmath.zetazero (провенанс зафиксирован).
* Результат: precision = recall = 1.0; max |Δγ| = 1.42e−14; Гаусс–Ньютон:
  ошибка 0; устойчивость к сетке h ∈ {0.02, 0.005} — 13 нулей; полнота:
  N(60) = 13.000000000000002 (аргументный принцип, стандартный путь).
* **Эрратум v0.1.0, найденный протоколом:** рукописная константа γ12 =
  56.446200059994141 оказалась неверной; слепой детектор дал
  56.446247697063399 (|ζ| = 9e−15), mpmath подтвердил детектор (на
  «рукотворном» значении |ζ| = 1.1e−4).
* Кросс-язык: Python-детектор (mpmath, 40 знаков) воспроизвёл все 13 позиций
  с max |Δγ| = **0.0** — побитовое совпадение двух независимых реализаций.

## Границы выводов (не доказывается)

Конечное число нулей не доказывает RH и не экстраполируется; CHSH-симуляция —
не физический Bell-тест; no-signaling — свойство квантовой теории; устойчивость
E15 — свойство модели без физического слоя; результаты относятся к классу A
плана (корректность/устойчивость/стоимость), частично к классу B.
