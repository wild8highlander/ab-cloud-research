## Что нового в v0.1.0

Нулевая (фундаментная) версия программы:

- **ISA AB-облака**: {AB2 — двухуровневый блок-импульс, PHASE —
  селективный детюнинг уровня} + производные RZ/RX/CPHASE/CNOT;
  фазовый континуум φ = 2πΦ/Φ₀; калибровка каждого примитива
  экспонентой блочного гамильтониана (fidelity ≥ 1−1e-14);
- **точный компилятор** произвольной унитарной логики 4×4/8×8
  (Givens-QR → AB2 + PHASE, замкнутая форма, без оптимизации);
- **превью-слои** фаз P1–P3: память (RAM 64/64), АЛУ (256/256),
  считывание нулей (12/12, без таблицы), нелокальность (CHSH 2√2,
  no-signaling);
- веб-лаборатория 7 вкладок; монографии RU/EN × PDF/DOCX; workbook;
  claim-аудит; IVP01–IV05; самосборка и чистая валидация ZIP.

## Ключевой тезис: считывает, а не несёт

Суть программы — не в том, что облако «несёт» нули Римана, а в том,
что оно **считывает** нули с критической прямой через прямые
алгебраические функции. Пайплайн: формула ζ(s) (O(1) констант) →
аргументная намотка arg ζ(½+it) → скачки π (монодромия V19) → позиции
нулей. Таблица нулей не входит ни во вход, ни в состояние; контроль
(бисекция вещественной функции Z(t)) применяется только ПОСЛЕ фиксации
результата — слепой протокол V1. На окне [2, 58]: 12/12 нулей точно,
максимальное отклонение 2.98e-3, хранение — 0 нулей и 6 констант
формулы. Полный протокол (K = 138, T = 300, dev ≤ 1e-8) — кампания
V23 фазы P3.

## Нелокальность: знает, но не сигнализирует

«Одна частица знает другую» — голономная (топологическая) корреляция:
фаза каждой частицы — функционал ЕДИНОЙ глобальной вихревой
конфигурации, а не результат обмена сигналом. Измерено: совместная
корреляция E(XX) = (1+cos Φ₁₂)/2 несёт перекрёстную фазу Φ₁₂ = 2πq₁₂L₁₂;
редуцированное состояние частицы инвариантно к локальным операциям
партнёра (100 унитарных, ‖Δρ₁‖ = 3.3e-16) — канала связи нет; 1000
случайных локальных возмущений не меняют фазу (максимум 5.6e-16) —
защита топологическая; CHSH S = 2√2 ≥ 2.8 при точной коммутации
разделённых наблюдаемых ([Aᵢ⊗I, I⊗Bⱼ] = 0). Полный протокол — V24
(фаза P4).

## Честные границы

1. Исполняется **математическая спецификация процессора** (точная
   линейная алгебра), а не физический чип; вопрос носителя — вне
   области пакета.
2. Глубина схем фиксируется, но не оптимизируется (KAK/Соловей–Китаев —
   обязательство P6/V26).
3. Считывание нулей демонстрирует механизм и не доказывает RH.
4. Нелокальность — голономная корреляция с алгебраически проверяемой
   коммутацией разделённых наблюдаемых; сверхсветовая передача не
   заявляется (напротив — исключается).
5. Превью-слои (память/АЛУ/считывание/нелокальность) — предварительные
   измерения; строгие пороги закреплены за V21–V24.
6. Все числа детерминированы (сиды 96/296); каждый claim имеет файл с
   does_not_prove и проходит аудит.
