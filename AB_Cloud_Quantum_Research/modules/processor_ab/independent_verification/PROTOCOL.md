# independent_verification — протокол

Независимая верификация из чистого состояния: свежие прогоны сравниваются
с закоммиченным вердиктом data/v20_verdict.json.

| IV | Протокол | Порог |
|----|----------|-------|
| IV01 | Свежий полный прогон компилятора (200×4×4 сид 96 + 100×8×8 сид 296) | совпадение с вердиктом до 1e-14; пороги 1e-12/1e-10 |
| IV02 | Контроли identity/permutation/DFT4/CL(2) | точно (≤ 1e-13) |
| IV03 | Бит-в-бит повтор (20 унитарных, дважды) | float64 идентичен |
| IV04 | RAM 64/64 + латентность b | бит-в-бит; b ≤ 6; совпадение с вердиктом |
| IV05 | Весь набор нелокальности | интерферометр/защита/кросс-фаза/CHSH/коммутаторы |

Запуск: `bash independent_verification/RUN_ALL.sh` (требуется
data/v20_verdict.json; pytest отдельно).
