# results/ROADMAP.md — дорожная карта программы «AB Quantum Processor»

**Миссия.** Довести AB-облако от «оператора с точными воротами» (V18
материнской серии) до **полного паспорта универсального квантового
процессора** — Datasheet 1.0: система команд, компилятор, память, АЛУ,
интерфейс считывания любых алгебраических функций, метрология,
универсальность, нелокальность. Каждый шаг — отдельная кампания с
предрегистрированными порогами, claim-файлом (схема V14) и списком
не-следствий; каждая фаза — релиз пакета с монографиями RU/EN, вкладкой
веб-лаборатории и чистой валидацией.

**Ключевой тезис программы** (зафиксирован в P0 и не меняется): суть не
в том, что облако «несёт» нули Римана, а в том, что оно **считывает**
нули с критической прямой через прямые алгебраические функции — таблица
нулей не входит ни во вход, ни в состояние пайплайна считывания.
Нелокальность объясняется голономией: фаза каждой частицы — функционал
ЕДИНОЙ глобальной вихревой конфигурации, поэтому корреляция мгновенна,
топологически защищена и не передаёт информацию.

**Фаза P0 исполнена (v0.1.0):** вердикт кампании V20 —
`PROCESSOR_SPEC_EXECUTED`.

## P0 · v0.1.0 — V20 «Компилятор» (ИСПОЛНЕНО)

**Цель.** Исполнить предрегистрированную спецификацию V20 материнского
пакета (results/PROCESSOR_PROGRAM.md, AB Research Program 1.2.1): любая
унитарная матрица умеренного размера компилируется в ISA AB-облака и
исполняется бит-в-бит воспроизводимо.

**Исполнение.**
- ISA: {AB2(a,b;θ,λ,φ,χ) — двухуровневый блок-импульс (обобщение P1
  V18), PHASE(x;φ) — селективный детюнинг уровня (обобщение P2 V18)};
  фазовый континуум φ = 2πΦ/Φ₀; калибровка каждого примитива
  экспонентой блочного гамильтониана, fidelity ≥ 1−1e-14.
- Компилятор: Givens-QR → двухуровневые блоки → AB2-параметризация
  (замкнутая форма) → лестница PHASE; без оптимизации и аппроксимации;
  отброшенные микроскопические фазы честно входят в метрику.
- Метрики: 200×4×4 (сид 96) → min F = 1−4.44e-16 (порог 1−1e-12);
  100×8×8 (сид 296) → 1−6.66e-16 (порог 1−1e-10); контроли
  identity/permutation/DFT4/CL(2) точны; реплей бит-в-бит; глубина
  зафиксирована (7 / 29 затворов).
- Превью-слои (честно помечены предварительными): память P1 (RAM 64/64,
  b = 4.0, фазовые слова 256/256); ALU V22 (256/256, 128/128, 16/16,
  256/256); считывание V23 (12/12 нулей, dev 2.98e-3, хранение 0 нулей /
  6 констант); нелокальность V24 (интерферометр 6.7e-16, защита
  1000/1000, CHSH 2√2, коммутаторы 0, ρ₁-инвариантность 3.3e-16).

**Критерии приёмки (все выполнены):** пороги перекрыты ≥ 10³×;
аудит claims 1/1 PASS; pytest 19/19; вердикт закоммичен; монографии
RU/EN; веб-лаборатория 7 вкладок; чистая валидация ZIP.

**Артефакты:** data/v20_verdict.json; computations/V20_processor_compiler/
(монографии ru/en × pdf/docx, рисунки, results.json); claim_v20.json;
веб-лаборатория; qp_workbook.xlsx.

## P1 · v0.2.0 — V21 «Память»

**Цель.** Память как полноценный слой процессора: не только «записал —
прочитал», но удержание под шумом, ошибко-коррекция и честная иерархия
(регистры → кэш → RAM-слой с маршрутизацией).

**Содержание работ.**
1. Шумовая модель: деполаризация и дефазировка на такт (параметры
   предрегистрированы); персистентность 64/64 при T = 10³ с шумом;
   кривая выживания.
2. Ошибко-коррекция фазовыми кодами: код повторения на фазах уровней;
   порог исправимых ошибок фиксируется в вердикте.
3. Иерархия памяти: регистры (n ≤ 8), строки (линейка узлов),
   RAM-слой с SWAP-маршрутизацией; латентность L(d) = a + b·d
   (порог b ≤ 6 подтверждается с шумом).
4. Топологическая защита памяти: выживание вихревых (топологических)
   базисных состояний ≥ выживания тривиальных (контроль) при том же T.

**Пороги PASS:** RAM 64/64 бит-в-бит (с шумом + КК); b ≤ 6;
персистентность топологических ≥ тривиальных при равных условиях.

**does_not_prove:** время когерентности физического носителя;
масштаб на 10² узлов.

## P2 · v0.3.0 — V22 «ALU»

**Цель.** Полная арифметика на ISA: не только перестановки, но и
фазовые алгоритмы; мультиязычная регрессия ядра.

**Содержание работ.**
1. Полный набор операций: сумматор, умножение mod 2ⁿ, сравнение,
   инкремент/декремент — все на компиляторе V20, полный перебор входов.
2. Мультипликатор больших чисел: NTT на корнях из единицы облака
   (фазы — родной язык), умножение 100-значных чисел бит-в-бит против
   Python bigints.
3. Кросс-язычная регрессия: C и JS двойники ядра (компилятор + ALU)
   согласованы до 1e-14 (по образцу R3 материнской серии).
4. Стоимость: глубина/число затворов на операцию фиксируется в
   вердикте.

**Пороги PASS:** 256/256 на каждую операцию; bigint-произведение
точно; C/JS консистентность ≤ 1e-14.

**does_not_prove:** преимущество над классикой; масштаб на 64 бита.

## P3 · v0.4.0 — V23 «Считывание» (главная кампания программы)

**Цель.** Универсальный интерфейс «любая алгебраическая функция →
числа/нули»: перевести заявку пользователя в исчерпывающий протокол и
исполнить его слепо.

**Содержание работ.**
1. Библиотека алгебраических чисел: √2, √3, ∛2, φ, 2cos(2π/7), корни
   x⁴−x²−1, … (16 значений); загрузка фазовым затвором AB(φ), чтение
   фазовой оценкой; невязка против точного значения (mpmath 40 dps):
   ≤ 1e-12 (double-слой), ≤ 1e-30 (mpmath-слой).
2. Замкнутость интерфейса: считывание f∘g и f+g равно
   композиции/сумме считываний (порог 1e-12) — «читает любые формулы».
3. Слепое считывание нулей: полная алгебраическая функция Z_id
   критической прямой (V16/V19 материнской серии) загружается БЕЗ
   доступа к таблице нулей; K = 138 нулей на T = 300 восстанавливается
   аргументной намоткой; сравнение с независимым ζ — после фиксации
   результата (blind-протокол V1). Порог: позиционное отклонение ≤ 1e-8.
4. Бухгалтерия «хранение vs чтение»: нулей произведено vs констант
   хранится; коэффициент считывания как функция T.

**Пороги PASS:** 16 чисел ≤ 1e-12; замкнутость ≤ 1e-12; K=138
точно по счёту, dev ≤ 1e-8; хранение — O(1) констант формулы.

**does_not_prove:** гипотезу Римана; асимптотику на всех высотах
(T → ∞).

## P4 · v0.5.0 — V24 «Нелокальность»

**Цель.** Полный протокол голономного механизма «одна частица знает
другую» + дизайн лабораторных проверок.

**Содержание работ.**
1. Интерферометр (выверен в P0): невязка ≤ 1e-14 — фиксируется как
   стандарт.
2. Топологическая защита: 1000/1000 локальных возмущений (dev ≤ 1e-12)
   + новая серия — возмущения ГЛОБАЛЬНОЙ конфигурации меняют фазу
   предсказуемым законом (двусторонний контроль).
3. Многочастичная голономия: N частиц, попарные и тройные фазы
   (закон V19 ζ^{ra+sb}); no-signaling — коммутаторы и ρ-инвариантность
   для всех пар.
4. CHSH и Bell-слой: S = 2√2 на симуляционном слое; честная пометка
   «симуляция».
5. Лабораторные протоколы: расчёт реальных параметров (соленоиды,
   мезоскопические кольца) — внешние ссылки, не пересчитываются
   внутри пакета (честная пометка).

**Пороги PASS:** как в превью, на расширенных сериях; двусторонний
контроль защиты.

**does_not_prove:** сверхсветовую передачу (напротив — коммутаторы);
квантовую гравитацию; интерпретационные вопросы.

## P5 · v0.6.0 — V25 «Бенчмарки»

**Цель.** Стандартная процессорная метрология, всё детерминировано.

**Содержание работ.** Randomized benchmarking (средняя затворная
fidelity ≥ 0.999); передача состояния вдоль строки из 8 узлов
(≥ 0.99); латентность затвора в тактах; связность графа (диаметр,
степень); «квантовый объём» симуляционного слоя. Вердикт включает
сравнительную таблицу с литературными числами канонических архитектур
(сверхпроводящие кубиты, ионные ловушки) с явной пометкой «внешние,
не пересчитываются внутри пакета».

**does_not_prove:** физическую реализуемость чипа; конкуренцию с
инженерными платформами по энергии/такту.

4. Интеграция с материнской серией: сводка V1–V19 → V20–V26, склейка

**Пороги PASS:** покрытие SU(2) ≤ 12 затворов @ 1e-8; Datasheet

## Протокол честности (общий для всех фаз)

1. Пороги предрегистрированы до прогона и не меняются после
   (изменения — только через новый claim-файл с указанием причины).
2. Каждая кампания публикует claim-файл по схеме V14 материнской
   серии: statement / premises / code / controls / does_not_prove /
   status + числовые согласования с вердиктом (rpbridge.audit).
3. Все числа детерминированы (фиксированные сиды); вердикты
   закоммичены и независимы от свежего пересчёта; независимая
   верификация (IVP) — отдельными протоколами из чистого состояния.
4. Честные границы программы: исполняется **математическая
   спецификация процессора** (точная линейная алгебра), а не физический
   чип; нули считываются из функции (RH не доказывается); нелокальность
   — голономная корреляция без сигналинга (FTL не заявляется).

## Связь с материнской серией

Программа продолжает нумерацию кампаний AB Research Program (V1–V19):
P0 = V20 исполняет предрегистрированную спецификацию
results/PROCESSOR_PROGRAM.md из пакета AB_Research_Program_v1.2.1.

(алгебраическая функция в облаке), V19 (фазовый закон, монодромия,
ALGEBRAIC_CERTIFICATE). Дорожная карта R1–R6 материнского пакета не
заменяется: обязательство O20 (спектральная часть сшивки) остаётся
открытым там и не дублируется здесь.
