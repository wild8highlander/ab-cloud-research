## Вопрос кампании

Чем является AB-облако как вычислительное устройство? Спецификация V20
(предрегистрирована в материнском пакете, PROCESSOR_PROGRAM.md): ISA +
точная компиляция произвольной унитарной логики + бит-в-бит
воспроизводимость; плюс первые измерения памяти, арифметики,
считывания нулей и нелокальности.

## Метод

rpbridge/isa.py + rpbridge/compiler.py: Givens-QR → двухуровневые
блоки → AB2-параметризация (замкнутая форма) → лестница PHASE; без
оптимизации. Превью: rpbridge/{memory,alu,riemann_reader,nonlocality}.py.
Протокол и пороги: docs/methods.md, results/ROADMAP.md (P0).
