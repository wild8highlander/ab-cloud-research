# Теория: машина без долговременной памяти

## 1. Модель

**Определение (спинорная фазовая машина).** Машина M(θ) — тройка
(φ, step, read), где:

- состояние — единственный регистр φ ∈ [0, 2π) (фаза единичного спинора);
- шаг реального времени: φ ← (φ + θ) mod 2π, θ — фиксированный модельный
  угол (спинорная фаза);
- считывание — проекция максимального правдоподобия на решётку
  G_θ = {0, θ, 2θ, …}: индекс s = round(φ/θ) mod N.

Константы θ и N — спецификация модели, известная до запуска; они не
являются состоянием. Единственный изменяемый регистр — φ. След состояния
(footprint) равен 1 при любом t; контейнеров истории нет — хранение = 0
по построению.

**Модельные фазы.** θ = π/2 (S1), θ = π/3 (S2), θ = π/7 (S3). Для любой
фазы вида π/k решётка замыкается через N = 2k шагов (теорема TS1): цикл
состоит из 2k корней из единицы, поэтому S1 — «квадрантная» машина с
4 состояниями, S2 — «секстантная» с 6, S3 — 14-фазная.

## 2. Почему у машины нет долговременной памяти — и почему это свойство, а не дефект

Три независимых аргумента, каждый со своим сертификатом:

**(a) Информационный (TS2/ES2).** Состояние несёт ровно log₂N бит
независимо от времени работы. После сброса (стирания) пост-состояние
вырождено: I(S_пре; S_пост) = 0, и никакой наблюдатель не восстанавливает
прошлое лучше уровня случайности 1/N. О времени машина помнит только
t mod N — доля согласованных моментов на горизонте T равна 1/N. Это и
есть строгий смысл фразы «нет долговременной памяти»: не «память плохая»,
а «память отсутствует как носитель истории».

**(b) Вычислительный (ES4).** Несмотря на один регистр, машина полноценно
вычисляет: модульный счётчик out_t ≡ (out_0 + t) (mod N) исполняется
300 000 шагов с точностью 1.0 для всех трёх моделей. Фаза сама является
счётчиком — внешнего счётчика времени у машины нет. Принцип «читает, а
не несёт» из материнской программы (V23/E17) — это тот же тезис:
результат живёт в потоке шагов, а не в хранилище.

**(c) Временной (TS3/ES3).** Шаг машины стоит O(1) при любом t — профиль
стоимости плоский (наклон −1.5e−12 мс/шаг, 0 пропусков дедлайна 1 мс на
200 000 шагов). Контрастная LogMachine с вечным журналом и полной
перепроверкой несёт Ω(t): рост стоимости шага ×129 к t = 2¹⁷, R² = 0.999.
Для любого дедлайна Δt найдётся t*, после которого журнал срывает
дедлайны. Вывод: жёсткое реальное время и долговременная память
архитектурно несовместимы — летучесть есть условие детерминизма.

## 3. Ёмкость против робастности

Ёмкость растёт как log₂N = log₂(2k) по k, а зазор между соседними
состояниями убывает как 2π/N = π/k. При iid-шуме считывания
(наблюдение φ̂ = φ + ε, ε ~ N(0, σ)) вероятность ошибки символа —
2Φ(−gap/2σ): зона тишины σ* масштабируется с зазором (измерено:
σ*_S1 = 0.135 ≥ σ*_S2 = 0.089 ≥ σ*_S3 = 0.038 рад; все внутри
[gap/12, gap/2]). При σ = gap канал ломается (SER ≈ 0.62). Компромисс
«биты против зазора» — фундаментальное свойство фазового канала, а не
дефект реализации; он опубликован как честная граница (ES5).

Для накопительного шума (фазовая диффузия) время до первой ошибки
масштабируется как t* ~ gap²/σ² — разведочное измерение с наклоном −2 в
log-log согласуется с теорией. Диффузия намеренно оставлена без порогов:
это отдельная физика, не смешиваемая со считывательным каналом.

## 4. Место в программе

Модель — вырожденный случай ISA AB-облаков (модуль processor_ab): поворот
фазы — это один PHASE-затвор, а решётка состояний — циклическая
подгруппа. Тем самым TS1–TS3 дают процессорной ветке (P1, V21) готовую
теоретическую опору: память процессора летуча по архитектуре, и это
доказано, а не постулировано. Для O-J3 (QEC-память) контраст «летучая
фаза против вечного журнала» задаёт нулевую точку сравнения.

## 5. Честные границы

Модели абстрагируются от когерентной физики (декогеренция, релаксация,
систематические дрейфы — за границей), от термодинамики стирания
(Ландауэр не заявляется) и от квантовых преимуществ (никакого
превосходства не утверждается). Исследование не связано с гипотезой
Римана: статус RH остаётся заблокированным машиной обязательств V13.
