# TS1 · Теорема о фазовом цикле

**Статус:** доказана (аналитически) · **Сертификат:** кампания ES1, вердикт
PASS · **Документы:** `theorem_ts1_{ru,en}.{pdf,docx}` (4 документа с
внедрённой плиточной фигурой) · **Фигура:** `figures/ts1_4dim_{lang}.png`
(2×2 «4 измерения», 600 dpi).

## Постановка

Пусть θ = π/k, k ∈ ℕ, и R: φ ↦ (φ + θ) mod 2π — поворот окружности S¹,
исполняемый машиной один раз за шаг реального времени. Тогда:

1. орбита любой точки решётки состояний G_θ = {0, θ, 2θ, …} замыкается
   ровно через **N = 2k** шагов (π/2 → 4, π/3 → 6, π/7 → 14);
2. минимальный угловой зазор между различными состояниями равен
   **2π/N = π/k** — то есть самому шагу фазы;
3. решётка равномерна: состояния делят окружность на N равных дуг.

Следствие: ёмкость — log₂N бит на цикл (2.00 / 2.585 / 3.807 бит/шаг для
трёх моделей), при том что шаг и память остаются O(1).

## Идея вывода

Замыкание — прямое следствие арифметики: N·θ = 2k·(π/k) = 2π ≡ 0
(mod 2π). Минимальность — если m·θ ≡ 0 (mod 2π), то m = 2kj ≥ 2k, поэтому
меньшего периода не существует. Зазор — соседние точки решётки отличаются
ровно на θ, а любое другое расстояние между состояниями кратно θ;
равномерность — точки {2πi/N} суть корни из единицы. Полное
доказательство — в документах (раздел «Формулировка»).

## Четыре измерения сертификата (ES1)

| Измерение | Что меряется | Итог |
|-----------|--------------|------|
| метрика | эмпирический минимальный период последовательности состояний | 4 / 6 / 14 = 2k точно |
| поведение по инстансам | серия θ = π/k, k = 2…16 | N = 2k для всех k |
| контроль | равномерность решётки, минимальный зазор | ≤ 8.9e-16 рад; gap = 2π/N (±1e-9) |
| порог | предрегистрированные допуски C1–C4 | все PASS |

## Границы (честно)

Теорема сертифицирует замкнутость **фазовых решёток выбранных моделей**.
Она не утверждает ничего о физической реализации спинорных фаз, о
когерентных носителях, о шуме (это ES5) и не связана с гипотезой Римана.
Компромисс «ёмкость log₂N против робастности 1/k» — свойство модели, а не
дефект реализации.
