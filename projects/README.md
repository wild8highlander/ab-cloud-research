# 🗂️ projects/ — the research programmes

**Every self-contained research project of the AB-Cloud programme lives here,
one directory per programme, all kebab-case.** The method layers they share —
canonical code (`code/`), the 13-language verification stack (`verification/`),
the formal layer (`formal/`), experiment archives (`results/`) and the deploy
portal (`site/`) — stay at the repository root.
