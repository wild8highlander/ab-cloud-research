# docs/methods.md — методы серии V1–V15

## 1. Решётка и затворы

Гамильтониан: H[i,j] = −t·e^{iφ} на связях, H[i,i] = V_i; фазы Ландау
φ_x = 2πα·iy; вихревые разности φ_y = Σ_k (q_k/2)(θ_j − θ_i), θ_k =
atan2; on-site V_i = Σ_k q_k·W/(r²/N + 1) + ε_i ~ U(−0.01, 0.01);
границы open/torus (тор требует α·L ∈ ℤ); расширения: твисты,
анизотропия, масса, профиль midpoint, знаки зарядов.

Протокол вихрей: центры ячеек (ix+0.5, iy+0.5) из 1..N−1; нейтральные
заряды (чётный Nv → половина +q, половина −q). Master-seed 96;
vortex-RNG = seed + 3500; disorder-RNG = seed + 3501.

## 2. Спектральный конвейер

eigvalsh (driver evr, overwrite_a) → сортировка → центральная полоса
60% (fld-арифметика: half = ⌊n·0.6/2⌋) → полиномиальная развёртка
(степени 6→3, фолбэк кусочно-линейный) → окно 200 развёрнутых уровней.
Бит-в-бит воспроизведение протокола C3 эталона: 1.45e-16.

## 3. Статистики (предрегистрированы)

⟨r⟩ по min/max соседних промежутков; Σ²(L) и Δ₃(L) по скользящим
окнам; форм-фактор K(t) = |Σe^{−2πiut}|²/N; D_KS против эмпирического
GUE-эталона (ансамбль 16 матриц 576², 3168 значений {r_n}); ранговая
корреляция Спирмена без scipy.stats.

## 4. Нулевая сторона

Файл Одлыжко 50 000 высот (γ₁ = 14.1347251, T_max = 40433.687); гладкий
счёт N̄(γ) = γ/2π·ln(γ/2πe) + 5/8; слепое разбиение V1 — детерминированное
перемешивание с salt-хешем; высоты вихрей V3 — середины γ̃_k между
соседними ординатами (вне нулей ζ).

## 5. Следовой конвейер (Th6)

Произведение Адамара: ξ′/ξ(½+a) = Q(a) = Σ_γ 2a/(a²+γ²); раскрытие по
определению ξ даёт замкнутую форму с B = ½ln(4π) − 1 − γ/2 и C₀ = −B.
Тождество: K(x) = Tr e^{−xH_ξ} = (1/π)∫₀^∞ Q(a)·sin(ax)da. Части:
T1 — сплайн Q на [0, 1.5] (601 узел, полюс a = ½ сдвинут на 1e-6);
T2 — простая часть ζ′/ζ = −ΣΛ(n)/n^{½+a} при a > A_SPLIT (решето до
2·10⁶, фаза ln n − ix, вес Λ(n)/√n); T3 — гладкая часть точными
Si/Ci-формами. Метрика затворов: D(u) = u·Σe^{−u·N̄(γ)} − (1−e^{−uX})
против гребёнки P(u) = ΣΛ(n)/√n·u/(u²+ln²n), U ∈ [0.05, 1.0] (40 точек),
s = 1 фикс.

## 6. Критерий Ли (Th4)

λ_n из степенных сумм S_n = Σ w^n, w = 1 − 1/(½+iγ); парная сходимость
2 − 2Re(w^n) = O(n/γ²); сертифицированный хвост |1−w^n| ≤ n|1−w| ⇒
n·[ln(T/2π)+1]/(2πT). Второй путь — Tr g_n(H_ξ), g_n(E) = 1 −
(1−1/ρ(E))^n, ρ(E) = ½ − iE/2. Согласие путей ≤ 4.4e-11.

## 7. Сертификаты (Th3)

Гершгорин в fractions (limit_denominator 1e12); оценка Каутского
|λ̂ − λ̃| ≤ δ²/gap в mpmath dps = 40; зазор — точная минимизация по
спектру. Все сертификаты — машинночитаемые JSON.
