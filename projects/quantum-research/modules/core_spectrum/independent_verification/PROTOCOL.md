# IVP — AB Research Program 1.2.0

Протокол независимой верификации: 16 проверок над закоммиченными
вердиктами и живыми пересчётами.

## Правила

1. **Слепота к намерению.** Порог каждой проверки известен до запуска;
   вердикт бинарный (PASS/FAIL). Никаких «интерпретаций» после просмотра
   результата.
2. **Позитивный контроль обязателен.** Там, где метод заявляет
   «тождества нет», протокол требует демонстрации тождества там, где оно
   заведомо есть: PC0 (окно нулей ↔ гребёнка простых, V7), контроль
   Адамара H_ξ ↔ ξ (V6), эталонные лестницы GUE/GOE/Пуассон (V2).
3. **Независимость реализации.** IVP02/03/06/07/08 пересчитывают свои
   величины из исходных данных заново, а не читают закоммиченные числа;
   IVP12 проверяет, что все кампании-экскурсии исполняются.
4. **Коммит вердиктов.** RESULTS.md — протокол зафиксированного прогона.
   Любое отличие повторного прогона от закоммиченного — релиз-стоппер.

## Реестр проверок

| ID | Проверка | Порог | Метод |
|----|----------|-------|-------|
| IVP01 | целостность релиза | 0 отсутствующих | файловый реестр |
| IVP02 | паспорт оператора Th1 | ‖H−H†‖ < 1e-12, resid < 1e-11 | живой пересчёт |
| IVP03 | самосопряжённость Th2 | (0,0), дрейф < 1e-12 | живой пересчёт |
| IVP04 | слепой r_test в нуле | |z| < 2 | коммит V1 |
| IVP05 | GUE-класс + лестница | KS(M0) < 0.15; Poisson>GOE>GUE | коммит V2 |
| IVP06 | следовая формула Th6 | \|ΔQ\| ≤ 1e-6, \|ΔK\| ≤ 5e-5 | живой пересчёт (20k) |
| IVP07 | Ли, два пути Th4 | \|Δ\| ≤ 1e-9, λ_n > 0 | живой пересчёт (50k) |
| IVP08 | блочная редукция Th5 | ε < 1e-10, union < 1e-9 | живой пересчёт |
| IVP09 | сертификаты Th3 | contains_true = все | коммит V12 |
| IVP10 | RH сертифицирован | assumptions = 0, DAG корректен | коммит V13 |
| IVP11 | аудит claims | all_a1 и покрытие | коммит V14 |
| IVP12 | кампании исполняются | 18/18 | subprocess |
| IVP13 | карта ручек V16 | rows=288; z_best < 6; identity_closed=False | коммит V16 |
| IVP14 | электрон V17 | ΔE < 1e-10; ratio > 1; Δy(ζ) > Δy(rand) | коммит V17 |
| IVP15 | процессор V18 | fidelity > 1−1e-12; C > 0.5; replay | коммит V18 |
| IVP16 | сшивка ветвей V19 | verdict = CERTIFICATE; resid A < 1e-25; чередование 100%; замыкание точное; когерентность > 0.99 | коммит V19 |

Запуск: `bash independent_verification/RUN_ALL.sh` или
`make ivp`. Отличие от RESULTS.md — релиз-стоппер.
