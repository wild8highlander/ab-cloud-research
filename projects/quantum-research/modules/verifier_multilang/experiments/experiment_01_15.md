# 15 экспериментов: пошаговые протоколы и критерии

## Эксперимент 01 — Контрольные унитарные матрицы

**Цель.** Проверить формулы fidelity и унитарной невязки на случаях с известным ответом до запуска случайных матриц.

**Шаги**
1. Построить \(I\), перестановочную матрицу, DFT\(_4\), Hadamard и случайный диагональный унитарный оператор.
2. Проверить \(U^\dagger U=I\).
3. Проверить fidelity \(F(U,V)=|\mathrm{Tr}(U^\dagger V)|^2/d^2\). Глобальная фаза должна не менять F.
4. Внести контролируемую ошибку в один элемент, затем повторить метрики.

**PASS-критерий:** невязка унитарности и \(1-F\) для точных контролей на уровне выбранного численного допуска, например \(10^{-12}\) в Float64. Допуск следует обосновать и фиксировать заранее.

**Контроль:** умножить U на \(e^{i\alpha}\); fidelity должна остаться равной единице.  
**Не доказывает:** корректность физической реализации ворот.

## Эксперимент 02 — Повтор Haar-компиляции 4×4 и 8×8

**Цель.** Независимо воспроизвести главный вычислительный результат V20, не подменяя его данными исходного отчёта.

**Шаги**
1. Генерировать комплексную гауссову матрицу \(A\), выполнить QR и нормировать фазы диагонали R для Haar-распределения.
2. Скомпилировать каждую матрицу Givens-разложением и фазами диагонали.
3. Собрать матрицу исполнения V и вычислить \(1-F(U,V)\).
4. Использовать новые заранее объявленные seeds; старые seeds 96 и 296 оставить как репликацию.
5. Сохранить все индивидуальные ошибки, не только максимум.

**PASS-критерий:** сравнение с порогами исходного claim-файла: \(1-F\le10^{-12}\) для 4×4 и \(\le10^{-10}\) для 8×8, если Julia-порт доказанно реализует тот же алгоритм и порядок умножения.

**Отчёт:** max, median, 95-й процентиль, число провалов, gates.  
**Не доказывает:** масштабируемость на десятки/сотни кубитов; точность Float64 не равна физической fidelity.

## Эксперимент 03 — Масштабирование

**Цель.** Измерить вычислительную стоимость без преждевременных заявлений об эффективности.

**Шаги**
1. Начать с \(d=2^n\), \(n=1,2,3,4,5\); расширять только при доступной памяти.
2. На каждой размерности сгенерировать одинаковое заранее установленное число матриц.
3. Измерять отдельно генерацию, компиляцию, сборку V и проверку fidelity.
4. Записать allocations/память, число AB2/PHASE-блоков и эквивалент двухкубитных ворот.
5. Сопоставить наблюдения с плотной оценкой \(O(d^3)\) времени и \(O(d^2)\) памяти.

**PASS-критерий:** все измерения завершены и сохранены; математическая точность оценивается отдельно от времени.  
**Анализ:** логарифмический график time(d), regression \(\log t = a+b\log d\), доверительный интервал b.  
**Не доказывает:** преимущество над лучшими компиляторами — для этого нужен честный baseline и одинаковые ограничения.

## Эксперимент 04 — Seeds, реплей и численная стабильность

**Цель.** Проверить, зависит ли заключение от одной выборки и воспроизводится ли результат в заданной среде.

**Шаги**
1. Запустить фиксированные seeds в одном окружении дважды.
2. Сохранить входные матрицы, параметры компиляции и массив ошибок.
3. Сравнить точные байты входов/выходов в одной среде; между платформами сравнивать численные допуски, а не требовать идентичности байтов.
4. Провести независимую серию минимум из 20 seeds.
5. Перемешать порядок прогонов и проверить отсутствие зависимости от порядка.

**PASS-критерий:** точный реплей внутри зафиксированной среды; для межплатформенного повтора — ошибка не превышает предрегистрированный допуск.  
**Отчёт:** hash окружения, Julia version, CPU, seed, максимум/квантили.  
**Не доказывает:** универсальную воспроизводимость на всех BLAS/CPU.

## Эксперимент 05 — Чувствительность к фазовому шуму

**Цель.** Проверить, насколько точность компиляции деградирует при ошибках фазовых параметров.

**Шаги**
1. Сгенерировать набор унитарных целей и их программы.
2. Для каждого фазового параметра добавлять независимый \(\epsilon\sim N(0,\sigma_\phi^2)\).
3. Прогнать сетку \(\sigma_\phi \in \{0,10^{-8},10^{-7},\ldots,10^{-1}\}\) рад.
4. Для каждого уровня провести, например, 100 повторов и сохранить полное распределение fidelity.
5. Добавить систематический сдвиг фазы как отдельный режим.

**PASS/FAIL:** здесь не предполагается PASS на всех шумах. Проверяется заранее выбранная спецификация, например максимальный \(\sigma_\phi\), при котором 95-й процентиль \(1-F\) остаётся ниже прикладного бюджета ошибки.

**Контроли:** нулевой шум; одинаковый сдвиг глобальной фазы, который не должен влиять на F.  
**Не доказывает:** характеристики реального носителя без измеренной модели шума.

## Эксперимент 06 — Память при дефазировке и деполяризации

**Цель.** Заменить идеальное удержание в базисе на явную стохастическую модель канала.

**Шаги**
1. Задать состояния памяти и канал дефазировки с вероятностью p на такт.
2. Отдельно добавить деполяризацию с вероятностью q; не смешивать эти параметры в один «шум».
3. Симулировать T шагов для нескольких T и уровней p/q.
4. Для каждого входного паттерна многократно сэмплировать ошибки и измерять вероятность верного чтения.
5. Построить кривые выживания и сравнить с идеальным каналом.

**Метрика:** \(P(\hat{x}=x)\), mutual information \(I(X;\hat X)\), время до пересечения фиксированного порога.  
**Контроль:** p=q=0 должен давать идеальное чтение.  
**Оговорка:** это поведение математической модели, а не измеренная когерентность физической памяти.

## Эксперимент 07 — Исправление ошибок: код против контроля

**Цель.** Проверить, снижает ли конкретный код частоту логических ошибок в заявленной модели.

**Шаги**
1. Начать с простого трёхкратного repetition code для битовых ошибок; отдельно учитывать, что он не исправляет произвольную фазовую ошибку.
2. Сравнить закодированную схему с одиночным физическим битом при одинаковой физической вероятности ошибки.
3. Ввести декодирование majority vote и независимые, затем коррелированные ошибки.
4. Измерить logical error rate на сетке p и количестве trials.
5. Проверить отрицательный контроль: для коррелированных ошибок, затрагивающих все копии, выигрыш может исчезнуть.

**PASS-критерий:** заранее выбранное снижение logical error rate относительно контроля на диапазоне p; сообщать доверительные интервалы.  
**Не доказывает:** топологическую защиту. Для неё нужны отдельный код, физическая модель и сравнение равных ресурсов.

## Эксперимент 08 — Полный перебор ALU и обратимость

**Цель.** Проверить арифметические операции не только на нескольких примерах, а на всей таблице состояний.

**Шаги**
1. Перебрать все 4-битные a,b.
2. Проверить reversible-сумматор вида \((a,b)\mapsto(a,(a+b)\bmod16)\), а не необратимое \((a,b)\mapsto(a+b)\bmod16\).
3. Проверить обратимость отображения и отсутствие коллизий выходов.
4. Отдельно проверить умножение mod 16 на нечётный множитель; чётный множитель не задаёт перестановку на всём кольце.
5. Для сравнения использовать фазовый оракул \( (-1)^{[a>b]}\), не выдавая его за классический необратимый comparator.

**PASS-критерий:** полное совпадение таблицы истинности и биективность там, где заявлен унитарный оператор.  
**Не доказывает:** ускорение арифметики относительно CPU.

## Эксперимент 09 — Стоимость арифметики при росте разрядности

**Цель.** Измерить стоимость реализации, а не только логическую корректность.

**Шаги**
1. Для n=2…8 бит построить reversible-операции с явными вспомогательными регистрами.
2. Проверить все входы для малых n; для больших n — случайные тесты плюс формальные инварианты.
3. Записать количество примитивов, глубину, SWAP-маршрутизацию и размер матрицы, если используется плотная модель.
4. Сравнить прямую матричную симуляцию с симуляцией по разреженной схеме.
5. Показать, где экспоненциальное представление матрицей становится непрактичным.

**PASS-критерий:** функциональная корректность и полный отчёт стоимости; численный порог не заменяет алгоритмического анализа.  
**Не доказывает:** превосходство над классическим умножением.

## Эксперимент 10 — Алгебраические числа как фазы

**Цель.** Проверить кодирование и чтение фаз на наборе значений, полученных из независимых точных/высокоточных выражений.

**Шаги**
1. Использовать фиксированный список: \(\sqrt2,\sqrt3,\sqrt[3]2,\varphi,2\cos(2\pi/7)\).
2. Преобразовать каждое число в фазу только через явно заданное отображение \(g(x)\); документировать диапазон и неоднозначность modulo \(2\pi\).
3. Восстановить фазу по комплексной амплитуде, используя circular distance \(d(\alpha,\beta)=|\arg(e^{i(\alpha-\beta)})|\).
4. Сравнить Float64 с BigFloat и с аналитическим значением.
5. Добавить отрицательный контроль с намеренно смещённой фазой.

**PASS-критерий:** максимальная circular error ниже заранее заданного допуска, например \(10^{-12}\) для вычислительного слоя.  
**Оговорка:** «загрузка фазы» — операция модели; нужно доказать, что она реализуется заданным набором примитивов.

## Эксперимент 11 — Слепое чтение нулей дзета-функции

**Цель.** Проверить заявленный пайплайн обнаружения нулей без утечки reference-таблицы в детектор.

**Шаги**
1. Разделить код на детектор и независимый валидатор; детектор не должен импортировать список нулей.
2. До запуска зафиксировать диапазон t, шаг сетки, критерий намотки аргумента, refinement и критерий остановки.
3. Детектор сохраняет найденные позиции и hash выходного файла до открытия reference-значений.
4. Валидатор после фиксации вычисляет precision, recall, смещение позиций и число пропусков/ложных находок.
5. Проверить устойчивость к сгущению сетки и повышению точности арифметики.
6. Сравнить с независимым методом — например, знакопеременами Hardy Z(t) и бисекцией — только после фиксации результата детектора.

**Критически важно:** формула \(\zeta(s)\), численная оценка и аргументная намотка требуют корректной высокоточной реализации и контроля около нулей. Обнаружение первых 12 нулей на ограниченном интервале не доказывает утверждение о всех нетривиальных нулях и не доказывает гипотезу Римана.

**Метрики:** precision/recall, максимальное и RMS отклонение, устойчивость к шагу сетки, число нулей по аргументному принципу. Для больших высот нельзя экстраполировать успех малой области.

## Эксперимент 12 — Интерферометр и AB-фаза

**Цель.** Проверить внутреннюю согласованность модели Маха–Зендера.

**Шаги**
1. Построить \(H\,\mathrm{diag}(1,e^{i\phi})\,H\).
2. Просканировать \(\phi\in[0,2\pi]\) на равномерной сетке.
3. Сравнить численную вероятность одного выхода с \(\sin^2(\phi/2)\).
4. Повторить с плотной и разреженной сеткой, а также с глобальной фазой на всю матрицу.
5. Отдельно добавить различный шум в два плеча.

**PASS-критерий:** аналитическая формула совпадает с численной реализацией в пределах допуска округления.  
**Контроль:** при \(\phi=0\) и \(\phi=2\pi\) выход возвращается к ожидаемой интерференционной картине.  
**Не доказывает:** что конкретный физический AB-эксперимент имеет эту ошибку или топологическую защиту.

## Эксперимент 13 — No-signaling через редуцированную матрицу плотности

**Цель.** Проверить локальную инвариантность маргинала в корректной модели составной квантовой системы.

**Шаги**
1. Создать нормированную совместную матрицу плотности \(\rho_{AB}\).
2. Сгенерировать локальные унитарные \(U_B\) и вычислить \(\rho'=(I\otimes U_B)\rho(I\otimes U_B^\dagger)\).
3. Вычислить частичный след \(\rho_A=\mathrm{Tr}_B\rho\) до и после операции.
4. Сравнить trace distance \(D(\rho_A,\rho'_A)=\frac12\|\rho_A-\rho'_A\|_1\).
5. Повторить на случайных чистых и смешанных состояниях; проверить локальные CPTP-каналы, а не только унитарные.

**PASS-критерий:** trace distance находится на уровне численной погрешности.  
**Не доказывает:** мгновенное физическое влияние; no-signaling — следствие структуры квантовой теории и локальных операций.

## Эксперимент 14 — CHSH и нулевые модели

**Цель.** Отделить вычисление квантовой корреляции от вывода о физическом нарушении неравенства Белла.

**Шаги**
1. Определить состояние Белла и четыре измерительных настройки.
2. Вычислить корреляции \(E(a,b)\) и \(S=|E_{00}+E_{01}+E_{10}-E_{11}|\).
3. Проверить квантовую симуляцию против аналитического значения \(2\sqrt2\).
4. Реализовать локальную скрытую модель как отрицательный контроль, которая должна соблюдать \(S\le2\) при стандартных предпосылках.
5. Если когда-либо подключаются реальные данные, заранее описать независимость настроек, детекторные потери, выборку событий и loopholes.

**PASS-критерий симуляции:** совпадение с аналитикой. Это не экспериментальное свидетельство Bell-нарушения.  
**Не доказывает:** сверхсветовую передачу или особую AB-модель; требуется сравнение с обычной квантовой механикой.

## Эксперимент 15 — Топологическая устойчивость и абляции

**Цель.** Проверить, какие возмущения действительно сокращаются, а какие меняют наблюдаемую фазу.

**Шаги**
1. Повторить заявленное локальное возмущение, действующее одинаково на оба плеча, и подтвердить, что это алгебраическое сокращение.
2. Добавить асимметричное возмущение только в одно плечо.
3. Изменить глобальный параметр/число зацеплений модели, которое должно менять голономию.
4. Сравнить «локальное общее», «локальное асимметричное» и «глобальное топологическое» воздействия в одном протоколе.
5. Провести абляции: убрать перекрёстный фазовый член, рандомизировать топологический параметр, заменить модель обычной фазой пути.
6. Оценить эффект с доверительными интервалами и показать все отрицательные результаты.

**PASS-критерий:** заранее заявленный контраст воспроизводится: общее локальное воздействие мало влияет, а контролируемое фазовое/глобальное воздействие меняет фазу согласно модели.  
**Не доказывает:** физическую топологическую защиту без реалистичного шума, равных ресурсов и независимого экспериментального измерения.

## Эксперимент 16 — Независимый движок Римана–Зигеля

**Цель.** Реализовать вторую, независимую от Эйлера–Маклорена оценку ζ(½+it)
методом Римана–Зигеля и сравнить движения при равной точности.

**Структура.** Формула Ариаса де Рейны (I, II) в сборке, сверенной с
mpmath/functions/rszeta.py: R = S₁ + rssum·S₃, ζ = R + e^{−2iθ}·conj(R);
коэффициенты F вычисляются на лету из целочисленной рекурренты чисел Эйлера
(без рукописных таблиц) на 400 бит; обрезка асимптотического ряда — U-turn
с шагом 2 (члены затухают парами нечёт/чёт).

**Шаги**
1. Построить ряд F(z) = (e^{πi(z²/2+3/8)} − i√2cos(πz/2))/(2cos(πz)) и таблицу
   производных Dm; проверить ряд против прямой формулы при |z| ≤ 0.999.
2. Проверить вещественность Z(t) = e^{iθ}ζ(½+it) на сетке высот.
3. Сравнить ζ_RS с ζ_ЭМ (масштабируемое расписание N ≥ 0.512t, K=14) на общей
   сетке [250, 1000] с шагом 3.7 (≈203 высот).
4. Измерить стоимости (медиана 7 прогонов) на высотах {100, 300, 1000, 3000,
   10000} при равной точности.

**PASS-критерий (предрегистрирован):** F-ряд ≤ 1e−30; вещественность ≤ 1e−12;
макс. |ζ_RS − ζ_ЭМ| ≤ 1e−9 (и на сетке самотеста, и в бенчмарке).  
**Не доказывает:** превосходство RS на всех высотах; применимость при t < 50;
гипотезу Римана.

## Эксперимент 17 — Слепое обнаружение нулей ζ на высоте T = 1000

**Цель.** Расширить флагман Э-11 с [0.3, 60] до [0.3, 1000] и провести
обнаружение ДВУМЯ независимыми движками с контролем полноты N(1000).

**Шаги**
1. Детектор A (Эйлер–Маклорен, масштабируемое расписание): намотка аргумента
   на сетке h = 0.01 по [0.3, 1000]; кандидаты |Δarg| > π/2; уточнение золотым
   сечением. Выход фиксируется, SHA256 — до валидации.
2. Детектор B (Риман–Зигель, окно [50, 1000], тот же протокол). Выход
   фиксируется, SHA256 — до валидации.
3. Валидатор: Гаусс–Ньютон по |ζ|² с ДРУГИМ расписанием ЭМ (N=320, K=12);
   сопоставление с эталонной таблицей mpmath.zetazero (n = 1…660, SHA256
   таблицы проверяется); precision/recall; кросс-движковое согласие.
4. Контроль полноты: N(1000) = θ(T)/π + 1 + S(T)/π по стандартному пути
   2 → 2+iT → ½+iT; согласие с числом найденных нулей.
5. Устойчивость к сетке на подокне [900, 1000]: h ∈ {0.02, 0.005}.

**PASS-критерий (предрегистрирован):** precision = recall = 1 для ОБОИХ
движков; max|Δγ| ≤ 1e−9 к mpmath.zetazero; кросс-движок ≤ 1e−9; N(1000) по
стандартному пути = числу найденных нулей; устойчивость к сетке ≤ 1e−9.  
**Не доказывает:** RH выше T = 1000; простоту всех нулей; отсутствие нулей
вне критической прямой при γ > 1000.

## Эксперимент 18 — Компилятор против сильных baseline (класс B, O-J2)

**Цель.** Перенести алгебраическое преимущество компиляции в класс B:
сравнить компилятор пакета (замкнутая форма Givens-QR) с сильными
baseline-синтезаторами на независимом наборе матриц при РАВНЫХ ограничениях.

**Равные ограничения (методологическое решение, зафиксировано до прогона).**
Все методы выдают программу в одном ISA (AB2 + PHASE); численные baseline
получают ровно те же слоты программы, что и ABQP (равный бюджет примитивов).

**Шаги**
1. Независимый набор (seeds 41800+, не пересекаются с V20/E02): 9
   структурированных матриц (identity4, DFT4, DFT8, Clifford4 = H⊗P,
   Clifford8 = H⊗H⊗H, перестановки 4/8, диагональные 4/8) + 40 Haar 4×4
   (seeds 41811…41850) + 20 Haar 8×8 (seeds 41911…41930) + испорченный
   контроль DFT4 + 1e−3.
2. Методы: ABQP (настоящий компилятор lib_abqp); BL1 — наивный Givens
   (прямой порядок, без пороговых пропусков); BL2 — учебная Эйлер-
   декомпозиция W = D1·G(θ)·D2 каждого 2×2 блока (1 AB2 + 4 PHASE, без
   слияния фаз); BL4 — Хаусхолдер-QR с разложением каждого отражения
   H = S†·P·S; BL3 — покоординатный спуск золотым сечением по слотам ABQP
   (3 рестарта × 200 свипов @4×4; 1 × 100 @8×8); BL5 — случайный поиск
   (3000/300 проб).
3. Метрики на каждую цель × метод: примитивы (n_AB2, n_PHASE, всего),
   2q-эквивалент (конвенция popcount-XOR из rpbridge/compiler.py), 1−F,
   время компиляции (медиана повторов), успех 1e−12.

**PASS-критерий (предрегистрирован):**
(i) ABQP: 1−F ≤ 1e−12 на 100% целей (контроль исключён из порога);
(ii) примитивов у ABQP ≤ каждой точной ISA-baseline (BL1/BL2/BL4) на каждой
цели;
(iii) медиана времени компиляции ABQP × 50 ≤ медианы BL3 (подмножество
Haar 4×4);
(iv) identity → 0 блоков AB2; испорченная цель компилируется (1−F ≤ 0.01).

**Честная фиксация вне порогов:** 2q-эквивалент сравнивается с теоретическим
KAK-оптимумом (3 CNOT для 4×4; Vidal–Dawson 2004) как КОНТЕКСТ вне ISA-класса
сравнения — превосходство по этой метрике НЕ заявляется.

**Не доказывает:** превосходство по 2q-эквиваленту над KAK-оптимумом;
масштабирование численных baseline на d > 8; физическую реализацию.
