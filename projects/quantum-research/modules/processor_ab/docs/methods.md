# docs/methods.md — методы AB Quantum Processor Program v0.1.0

## 1. Модель и ISA

Физическая база — блочный гамильтониан AB-облака в форме V18
материнской серии: H₂ = m·σz − t(cos φ·σx + sin φ·σy), где φ — фаза
из флакса. V18 доказала аналитическую калибровку шести фиксированных
ворот {X, Y, Z, H, S, T} (fidelity 1−2e-16). V20 добавляет два
параметрических примитива:

- **AB2(a, b; θ, λ, φ, χ)** — двухуровневый блок-импульс: произвольный
  элемент U(2) на паре базисных состояний |a⟩, |b⟩; ZXZ-Эйлер
  (RZ(φ)·RX(θ)·RZ(λ)) с глобальной фазой e^{iχ}. Резонансный импульс
  перехода — обобщение механизма P1 V18.
- **PHASE(x; φ)** — селективный детюнинг уровня |x⟩ на Δ; эволюция
  t = φ/Δ даёт diag-фазу e^{iφ} на уровне; обобщение механизма P2 V18
  (уровень |11⟩ → произвольный). В AB-облаке уровни — состояния
  вихревой конфигурации; многочастичный характер фазы согласован с
  законом V19 ζ^{ra+sb}.

Производные: RZ (чистая масса, m·t = φ/2), RX (чистый туннель,
t·t_pulse = θ/2), CPHASE (PHASE на паре), CNOT = H₂·CPHASE(π)·H₂.
Калибровка проверяется численной экспонентой блочного гамильтониана:
fidelity F = |Tr(U_t†U)|²/d ≥ 1−1e-14 на каждом примитиве.

## 2. Компилятор (V20)

Трёхшаговая замкнутая схема (без оптимизации):

1. **Givens-QR.** U = B₁·B₂·…·B_k·D: последовательные вращения в
   плоскостях строк (c, r) зануляют поддиагональ; для унитарной U
   R-фактор диагонален. Блоки хранятся эрмитово-сопряжёнными
   (B_i = W_i†), поэтому произведение блоков в обратном порядке даёт U.
2. **AB2-параметризация.** Каждый 2×2 блок B = [[α, β], [γ, δ]] в
   замкнутой форме: c = |α|, θ = 2·arccos c, χ = arg α,
   λ = arg(β/(−i s)) − χ, φ = arg(γ/(−i s)) − χ; корректность
   проверяется assert-ом (|Tr(B₂†B)| = 2).
3. **Лестница PHASE.** D = Π_x PHASE(x; φ_x), φ_x = arg D_xx, приведённые
   в (−π, π]; фазы с |φ_x| < 1e-14 отбрасываются, их вклад входит в
   метрику fidelity (процессор исполняет только операции программы).

Временнóй порядок программы: фазы уровней первыми, затем блоки в
обратном порядке. Стоимость: n_AB2 + n_PHASE и «двухкубитный
эквивалент» с CNOT-маршрутизацией (правило 2h−1 по расстоянию Хэмминга
h между базисными состояниями пары).

Метрика: F = |Tr(V†U)|²/d² — глобальная фаза не учитывается.

## 3. Протокол V20

- 4×4: M = 200 Хаар-унитарных (QR комплексного Гаусса с фазовой
  нормировкой), сид 96, порог 1−F ≤ 1e-12.
- 8×8: M = 100, сид 296, порог 1−F ≤ 1e-10.
- Контроли: identity (0 затворов), циклическая перестановка, DFT 4×4,
  CL(2) — фиксированный Клиффорд (H⊗I)·CNOT·(I⊗H)·(S⊗I).
- Бит-в-бит реплей: полный повтор прогона, сравнение float64-битов
  выходных матриц.
- Превью-слои: память/АЛУ/считывание/нелокальность (см. ниже), честно
  помечены предварительными.

## 4. Превью: память (P1)

Регистр = 6 узлов (64 базисных состояния). Запись — приготовление
базисного состояния; удержание — T = 10³ тактов диагональной динамики
H_RAM (фазы уровней статичной вихревой конфигурации; базис —
собственный, поэтому выживание точное и честно фиксируется как
свойство модели); чтение — измерение в вычислительном базисе (аргмакс
|ψ|²). RAM-тест: полный перебор 64 паттернов. Латентность: L(d) = a + b·d,
a = 2, b = 4 (SWAP-маршрутизация; порог V21 b ≤ 6). Фазовые слова:
k ∈ [0, 256) → фаза 2πk/256 → чтение аргументом.

## 5. Превью: АЛУ (V22)

Арифметическая операция (a, b) → a⊕b на 4-битных словах —
перестановочная унитарная матрица 256×256 на регистре |a⟩|b⟩;
компилируется компилятором V20; таблица истинности проверяется полным
перебором входов (исполнение программы на базисных состояниях, чтение
аргмаксом). Умножение mod 16 определено на обратимых (нечётных)
множителях; блоки чётных множителей остаются тождественными (полная
матрица перестановочна). Компаратор — фазовый оракул: diag(±1),
фаза −1 на входах с a > b (compare-exchange необратим — коллизии;
фазовая кодировка унитарна).

## 6. Превью: считывание нулей (V23)

Вход — ТОЛЬКО прямая формула ζ(s) (mpmath, Euler–Maclaurin, O(1)
констант); таблица нулей не используется нигде. Механизм — аргументная
намотка: φ(t) = arg ζ(½+it) разворачивается вдоль критической прямой;
скачки |Δφ| > π/2 — прохождения нулей (монодромия π, V19); позиции
уточняются минимумом |ζ| на под-сетке (интерферометрическое считывание).
Контроль — независимый: нули вещественной функции Z(t) = e^{iθ(t)}ζ(½+it)
(Зигель-тета), бисекция, применяется ТОЛЬКО после фиксации результата
чтения (blind-протокол V1). Параметры P0-превью: окно [2, 58], M = 560,
уточнение 17 точек; порог позиционного отклонения — половина шага
сетки. Бухгалтерия: хранится 0 нулей и 6 констант формулы; нули
воспроизводятся по запросу.

## 7. Превью: нелокальность (V24)

Модель: голономия зацеплений. Состояние пары после совместной AB-фазы:
|Ψ(Φ₁₂)⟩ = (1/2)(|++⟩ + |+−⟩ + |−+⟩ + e^{iΦ₁₂}|−−⟩), Φ₁₂ = 2π·q₁₂·L₁₂.
Три точных факта: (а) интерферометр Маха–Зандера с AB(φ) даёт
P = sin²(φ/2) с невязкой ≤ 1e-14; (б) топологическая защита: 1000
случайных унитарных возмущений внутренних состояний (одинаково во всех
плечах — область без поля) не меняют измеренную фазу; (в) no-signaling:
E(XX) = (1+cos Φ₁₂)/2 несёт Φ₁₂, но ρ₁ = Tr₂ ρ инвариантно к локальным
унитарным второй частицы (Tr₂[(I⊗A₂)ρ(I⊗A₂)†] = ρ₁ — алгебраически
точно, 100 случайных A₂). CHSH на |Φ+⟩: S = 2√2 при
[Aᵢ⊗I, I⊗Bⱼ] = 0.

## 8. Аудит и независимая верификация

Claim-файл по схеме V14 (statement / premises / code / controls /
does_not_prove / status) с числовыми согласованиями путь→значение→допуск
(rpbridge.audit). IVP01–IV05: свежий полный повтор протокола компилятора
с проверкой совпадения с вердиктом; контроли; бит-в-бит повтор; RAM и
латентность; весь набор нелокальности. Все прогоны детерминированы
(сиды 96 / 296).
