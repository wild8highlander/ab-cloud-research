# 🧪 HYPOTHESIS_LAB — examples

> **Four ready-to-run hypothesis files: the input format of the lab, by example.**

Each JSON file here is a complete, loadable hypothesis for [`../ab_lab.py`](../ab_lab.py) — the lab's input format demonstrated end to end. The quartet covers the four supported hypothesis shapes: a spinor-family hypothesis ([`hypothesis_spinor.json`](hypothesis_spinor.json)), a trace-formula variant, a zeros-domain variant, and a compiler-style gates hypothesis. Copy one, edit the parameters, and run the lab — the engine validates the schema before computing anything, so these files double as schema documentation.

After a run the engine writes its assembled reports into [`../reports/`](../reports/) (currently empty — reports appear here the first time you execute the lab locally; generated artifacts are not committed).
