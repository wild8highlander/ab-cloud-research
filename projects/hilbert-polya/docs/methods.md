# Methods — конвейеры серии

> Единые методы всех кампаний: развёртки, статистики, сита, следовой
> конвейер. Пороги и контроли — в docs/validation.md.

## 1. Спектральный конвейер затвора

```
vortex config (seed 96, центры ячеек, нейтральные заряды)
  → build_hamiltonian (engine/hamiltonian.py)
  → eigvalsh (driver evr)
  → central_band: floor(n·frac/2) — fld-арифметика, 344 уровня
  → unfold_poly (степень 6 → 3, фолбэк — монотонный interp)
  → window_u (ровно 200 уровней с отступом 10)
```

Бит-в-бит контроль базы: Nv = 0, W = 0.5, α = 0.5 воспроизводит
mean_spacing CSV C3 с |Δ| = 1.45e-16 — порт эквивалентен протоколу C3.

## 2. Развёртка нулевой стороны

Гладкий счёт Римана–фон Мангольдта N̄(γ) = γ/2π·ln(γ/2πe) + 5/8; окно —
те же 200 уровней, отцентрированные N̄(γ_n) − N̄(γ_1). Обе стороны
оказываются в координатах «единица средней плотности» — это делает
корректными все три статистики:

- **r_H7** — корреляция Пирсона флуктуаций (рампы исключены вычитанием
  линейного тренда ранга);
- **D_nn** — среднее ближайшее соседство после оптимизации глобального
  сдвига (для изоспектральных близнецов — со склейкой кратностей);
- **KS_sp** — двухвыборочный KS между соседними развёрнутыми расстояниями.

## 3. Нулевые распределения и контроли

- циклические сдвиги списка нулей (64) — «тождества нет»;
- GUE-матрицы (X + X†)/2 тем же конвейером — «универсальность без тождества»;
- декуи (случайные фазы) — «структура фаз не важна»;
- позитивные контроли: PC1 spinor64-близнецы, PC2 график↔файл, PC0
  окно нулей против Λ-гребёнки.

Для тепловой метрики C4 дополнительно: блочный суррогат гребёнки
(перемешивание блоков по 5 — сохраняет локальную форму, разрушает
выравнивание) и пуассоновский нуль (200 равномерных точек на [0, 199]).

## 4. Следовой конвейер (C4, T6)

Полный вывод — docs/trace_formula.md. Схема:

```
Hadamard:  ξ'/ξ(s) = B + Σ_ρ[1/(s−ρ)+1/ρ],  B = ξ'(0)/ξ(0) = ½ln(4π) − 1 − γ/2
   ↓ спаривание ρ ↔ ρ̄
Q(a) = Σ_{γ>0} 2a/(a²+γ²) = ζ'/ζ(½+a) + 1/(½+a) + 1/(a−½) − ½lnπ + ½ψ(¼+a/2) − B − C₀
   ↓ 2a/(a²+γ²) = 2∫₀^∞ e^{−γt} sin(at) dt,  обращение синус-преобразования
K(x) = Tr e^{−xH_ξ} = (1/π)∫₀^∞ Q(a) sin(ax) da
   ↓ расщепление по a = 1.5 (Re s = 2)
T1 (Γ-часть, [0, 1.5], сплайн mpmath-сетки)
T2 (простая часть: −ΣΛ(n)/√n·Im[e^{−A(ln n−ix)}/(ln n−ix)], решето до 1e7)
T3 (гладкая часть: точные формы Si/Ci для 1/(a∓½), ln-члена, R₂, констант)
```

Метрика затворов: D(u) = Σ e^{−u x_n} − (1 − e^{−u x_K})/u — флуктуация
развернутого теплового следа; r_EF = corr(D, c·P) с амплитудой по МНК
и ФИКСИРОВАННЫМ масштабом s = 1 (оптимизация масштаба исключена —
она систематически завышает r; диагностический скан сохранён в данных).

## 5. Арифметические конвейеры

- **Решето Λ(n)** — наименьший простой делитель до 10⁷ (C4) / 10⁶ (C6);
  носители — 665 134 числа при 10⁷.
- **ψ-лестница** — эталон по первым 200 нулям против сита до 10⁶;
  методологическое правило: окно эталона — на тех же высотах, где
  работает сито (окно на γ ~ 500 даёт corr 0.48 и отвергнуто).
- **Счёт кампании C2** — рекурсивно-адаптивный шаг Тьюринга с двойным
  условием листа; две арифметики (numpy / mpmath dps 26) с мостом 2.6e-26.
