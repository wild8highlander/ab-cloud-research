# T11. Уникальность теплового следа и нелокальный примитив (C9)

**Теорема T11.** Пусть H — самосопряжённый оператор с дискретным спектром
{λ_n ⊂ (0,∞)} и Tr e^{−xH} = (1/π)∫₀^∞ Q(a)sin(ax) da для всех x > 0, где
Q(a) = Σ_{γ>0} 2a/(a²+γ²) — нулевая сторона явной формулы. Тогда
{λ_n} = {γ_n} (с учётом кратности).

**Доказательство.** Преобразование Лапласа функции распределения
ν(E) = #{n : λ_n ≤ E} равно Tr e^{−xH} = ∫₀^∞ e^{−xE} dν(E) —
аналитична по x > 0. Правая часть, (1/π)∫Q(a)sin(ax)da, по классической
теореме единственности для преобразования Лапласа–Стилтьеса определяет
меру ν однозначно. Поскольку (1/π)∫₀^∞ 2a·sin(ax)/(a²+γ²) da = e^{−xγ},
мера ν — в точности считающая мера множества {γ_n}. ∎

**Следствие (архитектурное).** «Вес простых в тепловом следе» — не
декорация, а спектр: любой оператор с таким следом изоспектрален H_ξ.
Нелокальность при этом достижима произвольно (DCT/QR-сопряжения дают
плотные реализации с тем же следом бит-в-бит), локальность (решётка) —
никогда: измеренная стена C3–C5+C13 отделяет именно её.
