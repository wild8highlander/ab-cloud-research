# 🧭 Guides — the submission wizards, visible without unzipping

Each sealed zip on this shelf carries its own step-by-step guide inside.
This folder holds **render-friendly copies** of those guides so that a
reviewer, an editor — or the Author a month later — can read the exact
wizard instructions straight on GitHub, without downloading a single byte.

| Guide | For | The zip it mirrors |
|---|---|---|
| [`NSR_JINR_how_to_submit.md`](NSR_JINR_how_to_submit.md) | Natural Science Review (JINR) wizard — [nsr.jinr.int](https://nsr.jinr.int) | `NSR_JINR_submission_AB-Cloud.zip` → `nsr_submission/README_how_to_submit.md` |
| [`SciPost_how_to_submit.md`](SciPost_how_to_submit.md) | SciPost Physics wizard — [scipost.org](https://scipost.org) | `SciPost_Physics_submission_AB-Cloud.zip` → `scipost_submission/README_how_to_submit.md` |
| [`arXiv_metadata.md`](arXiv_metadata.md) | arXiv metadata & endorsement checklist — [arxiv.org](https://arxiv.org/submit) | `arXiv_submission_AB-Cloud.zip` → `arxiv_submission/README_arxiv_metadata.md` |

> [!IMPORTANT]
> **Provenance rule.** The copy **inside the zip is the source of truth**;
> these visible copies were extracted on **2026-10-19** from the
> 2026-10-19 re-seal and are stamped with a provenance note at the top. The
> zips themselves are pinned by [`../SHA256SUMS.txt`](../SHA256SUMS.txt) — if
> a zip is ever re-sealed again, the mirrored guide must be re-extracted in
> the same commit, and [`../CHANGELOG.md`](../CHANGELOG.md) must say so.

> [!TIP]
> The guides also live outside the zips' scope of authority: they describe
> *how to upload*, not *what the science says*. For the manuscript's
> content, honest boundaries and the programme's current verdict state
> (G1–G5, C17, algebraic_map — synced 2026-10-16), start from the
> [README](../README.md#-where-the-science-stands-now) and the
> [FAQ](../FAQ.md#5-does-any-of-this-prove-the-riemann-hypothesis).
