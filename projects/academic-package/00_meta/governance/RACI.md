# RACI

| Activity | Author | Replicator | Reviewer | Reader |
|---|---|---|---|---|
| Registry numbers | A | C | R | I |
| Honesty layer (does_not_prove) | A/R | C | R (must approve) | I |
| Monograph text | A/R | C | R | I |
| CLI contract changes | A/R | C | R | I |
| New campaigns (in sources) | A | R | C | I |
| Translations | A | C | R | I |
| Web lab | A/R | C | R | I |
| Licence/honesty clause | A/R | I | R (must approve) | I |

A = accountable, R = responsible, C = consulted, I = informed.
For a single-author programme the columns collapse in practice — the table
exists so that *when* contributors arrive, the lanes are already drawn.
