# Policy brief — open science infrastructure note

**For:** research-infrastructure and open-science decision makers.
**Subject:** what the AB-Cloud unified package demonstrates about honest
computational research packaging.

1. **Pre-registration travels.** The package shows that verdict windows fixed
   in a config file (`config.yaml: gue_windows`) can govern an entire
   multi-laboratory programme's claims — a template any computational
   field can adopt.
2. **Negative results must be first-class.** The C17 blind phase-B verdict
   (NEGATIVE by the letter of its criterion) and the bit-level locality wall
   are the programme's most cited findings; infrastructure should
   treat "failure replication" as a publication-grade artefact.
3. **Honesty can be enforced structurally.** The V13 obligation machine
   (Lean 4 / Coq) makes overclaiming *impossible to express* rather than
   merely discouraged. Formal layers of this kind are cheap insurance for
   any programme whose outputs touch famous conjectures.
4. **One funnel for numbers.** A single machine-readable registry feeding
   monographs, reports, web labs and CLIs eliminates the "which number was
   that again" class of errors. The integrity test suite polices the funnel.
5. **Reproducibility across languages.** Six CLI implementations of one
   JSON contract, plus the sources' Python ↔ Julia cross-verification,
   demonstrate that multi-language reproducibility is a maintainable
   property, not an aspiration.
6. **Licensing honesty as data.** The three-component licence (MIT / CC BY
   4.0 / ODbL) plus an umbrella honesty clause shows a workable pattern for
   research artefacts whose *caveats are part of the record*.
